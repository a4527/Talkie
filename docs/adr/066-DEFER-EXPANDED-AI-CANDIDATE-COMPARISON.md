# ADR-066 · DEC-066 · AI 후보 확장 비교 후순위와 공개 경로 검증

- 결정일: 2026-11-02
- 상태: Accepted
- 동의 근거: 사용자가 Soniox STT/TTS 사용액을 보고하고 추가 AI 모델 비교를 여기서 멈춰 실제 운영에서 조정하자고 요청했다. 기존 DEC-054와 공개 전 조건의 차이를 [검토안](../proposals/AI-CANDIDATE-EVALUATION-PLAN.md#2026-11-02-후속-비교-범위-검토-채택)에 비교한 뒤, 후보 확장 비교를 선행 조건에서 해제하되 공개 전 선택 경로의 데이터·비용·핵심 학습 검증을 유지하는 B안에 “그러자”라고 동의했다. 사용액의 조건과 한계는 [오늘 기록](../worklogs/2026-11-02.md#사용자-보고-사용액과-후보-비교-중단-요청)을 따른다.
- 배경·이유: Gemini Live와 Soniox STT·Gemini 텍스트·Gemini/Cloud TTS의 로컬 경로가 연결됐고, 사용자는 짧은 음성·TTS 청취에서 문제를 보고하지 않았다. 여러 공급자의 구성 요소를 모두 시험하는 데 드는 계정 설정·개발 시간·호출비보다 현재 제품의 저장·인증·비용 통제를 진척시키는 가치가 크다고 판단했다. Soniox 사용액은 사용자 보고이며 Google Cloud 청구액과 완결 세션 비용은 미확인이다.
- 결정: DEC-054의 요소별 2~3개와 Gemini Live·OpenAI Realtime 전 후보 시험을 공개 경로 선택의 선행 조건에서 해제한다. 현재 로컬 경로로 기능 구현을 이어가고, 공개 전에는 실제 선택할 공급자·모델·경로를 명시적으로 합의한다. 선택 경로의 공급자 데이터 조건·계정 한도·실제 과금과 지출 통제, 긴 대화·끼어들기·교정·노트의 핵심 품질 및 저장·접근·삭제 정합성을 확인한다. 공개 후 주간 실제 비용·품질·오류를 관찰해 후보 또는 설정을 재평가한다.
- 대안·절충: DEC-054의 전 후보 비교를 유지하면 출시 전 비교 근거가 넓어지지만 기능 완성과 운영 검증이 늦고 시험비가 늘어난다. 현재 경로를 바로 공개하면 일정은 짧아질 수 있으나 미확인 데이터 조건·비용·품질과 PRD 제약을 감수하게 되어 선택하지 않았다. 이번 선택은 최저 비용 또는 최선 품질을 입증하지 못한 채 공개 후보를 좁히며, 운영 중 교체와 사후 비교가 필요할 수 있다.
- 미검증·재검토: 실제 사용자 데이터에 대한 공급자 적합성, Cloud 청구액, 장시간/동시 사용과 학습 품질은 아직 확인되지 않았다. 선택 경로가 기준을 충족하지 못하거나 운영 비용·오류·품질이 허용 범위를 벗어나면 다른 후보를 시험하고 경로를 재결정한다. 공개 연결의 제품 조건은 [PRD](../PRD.md#provider-data-policy), 완료 근거는 [TASKS](../TASKS.md#선행-관계)와 worklog를 따른다. 로컬 비공개 시험이나 본 결정만으로 공개 배포를 승인하지 않는다.
- 대체 관계: DEC-053/054의 비교 후보 수·순서 및 전 후보 시험 후 선택 조건을 대체한다. DEC-055의 Gemini Live 우선 로컬 통합과 음성 포트·어댑터 경계는 유지하고, 그 뒤 전 후보 비교를 예정한 부분만 대체한다. DEC-016의 실험 예산, DEC-025/056의 데이터 적용 범위, DEC-062/063의 비용 집행과 PRD의 실제 사용자 연결 조건은 유지한다.
