# ADR-088 · DEC-088 · 미션 결과 집계의 장기 보관

- 결정일: 2026-11-15
- 상태: Accepted
- 동의 근거: [최소 계약 검토안](../proposals/FIRST-MISSION-MINIMUM-CONTRACT.md)의 Q3에서 추천안(평가 결과 전체를 기존 지속 학습 기록 기간에 맞춤) 대신 사용자가 “점수 집계만 장기 보관”을 선택했다. 질문에는 기준별 사유는 기존 기간, 점수·달성 여부는 계정 유지 동안 보관하며 PRD 8절 변경이 필요하다는 설명을 함께 제시했다.
- 배경·이유: DEC-017은 무료 체험의 지속 학습 기록을 종료 후 30일 보관한다. 달성 일수는 여러 날에 걸친 누적 지표이므로 결과가 30일 뒤 사라지면 누적·소급 집계의 근거가 없어진다. 사용자 발화 원문이 없는 점수 집계만 길게 남기면 일수 근거를 유지하면서 장기 보관하는 개인 학습 내용의 범위를 작게 둘 수 있다.
- 결정:
  - 결과 집계(미션 ID·정의/평가표 버전·모드·수준·종료 사유·최종 경로·영역별/전체 획득 점수와 평가 만점·달성 여부·종료 시각)는 요금제와 관계없이 회원 탈퇴 전까지 보관하고 탈퇴 시 함께 삭제한다(DEC-019/021 유지).
  - 기준별 판정·사유와 짧은 근거는 기존 지속 학습 기록(DEC-017/018)과 같은 기간 보관한다. 무료 체험은 종료 후 30일에 만료한다.
  - 집계에는 사용자 발화 원문·교정문을 넣지 않는다.
- 대안·절충: 평가 결과 전체를 DEC-017 기간에 맞추면 보관 정책이 하나로 단순하지만 무료 사용자의 달성 일수 근거가 30일 뒤 사라진다. 기준별 사유까지 장기 보관하면 상세 피드백을 다시 볼 수 있지만 무료 체험 기록을 30일로 제한한 약속과 충돌한다. 선택안은 만료 작업이 상세와 집계를 다르게 다뤄야 하는 구현 비용을 수용한다.
- 미검증·재검토: 달성 일수의 날짜 귀속·누적/연속 표시·소급은 미정이며(B-12) 이 결정은 그 계산 방식을 정하지 않는다. 백업 삭제 기한·유료 전환 시 처리·운영 보관 검증은 기존 정책을 따르며 실제 사용자 데이터 처리 전 확인한다. 집계 항목이 늘어나 개인 학습 내용을 담게 되면 재검토한다.
- 대체 관계: DEC-017의 보관 기간을 미션 결과 집계에 한해 확장한다. 기존 노트·학습 항목·근거의 기간과 DEC-019 탈퇴 삭제는 바꾸지 않는다.
