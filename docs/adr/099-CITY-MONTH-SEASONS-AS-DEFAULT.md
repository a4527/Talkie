# ADR-099 · DEC-099 · 영어권 도시 한 달 살기 시즌을 기본 경험으로

- 결정일: 2026-11-20
- 상태: Accepted
- 동의 근거: 디자인 방향 탐색(라이프스타일·교육형 시안 E·F·G)에서 사용자가 여행 일지형을 고르고 “기본은 여행일지로 둘까?”라고 제안했다. 미션을 미리 모두 만드는 부담과 시즌의 연관성 문제를 사용자가 직접 제기했고, 추천안(시즌 틀만 직접 제작·미션은 AI 생성·평가표는 유형 단위·시즌 밖은 번외편)에 “한 달 살기로 해보자”, 첫 나라 추천(미국 뉴욕)과 요약 전체에 “그렇게 해보자 공유탭은 일단 보류”로 동의했다.
- 배경: PRD 4.1은 기본 미션·연속 스토리·AI 추천·직접 지정을 모두 제공하지만 무엇을 기본 진입으로 둘지 정하지 않았다. 매일 다른 주제를 하면 진행을 한눈에 보여 주기 어렵고, 테마와 이야기 흐름이 있어야 한다는 것이 사용자 요구였다. 반면 카페 미션 하나의 배점·허용 경로·경계 사례 검증(DEC-081~093)에 2주 넘게 걸려 미션을 하나하나 직접 만드는 방식은 비용이 크다.
- 결정:
  - 기본 경험은 영어권 도시에서 ‘한 달 살기’를 하는 시즌형 연속 스토리다. 첫 시즌은 미국 뉴욕이며 지역 문화를 미션 소재로 쓴다. ‘여행’보다 넓게 잡아 생활·업무 상황(숙소·은행·병원·직장)도 담는다.
  - 직접 만드는 것은 시즌 틀(무대·고정 인물·챕터 6개 내외의 주제 순서)뿐이다. 각 미션은 챕터 주제 안에서 AI가 짧은 후보 2~3개를 만들고 사용자가 고른 후보만 상세 구성·검증·고정한다(기존 PRD 4.1·7절 흐름).
  - 평가표는 미션마다가 아니라 미션 유형마다 검증한다. 카페 미션 평가표를 문제 해결형의 기준으로 삼고, 초기에는 목표가 분명한 유형 3~4개(후보: 문제 해결·예약/일정 조율·길/정보 묻기·부탁/제안)만 둔다. 해결 기준이 없는 가벼운 잡담형은 초기 범위에서 뺀다.
  - 이야기 연속성은 이전 미션에서 정해진 이야기 사실만 담은 짧은 스토리 상태로 잇는다. 사용자 발화 원문을 넣지 않고 지속 학습 기록과 같은 보관 기간·탈퇴 삭제를 따른다.
  - 직접 지정과 개인별 AI 추천은 유지하며, 시즌 밖 미션은 ‘번외편’으로 기록해 시즌 진행을 바꾸지 않는다. 달성 일수는 시즌과 번외편을 같은 기준으로 인정한다.
  - 사용자 제작 미션을 다른 사용자와 공유하는 기능은 보류한다(PRD 10절의 학습자 간 소셜 기능 제외 유지).
- 대안·절충: 시즌 미션을 모두 직접 만들면 연관성과 평가 품질은 가장 높지만 미션마다 검증 비용이 든다. 시즌 없이 일지만 두고 장소·주제로 자동 묶으면 비용은 가장 작지만 테마와 이야기 흐름이 약하다. 선택안은 AI 생성 미션의 품질 편차와 유형 평가표가 개별 상황에 덜 맞을 위험을 받아들인다. 공유 탭은 상황 다양성을 늘리지만 개인정보·부적절한 내용 관리, 탈퇴 삭제(DEC-019)와의 관계, 검증되지 않은 미션의 점수·일수 공정성 문제가 있어 미뤘다. 운영자가 검토해 공식 미션으로 올리는 방식은 다음 후보로 남긴다. 첫 나라로 영국 런던(억양·표현 차이 부담)·호주(억양·속어)·캐나다(미국과 문화 소재 차이 작음)·미국 서부 도시(일상 소재·인지도 약함)도 비교했다. 미국식 영어가 국내 학습자에게 익숙하다는 판단은 조사 없는 추정이다.
- 미검증·재검토: 챕터 안 AI 생성 미션의 실행 가능성·채점 근거·허용 대안 검증과 비용(PRD 11절의 생성 검증 미정), 유형 평가표가 생성 미션에 맞는지, 문화 소재의 사실성·고정관념 검토 기준, 스토리 상태의 크기·저장 위치는 구현 전에 정한다. 시즌 틀·유형 평가표의 저장 방식(DEC-086의 코드 레지스트리 확장 여부)도 미정이다. 실제 이용에서 시즌 진입률이 낮거나 번외편 비중이 크면 기본 경험을 재검토한다. 연속 일수 표시는 DEC-095대로 도입하지 않는다.
- 대체 관계: DEC-069의 미션 중심 경험 안에서 기본 진입을 구체화하며 기존 결정을 대체하지 않는다. DEC-070의 첫 카페 미션은 시즌 1의 미션 후보로 편입할 수 있다.
