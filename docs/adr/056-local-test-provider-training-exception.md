# ADR-056 · 로컬 시험의 공급자 학습 허용

- 결정일: 2026-10-27
- 상태: Accepted
- 동의 근거: 사용자는 테스트 중 학습 사용을 허용한다고 명시하고 무료 Gemini Live로 E2E를 먼저 구현하는 방향, 포트·어댑터 경계를 논의한 뒤 진행에 동의했다.
- 배경: DEC-025/052의 학습 금지 확인 때문에 무료 Gemini API를 시험하지 못했다. 공급자 키·결제와 여러 후보의 선행 비교는 실제 앱 흐름 구현을 지연한다.
- 결정과 이유: 개인정보·민감/기밀정보 없는 합성 대화와 개발자 본인 음성의 비공개 로컬 시험에 공급자 학습·표준 보관 조건을 허용한다. 초기 비용을 줄여 음성 E2E부터 확인하기 위한 예외다. 다른 사용자와 공개 배포에는 적용하지 않는다.
- 대안과 영향: 유료 API는 제품 개선 미사용 조건을 제공하지만 결제·비용 관리가 필요하다. 무료 API는 입력/응답의 제품 개선 사용과 사람의 검토 가능성, 공급자 보관/삭제 통제 한계를 수용한다. 앱에서 녹음하지 않더라도 공급자 보관까지 없어지는 것은 아니다. 자유 대화에서 개인정보를 완벽히 자동 차단할 수 없으므로 본인 시험만 허용한다. 단순 동의 UI로 공급자 개인정보 제출 제한을 없애지 않는다.
- 유지하는 경계: DEC-016 총 지출 3만 원, 유료 호출 상세 합의, 앱의 원본 음성 파일·DB·로그·백업 미저장은 유지한다. 유료 티어 자동 전환·결제 설정·실제 사용자 전송 승인은 아니다. 실제 사용자 연결은 DEC-025의 학습 금지·최대 30일 조건을 그대로 검증한다.
- 미검증·재검토: 사용자의 무료 등급 화면에서 Gemini 3.8 Live는 RPM/RPD 무제한, 입력 TPM 65K로 표시됐다. 이는 해당 프로젝트의 관찰이며 모든 계정의 보장이나 동시 연결/세션 길이 무제한을 뜻하지 않는다. 실제 연결·품질·차단·비용은 별도 검증한다. 공개 시험 확대·유료 전환·공급자 약관 변경 전 재검토한다.
- 대체 관계: DEC-025와 DEC-052의 로컬 합성·본인 시험에 대한 학습 금지/보관 전제만 부분 대체한다. 개발 순서는 DEC-055, 제품 데이터 정책은 PRD 8절이 기준이다.
