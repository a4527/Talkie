# ADR-049 · DEC-049 · DB 명명과 로그인·원문 상태 통합

- 결정일: 2026-10-25
- 상태: Accepted
- 동의 근거: 사용자가 계정 생성 시각·탈퇴 재확인·권한/원문 테이블 분리의 필요성을 질문했다. 이메일 재확인 유지, 탈퇴 최종 권한의 로그인 세션 통합, 임시 제어/수명 이력 통합으로 11개를 9개로 줄이는 추천에 동의했고, `batch` 대신 저장 순번 용어를 선택한 뒤 “그렇게해서 db관련 변경사항 적용해줘”라고 요청했다.
- 결정과 이유: 계정 생성 시각은 `account_created_at`으로 유지한다. 탈퇴 권한의 만료/사용 시각은 `login_sessions`에 포함하고 임시 제어/수명 행은 `transcript_session_states`로 합친다. 실제 저장은 `transcript_saves`에 두며 순번은 `save_sequence_number`, 지속 DB의 확정 위치는 `confirmed_save_sequence_number`다. 대상과 사건이 드러나는 컬럼명으로 로그인/학습 세션, 삭제 기한/탈퇴 확정/원문 삭제 완료를 구분한다. 현재 구현에서 필요 없는 임시 제어 행의 초기 순번/해시/payload는 제거한다.
- 대안·절충: 기존 분리는 권한 정리와 부모 삭제에 의한 원문 차단이 단순하지만 상태/식별자가 중복된다. 통합은 테이블·조인을 줄이지만 로그인 권한 컬럼의 독립 정리와 삭제 완료 상태의 저장 거절을 모든 경로에서 보장해야 한다. 원문까지 단일 JSON 행으로 합치면 저장 재작성과 부분 커밋 복구 계약을 다시 설계해야 하므로 채택하지 않는다.
- 보존 계약: 이메일 재확인·동일 브라우저·각 10분·일회성, 인증 효력 종료 후 24시간 내 정리, 원문 성공 즉시/최초 종료 후 최대 24시간 삭제, 별도 인스턴스·백업 제외는 유지한다. 원문 삭제는 상태 행을 잠그고 저장 행 삭제와 완료 기록을 같은 임시 트랜잭션으로 처리한다. 삭제된 상태에서는 저장하지 않으며 상태 행을 저장 요청에서 재생성하지 않는다. 백업 복원 시 로그인 세션 삭제로 통합 탈퇴 권한도 무효화한다.
- 이관·영향: 새 마이그레이션으로 기존 사용자/노트/권한·시각·원문 저장 순번/해시/확정 위치를 보존한다. 과거 미확인 시각은 NULL로 남긴다. 호스팅/서비스 추가·제품 보관 정책 변경은 없다. 테이블 감소의 성능·비용 이득은 미측정이며 SQL 이관과 인증/저장/삭제 경쟁 시험이 필요하다. 예약 실행기 전면 개편, delta 저장, 미확정 저장 덮어쓰기·메모리 소실 재개 복구 계약 변경은 이번 범위에 포함하지 않는다.
- 검증: 기존 데이터 이관, 동일 순번 재전송/다른 내용 거부, 임시 DB만 커밋된 재시도, 삭제/이력 원자성·중복 불변·늦은 저장 경쟁, 원래 브라우저의 탈퇴 권한·독립 정리·복원 무효화를 확인한다. 성능 및 전체 운영 기한 준수는 별도 검증이다.
- 대체 관계: DEC-020/036/046의 사용자 계약과 DEC-034/048의 데이터 경계를 유지하면서 저장 구조와 이름을 구체화한다. 현행 구조는 [design](../../design.md), 검토 과정은 [검토 제안](../proposals/database-schema-review-2026-10-25.md)을 따른다.
