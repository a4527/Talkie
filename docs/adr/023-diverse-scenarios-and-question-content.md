# ADR-023 · DEC-023 · 미경험 상황 우선과 질문 내용 반복 회피

- 결정일: 2026-10-21
- 상태: Accepted
- 동의 근거: 사용자는 최근 하지 않은 주제·표현과 지난번 어려웠던 표현을 넣고 나머지를 무작위로 보충하자고 제안했다. 최근 3회 기준은 “3회도 많이 겹칠것 같아. 최대한 다양한 상황에서의 회화가 목표라 길면 길수록 좋을 것 같아”라고 반대했다. 보관 중인 이력 전체에서 미경험 상황을 우선하고 후보가 부족하면 오래된 상황을 다시 활용하는 제안에 “그러자”라고 동의했으며, “똑같은 주제라도 내용만 달라지면 괜찮을 것 같아. 이전에 gpt에서 진행했을때는 질문이 완전 똑같이 나오더라고”라고 조건을 추가했다.
- 배경·기존 결정: DEC-008은 새 학습마다 현재 대화·짧은 학습 정보·관련 복습 기록만 AI에 전달하고 전체 이력 전송을 피한다. DEC-012/017/018은 보관 가능한 이력의 내용·기간을 정한다. PRD F-06은 주제와 질문의 다양성을 요구한다.
- 검토한 대안과 장단점: 최근 3회 또는 7일 회피는 구현·검증 범위가 작지만 오래 전에 반복한 질문을 놓칠 수 있다. 주제명만 중복 회피하면 같은 주제의 다른 상황까지 배제하며, 주제명만 달라도 질문 내용이 같은 문제를 잡지 못한다. 이력 전체를 AI에 전달하면 앱의 선택 로직은 단순하지만 누적 비용·지연·노출 데이터가 늘어 DEC-008과 충돌한다. 보관 중인 이력 전체를 앱에서 확인하되 선택한 소재와 필요한 반복 회피 정보만 전달하는 방식은 다양성을 지원하지만 상황·질문 의도를 식별하고 보관 기록에서 후보를 고르는 구현·평가 비용이 든다. 무작위만으로 고르면 예측하기 어렵지만 같은 질문이 반복되거나 어려운 표현 복습이 누락될 수 있다.
- 결정: 앱은 보관 중이며 접근 가능한 사용자의 학습 이력 전체를 후보 선택에 활용한다. 미경험 상황·대화 내용을 우선하고 같은 주제는 다른 상황·역할·목표·질문 내용이면 다시 사용할 수 있다. 후보가 부족하면 가장 오래전에 다룬 상황부터 활용하되 질문과 전개를 달리한다. 이전과 동일하거나 단어만 바꾼 질문의 불필요한 반복은 피한다. 덜 사용했거나 아직 연습하지 않은 표현을 우선하고 지난번 어려웠던 표현은 최근에 나왔더라도 새 상황에 자연스럽게 복습한다. 남는 선택은 이 조건을 만족하는 후보에서 무작위로 보충한다. 의도적인 복습·교정 재시도·인식 확인은 불필요한 반복과 구분한다. 제품 동작은 [PRD 4.1·5·7·9.2절](../../PRD.md#7-주제와-표현-정책)을 따른다.
- 이유: 사용자의 목표는 상황을 넓게 경험하는 것이고 실제 불편은 같은 질문이 다시 나오는 것이었다. 상황·질문 내용을 기준으로 선택하면 같은 큰 주제를 유용하게 다시 활용하면서 반복된 질문은 줄일 수 있다. 어려운 표현의 의도적인 재사용은 학습 목적에 맞춘다.
- 영향·비용·일정·사용자 경험·데이터·운영: 앱의 이력 조회와 후보 선택, 중복/유사 질문 평가, AI 프롬프트·평가 사례를 구현해야 한다. 이력이 많아질수록 선택 비용이 증가할 수 있어 지연과 비용을 측정한다. AI에는 선택된 짧은 맥락만 보내며 전체 원문 저장·전달 기간을 늘리지 않는다. 체험 기록 만료·회원 탈퇴로 삭제된 이력은 선택에 이용하지 않는다. 기록이 삭제되면 과거에 했던 질문을 기억해 회피하는 능력에도 한계가 있다. 주제 이름만으로 다양성을 보장하지 않으며 AI가 실제로 다른 질문을 하는지는 사례 평가가 필요하다.
- 검증: 식당 주문·주문 오류 해결·계산 나누기처럼 같은 주제의 다른 목표를 허용하고, 주제명이나 고유명사만 바꾼 같은 질문이 반복되는 사례를 확인한다. 미경험 후보가 남아 있을 때 우선 선택되는지, 후보 소진 후 오래된 상황이 다른 질문으로 재등장하는지, 지난번 어려운 표현이 새 상황에서 복습되는지, 삭제·만료 기록을 사용하지 않는지 확인한다. 앱의 후보 선택은 자동 테스트로, 실제 질문 다양성과 복습의 자연스러움은 고정 시나리오 AI 평가로 검증한다.
- 미확정 구현 상세: 상황·질문 의도를 기록에서 표현하는 방식, 의미상 같은 질문을 판정하는 기술과 허용 수준, 후보 목록·최근 어려움 판정·개수/비중·무작위 시드·컨텍스트 분량 상한은 해당 구현/평가 전에 정한다. 완전히 새로운 질문의 생성이나 의미상 중복 제로를 보장한 것은 아니다. 실제 측정·AI 평가·구현은 수행하지 않았다.
- 재검토 조건: 질문 반복 평가 결과, 후보 부족·선택 지연·비용 또는 복습 품질 저하가 확인되면 선택 기준과 비용·사용자 경험의 균형을 다시 논의한다.
- 대체 관계: DEC-008의 제한된 학습 맥락에서 앱의 이력 선택 기준을 구체화한다. DEC-008의 전체 이력 비전송과 DEC-012/017/018의 보관·삭제 범위는 유지한다.
