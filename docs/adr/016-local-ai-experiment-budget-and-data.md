# ADR-016 · DEC-016 · 로컬 AI 후보 실험 예산과 데이터·로그 범위

- 결정일: 2026-10-21
- 상태: Accepted
- 동의 근거: 총 3만 원·합성 대화와 본인 테스트 음성·앱 원본 음성 미저장·비용 중단 규칙을 제안했다. 사용자가 합성 대화와 로그 내용을 확인했고, 식별자·상태·시간·사용량·오류·저장/삭제 결과만 로그에 남기며 원문·음성·이메일·비밀값을 제외한다는 설명 후 “그렇게 결정하자”라고 동의했다.
- 배경·확정 제약·측정 근거: 로컬 실제 기능 구현 전 결정 계획의 1순위다. DEC-008의 서비스 부담 비용·서버 통제와 DEC-012의 학습 기록 정책을 유지한다. 가격·실험 비용·차단 효과 실측은 아직 없다. 금액은 지출 상한이며 실험 완료 비용 추정이 아니다.
- 검토한 대안과 장단점: 1만 원은 최대 지출을 줄이지만 비교 사례·반복 수를 줄일 수 있다. 3만 원은 제한된 초기 비교의 출발점이며 충분성은 단가·호출량 확인이 필요하다. 5만 원은 반복 여유가 있지만 최대 지출이 커지며 품질 향상을 보장하지 않는다. 합성 텍스트·합성 음성만 쓰면 본인 목소리 전달을 줄일 수 있지만 자연 발화 평가는 남는다. 본인 테스트 음성은 자연 발화·끼어들기를 확인할 수 있으나 공급자에게 목소리가 전달된다.
- 결정: PRD 8·9.1·9.2절의 최초 후보 비교 총 3만 원, 데이터·로그 범위와 집행 규칙을 채택한다. 합성 대화는 실제 사용자 기록이 아닌 가상의 테스트 대화다. 앱의 원본 음성 미저장은 이번 로컬 실험 범위이며 공급자 미보관 보장이 아니다. 전사문은 로그와 분리해 기존 임시 원문 정책을 따른다.
- 이유: 비교 지출과 외부 전달 데이터를 제한하면서 실제 음성 흐름 평가에 필요한 본인 발화를 사용할 수 있도록 한다. 내용 없는 진단 로그로 성능·오류·비용을 추적하고 대화 원문은 학습 기록 정책에서 관리한다.
- 영향·단점: D-03·V-05에 호출 전 비용 추정·예약·중단 검증이 필요하다. 반복 수가 예산으로 제한되고 공급자 청구 지연·추정 오차 때문에 실제 청구 한도를 보장했다고 볼 수 없다. 원문 없는 로그는 내용 관련 문제 재현을 제한한다. D-02의 공급자 처리 조건·전사문/평가 결과·로그 접근/보관 기간은 남아 있다. 공개 운영 비용과 클라우드 생성은 승인하지 않는다.
- 검증하지 못한 가정: 공급자·모델·단가·호출 수·시간/출력/재시도 한도 상세·비용 추정 정확도·데이터 보관 조건·음성 버퍼 수명은 미확정이다. 유료 호출은 해당 조건을 확인·합의한 뒤 예산 내에서 진행한다.
- 재검토 조건: 예산 안에서 필수 사례를 평가할 수 없거나 비용 상한 계산·로그 제한·공급자 처리 조건이 충족되지 않으면 실험을 중단하고 범위·예산·후보를 재논의한다.
- 대체 관계: DEC-008의 실험 예산·데이터 통제와 DEC-012의 음성 취급 방향을 로컬 실험에 구체화한다. 기존 결정을 대체하지 않는다.

후속 합의: 앱의 입력·출력 음성 버퍼와 공급자 모델 학습 금지·최대 30일 보관 정책은 [ADR-025](025-ephemeral-audio-and-provider-retention.md)로 확정했다. 위의 공급자 조건 미정 표현은 당시 상태이며, 실제 후보가 충족하는지는 아직 검증하지 않았다.

## 후속 상태 연결 (2026-10-21)

후보는 [ADR-029](029-compare-two-live-audio-candidates.md)의 두 곳, 경로는 [ADR-030](030-validate-direct-voice-path-first.md)의 직접 연결 우선 비교로 범위를 정했다. 위 후보 미정 표현은 당시 상태이며 최종 공급자·모델·경로 및 세부 평가 조건은 아직 미확정이다.
