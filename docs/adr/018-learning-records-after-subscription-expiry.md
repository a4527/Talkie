# ADR-018 · DEC-018 · 구독 만료 후 기존 유료 학습 기록 유지

- 결정일: 2026-10-21
- 상태: Accepted
- 동의 근거: 구독 만료 시 기록 유지·조회·다운로드, 재구독 시 기존 이력 활용, 사용자 삭제/탈퇴 시 삭제를 제안하고 휴면 사용자 비용 누적을 설명했다. 사용자가 “그렇게 하자”라고 명시적으로 동의했다.
- 배경·확정 제약·측정 근거: DEC-017에서 무료 체험 1개월·유료 기간 제한 없는 보관은 정했지만 구독 종료 후 처리는 미정이었다. 사용자가 구독 종료와 데이터 삭제의 연결에 이의를 제기했다. [논의와 출처](../proposals/mvp-preimplementation-decisions.md#구독-만료-후-기록-보존-재검토)를 참고하며 경쟁사 안내가 모든 데이터의 무기한 보존을 입증하지는 않는다.
- 검토한 대안과 장단점: 만료 후 30일 유예 뒤 무료 범위를 넘는 기록을 삭제하면 비용 누적을 제한하지만 복귀 시 이력이 사라지고 삭제 안내·유예 처리가 필요하다. 기존 기록 유지안은 재방문·재구독 시 연속성을 지키지만 이탈/휴면 계정의 저장·백업 비용이 누적된다. 30일 삭제안은 사용자 동의 없이 제안 단계에서 철회했다.
- 결정: 유료 이용 중 남긴 지속 학습 기록은 구독 만료만으로 삭제하지 않으며 사용자 삭제·탈퇴 전까지 보관한다. 만료 후 기존 기록 조회·다운로드를 허용하고 재구독 시 기존 이력을 이어서 활용한다. 추가 AI 학습·생성은 별도 이용 권한을 따른다. 무료 체험만 이용한 기록의 1개월 원칙과 DEC-012의 임시 전체 원문 삭제 규칙은 유지한다.
- 이유: 구독을 쉬더라도 기존 학습 성과와 재개 기반을 보존한다. 기존 기록 조회/다운로드와 추가 AI 처리 권한을 분리해 복귀 경험과 비용 통제를 함께 지원한다.
- 영향·단점: 현재 유료 여부만으로 기록 삭제 대상을 선정하면 안 된다. 보존 근거와 AI 이용 권한을 구분해 검증해야 한다. 비용 예측에 이탈·휴면 사용자와 유료 이용 기간의 누적 기록을 포함해야 한다. 단순 보관·조회 때문에 추가 AI 요약을 자동 실행하도록 합의한 것은 아니다. 인증·결제·DB·운영 공급자 선택은 미채택이다.
- 검증하지 못한 가정: 무료→유료 전환 시 기존 체험 기록 적용, 무료 보관 기산점·달력 기준, 사용자 삭제/탈퇴의 백업 처리·처리 기한, 통합 요약 정책·비용은 미정이다. 장기 데이터량·복귀율·저장 비용은 미측정이다.
- 재검토 조건: 누적 비용이나 제품 요구로 보존 정책 변경이 필요하면 기존 기록에 대한 영향을 논의하고 동의 후 새 결정으로 변경한다.
- 대체 관계: DEC-017의 미정 구독 종료 후 처리를 구체화한다. 무료 체험 기간·기존 유료 보관·DEC-012의 임시 원문 규칙은 대체하지 않는다.

- 후속으로 [ADR-017의 기산점·전환 합의](017-plan-based-learning-record-retention.md#2026-10-21-후속-합의--무료-기록의-기산점과-유료-전환)에서 무료 기록 30일 기산과 기한 전 전환 시 기존 체험 기록의 유료 보존 적용을 정했다. 해당 기록도 이 ADR의 만료 후 유지 원칙을 따른다.

- 후속 [DEC-019](../../DECISIONS.md#dec-019)에서 MVP 사용자 조작 삭제를 회원 탈퇴로 한정했다. 위 사용자 삭제/탈퇴 표현의 현재 기능 범위는 해당 ADR을 따른다.

## 후속 상태 연결 (2026-10-21)

탈퇴 데이터·백업 기한은 [ADR-021](021-scheduled-account-deletion-and-backup-deadlines.md), 인증 구현 책임은 [ADR-026](026-app-managed-email-link-authentication.md)으로 후속 구체화했다. 위 관련 미정 표현은 최초 결정 당시 상태이며 실제 기술·동작 검증은 남아 있다.
