# ADR-061 · DEC-061 · 경로별 사용량 정산과 대화 마무리

- 결정일: 2026-10-30
- 상태: Superseded by DEC-062
- 동의 근거: 사용자가 [다섯 항목 검토안](../proposals/API-USAGE-BUDGET.md#다음-결정-검토-집계경계안내)을 확인하고 “추천한대로 다 진행해”라고 명시적으로 동의했다. 추천 1A~5A의 채택이며 과거 Live 전용 $1.25 산정값이나 구체 한도 수치의 승인은 아니다.
- 배경: DEC-060은 시간 상한을 세션·구독 기간의 토큰 사용량 한도로 대체했으나, Live와 STT→LLM→TTS 분리형의 과금 항목이 달라 공통 집계·종료 경험·노트 보호 방식이 필요했다.
- 결정과 이유: 공급자/경로별 과금량을 종류별로 기록하고 단가를 반영한 정규화 사용량으로 세션·기간 한도를 차감하며 실제 청구와 대조한다(1A). 다음 AI 응답의 최대 예상량과 짧은 마무리분을 먼저 예약하고 부족하면 새 질문을 열지 않으며 확인된 발화의 교정/재시도를 가능한 범위에서 마치고 종료를 안내한다(2A). 기간 잔여량이 새 응답 예약에 부족하면 새 대화를 막되 진행·재개 중인 대화는 저장된 기록으로 정리하며 갱신까지 추가 AI 대화를 열지 않는다(3A). 대화 시작 때 별도 노트 예산을 예약하고 종료 후 정산하며 실패는 기존 기한과 정한 재시도 한도 안에서 명시한다(4A). 시작 전 이용 가능 상태·갱신일·사용량에 따른 변동을 보여주고 대화 중 마무리 단계를 알리며 실측 전 남은 분/횟수는 표시하지 않는다(5A). 현행 제품 동작은 [PRD 6절](../PRD.md#6-대화-상태와-예외)과 [9.2절](../PRD.md#92-ai-제공맥락이용량-정책), 집행 계약은 [음성 설계](../design/VOICE.md#사용량-집계와-집행-계약)를 따른다.
- 대안과 절충: 원시 토큰 1:1 합산은 단순하지만 경로/종류별 비용 차이를 반영하지 못한다. 즉시 생성·재생 차단은 비용 경계가 단순하지만 발화와 교정을 끊는다. 기간 소진 때 노트까지 중단하거나 종료 시에만 노트 예산을 확인하면 이미 한 학습의 결과를 잃을 수 있다. 항상 예상 시간/횟수를 표시하면 계획은 쉽지만 누적 맥락과 경로 차이로 오해를 줄 수 있다. 채택안은 원장·원자적 예약/정산·마무리 여유·공급자별 계측 때문에 구현과 운영 부담이 늘고 예약 오차만큼 사용량이 남거나 초과할 수 있다.
- 미정·재검토: 세션/기간/노트의 실제 수치, 정규화 환산 기준, 구독 기간 길이·갱신과 체험량, 응답/마무리 최대량, 재시도 횟수, 노트 모델은 실측과 후속 합의로 정한다. 두 경로에서 신뢰 가능한 사용량 보고와 연결 중 차단·청구 대조가 성립하는지 검증한다. 성립하지 않는 경로는 중계 등 집행 방식과 비용·지연을 재논의한다. 승인만으로 구현·공개 사용자 연결이 완료되지는 않는다.
- 관계: DEC-060의 한도 구조를 구체화한다. DEC-024의 외부 중단 후 24시간 재개·자동 종료, DEC-058의 별도 종료 노트·시험용 노트 자동 대체 금지, DEC-032의 진행 대화 하나를 유지한다.

2026-10-30 후속 합의: 사용자가 초기에는 공급자 과금량·단가를 기준으로 계산하고 운영 중 Talkie 자체 환산식을 조정하는 방향에 명시적으로 동의했다. 세션별 실제 청구액을 즉시 정확히 알아야 한도를 집행할 수 있다는 해석은 채택하지 않았다. 환산식 조정은 실제 청구·이용 패턴과의 대조를 근거로 버전과 적용 시점을 남겨 새 사용량에 적용한다. 공급자별 사용량 관찰과 전체 비용 대조는 계속 필요하며 직접 연결의 집행 오차는 별도로 검증한다. 현행 계약은 PRD 9.2절과 음성 설계를 따른다.

후속 상태: [DEC-062](062-TIME-BASED-VOICE-ALLOWANCE-AND-WEEKLY-COST-REVIEW.md)가 종류별 토큰 원장·응답/마무리/노트 예약과 환산식 집행을 대체했다. 주간 실제 비용 대조와 별도 노트 호출 제한이 현행 방향이며 위 문단은 당시 합의 기록이다. 현행 계약은 PRD 9.2절과 음성 설계를 따른다.
