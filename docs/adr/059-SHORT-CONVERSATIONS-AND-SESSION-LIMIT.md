# ADR-059 · DEC-059 · 짧은 회화 중심과 한 대화 시간 상한

- 결정일: 2026-10-29
- 상태: Accepted
- 동의 근거: 사용자가 “한 대화 최대 15분으로 두고 짧게짧게 진행하는 형태의 어플로 방향성을 잡으면 되지”라고 명시했다.
- 배경: 평균 10분을 초기 산정 가정으로 두고 종료 후 별도 요청에서 노트를 일괄 선별하기로 했다(DEC-058). 무제한 대화보다 짧은 연습을 자주 하는 경험이 제품 목표에 맞는지 논의했다.
- 결정과 이유: 한 대화에 시간 상한을 두고 종료 뒤 새 대화를 시작하는 구조를 채택한다. 장시간 연속 회화보다 짧게 자주 말하고 복습하는 경험을 제품 방향으로 삼기 위해서다. 현행 수치·종료 정책은 [PRD](../PRD.md#6-대화-상태와-예외)를 따른다.
- 대안과 절충: 권장 시간만 두면 사용자가 자유롭게 길게 대화할 수 있지만 짧은 세션이라는 제품 경험을 보장하지 못한다. 상한을 두면 진행 중인 주제·교정이 끝나기 전에 종료될 수 있어 사전 안내와 경계 처리가 필요하다.
- 영향·한계: 세션별 입력 규모와 노트 처리량을 관리하기 쉬워지지만 실제 토큰량·비용 상한을 보장하지 않는다. 새 대화를 반복할 수 있으므로 일일 비용 통제는 별개이며, 노트 생성 횟수는 늘 수 있다. 시간 집계의 중단/재개 처리·사전 안내·경계 발화 처리는 미정이며 구현 전에 구체화한다. 앱 구현·사용성/AI 품질·비용 검증은 후속이다.
- 대체 관계: DEC-003/024의 정상 연결 중 명시 종료 전까지 지속하는 범위에 시간 한도 종료를 추가한다. 외부 중단의 재개 기한과 종료 후 저장/노트·원문 삭제 계약은 유지한다.
- 재검토 조건: 발화/교정 중단이 학습을 방해하거나 실제 사용성·노트 품질에 문제가 확인되면 상한과 마무리 흐름을 재검토한다.
