# ADR-012 · DEC-012 · 전체 대화 임시 보관과 요약·학습 항목·원문 근거 보관

- 결정일: 2026-10-21
- 상태: Accepted
- 동의 근거: 사용자가 전체 대화 글을 임시 저장한 뒤 중요 항목을 추출하고 요약을 남기는 방식을 제안했다. 짧은 원문 근거를 함께 보관하는 대안과 한계를 논의한 뒤 “요약본이랑 원문 근거 저장하는거 좋을 것 같아”라고 동의했다.
- 후속 동의 근거: 세션 종료 후 요약·학습 항목·근거 저장 성공을 확인한 뒤 임시 전체 원문을 삭제하고, 실패하면 재시도를 위해 잠시 유지하되 최대 보관 기간은 별도로 정하자는 제안에 사용자가 “좋아”라고 동의했다.
- 배경·확정 제약: DEC-010은 앱 기록·복원 및 저장된 글을 입력으로 하는 종료 정리를 정했으나 기록 범위는 미정이었다. 노트·복습은 실제 대화에 근거해야 하고, 교정 대기 같은 진행 상태도 복원할 수 있어야 한다.
- 검토한 대안과 장단점:
  - 전체 대화 지속 보관: 추후 대화 맥락과 교정을 다시 확인하기 쉽지만 보관할 사용자 데이터가 늘어난다.
  - 전체 대화 임시 보관 후 요약·학습 항목만 보관: 장기 보관 범위는 줄지만 원문 삭제 후 교정 정확성을 재검증할 근거가 줄어든다.
  - 전체 대화 임시 보관 후 요약·학습 항목과 짧은 원문 근거 보관: 전체 대화 보관을 피하면서 일부 교정 근거를 남길 수 있다. 근거를 과다 선정하면 전체 보관과 차이가 줄고 짧은 근거에도 민감정보가 포함될 수 있다.
- 결정: 세 번째 방향을 채택한다. 전체 대화 글은 임시 저장하고, 추출된 대화 요약·중요 학습 항목과 필요한 짧은 원문 근거·교정문을 지속 기록으로 남긴다. 원문 전체를 지속 보관하는 방식은 채택하지 않는다. 원문 삭제 후에도 저장된 학습 항목과 근거 조각의 연결은 유지한다. 실제 재생되지 않은 AI 발화는 학습 근거에서 제외한다. 세션 종료 후 요약·학습 항목·근거의 저장 성공을 확인한 뒤 임시 전체 원문을 삭제한다. 추출 또는 저장 실패 시 재시도를 위해 원문을 임시 유지한다. 일시 중단은 종료와 구분하며 복원에 필요한 정보를 이 종료 후 정리 대상으로 취급하지 않는다.
- 이유: 장기 보관할 대화 범위를 줄이면서 노트와 복습의 근거를 일부 확인할 수 있게 하기 위해서다. 임시 원문과 선택된 근거는 목적과 수명이 다르다.
- 영향·단점:
  - 데이터·사용자 경험: 원문 전체 삭제 후 전체 맥락을 재조회·재검증할 수 없다. 근거 조각도 사용자 데이터이며 D-02의 접근·보관·삭제 정책 대상이다. 재개용 진행 상태는 별도로 보존·복원해야 한다. 저장 성공을 확인하기 전에 전체 원문을 삭제하지 않으며, 실패 시 유지에는 후속 합의의 세션 종료 후 최대 24시간 상한을 적용한다. 기한 경과 삭제 시 노트를 생성하지 못할 수 있다.
  - 비용·일정: 임시 원문과 지속 기록을 구분하고 추출·근거 연결·삭제 동작을 구현해야 한다. 실제 보관량·추출 비용·지연 감소는 미측정이다.
  - 운영·검증: 추출 결과의 실제 대화 근거, 원문 삭제 뒤 근거 조회, 재생 범위 정합성을 검증한다. 추출·저장 실패 시 원문 유지, 재시도 성공 후 정리, 삭제 실패 후 재처리에서 지속 기록과 근거가 유지되는지 검증한다. 보관 상한·기간 초과 처리는 후속 합의를 따른다. 재시도 및 삭제 실패 처리 상세는 추가 합의해야 한다. 공급자 보관은 앱의 원문 삭제와 별개로 확인한다.
  - 연결 요구사항/작업: PRD 8·11절, D-02, B-05/B-06, V-02/V-03 및 관련 설계·진행 현황에 반영한다. 작업 완료나 실제 데이터 저장 실행을 뜻하지 않는다.
- 후속 선별 합의 (2026-10-21): 사용자가 “종료 후 ai가 한 번에 선별”이라고 동의했다. 세션 종료 후 AI가 앱에 저장된 대화 글과 교정·재시도 기록을 한 번에 검토해 요약·학습 항목·원문 근거를 선별하고, 앱은 선택된 원문 근거의 실제 기록 존재를 확인해 저장한다. 대화 중 수시 선별은 당시 맥락을 활용하기 쉽지만 처리·판단이 자주 발생한다. 종료 후 선별은 전체 흐름의 반복 오류와 중요한 표현을 함께 검토하기에 적합해 채택했다. 종료 후 처리 지연·AI 비용과 추출 실패 재처리가 추가되며 실제 비용·지연·선별 품질은 미측정이다. 대화 중 교정 판단·진행 기록은 계속 수행한다. 원문 존재 확인만으로 학습 항목의 정확성·중요도가 보장되지는 않으므로 사례 평가로 검증·조정한다. 선별 기준·분량과 모델은 추가로 정한다. 기존 기록 범위·삭제 조건은 유지한다.
- 후속 선별 기준 합의 (2026-10-21): 사용자가 제안된 세 기준에 “그 기준 + 대화 중 ai 가 추천한 표현도 넣는게 좋을 것 같아”라고 동의했다. 사용자가 직접 질문한 표현, 반복해서 틀리거나 다시 말하기에 어려움을 보인 표현, 다음 대화에서 다시 활용할 핵심 표현, 대화 중 AI가 추천한 표현을 학습 항목 선별 기준으로 채택한다. 질문·어려움·재사용 가치와 함께 AI가 소개한 유용한 표현도 복습 대상으로 남기기 위해서다. 기존 실제 전달 범위 제약을 적용하며 추천 기록을 학습 성공으로 해석하지 않는다. 선정 항목이 많아질 수 있어 실제 품질·보관량을 평가하고 조정한다. 항목 수·분량·기준 간 우선순위와 선별 모델은 미정이다.
- 후속 보관 기한 합의 (2026-10-21): 사용자가 7일 제안을 길다고 지적하며 빠른 실패 해결과 짧은 보관을 선호했고, 캐시의 특성과 손실·운영 영향을 논의한 뒤 “하루정돈 유지하는게 좋아보이네 저장 성공하면 바로 삭제”라고 동의했다. 종료된 세션의 임시 전체 원문은 세션 종료 시점부터 최대 24시간 유지하며, 요약·학습 항목·원문 근거의 검증과 저장이 완료되면 즉시 삭제한다. 실패 시 그 기한 안에서 재시도하고, 재시도로 기한을 연장하지 않는다. 기한이 지나면 정리 성공 여부와 관계없이 임시 원문을 삭제하므로 미완성 노트의 재생성이 불가능할 수 있다. 즉시 삭제만 하면 일시 장애에서 복구하기 어렵고, 성공할 때까지 무기한 보관하면 임시 보관 목적을 벗어난다. 하루 상한은 복구 여유와 보관 제한을 절충한 초기 정책이며 비용·복구율은 미측정이다. 7일·10분 제안은 채택하지 않았다. 캐시 또는 DB 등 저장 기술은 선택하지 않았으며 일시 중단 세션의 재개 기한·공급자 보관·지속 기록 보관 기간도 이 합의로 정하지 않는다. 검증에는 성공 즉시 삭제, 실패 중 기한 경과 삭제, 재시도로 기한이 늘어나지 않는지와 삭제 실패 처리를 포함한다.
- 후속 결정: 저장 방식은 [DEC-013](../../DECISIONS.md#dec-013)의 주기적 묶음 저장으로 정했다. 구체 간격은 검증 후 조정한다.
- 미확정 범위: 저장 간격·묶음 크기 등 상세, 재시도 횟수·간격 및 삭제 실패 처리 상세, 캐시/DB 등 임시 저장 기술, 일시 중단 세션의 재개 기한, 요약·근거의 보관 기간, 선별 항목 수·분량 상한·기준 간 우선순위·선별 모델, 공급자 보관·삭제 조건, B-00 임시 기록 상세.
- 검증하지 못한 가정: 짧은 근거로 노트·복습의 적절성을 충분히 확인할 수 있는지, 근거 선정이 보관량을 실제로 줄이는지는 미확인이다.
- 재검토 조건: 평가에서 근거 부족·과다 보관·재개 실패·추출 실패 후 기록 손실 등이 확인되면 근거 선정과 수명 정책을 재검토한다. 전체 대화 지속 보관으로 변경하려면 다시 논의하고 동의를 받는다.
- 대체 관계: DEC-002의 사용자별 저장과 DEC-010의 앱 기록 원칙을 구체화하며 기존 채택 결정을 대체하지 않는다.

- 지속 학습 기록의 요금제별 보관 기간은 후속 [ADR-017](017-plan-based-learning-record-retention.md)에서 구체화했다. 이 ADR의 임시 전체 원문 보관 규칙은 유지한다.

- 외부 환경 중단 후 24시간 자동 종료는 [ADR-024](024-auto-close-interrupted-session-after-one-day.md)를 따른다. 자동 종료 시점부터 이 ADR의 임시 전체 원문 최대 24시간/성공 즉시 삭제 규칙이 적용되므로 두 기한은 별개다.

- 음성 원본의 앱 내 휘발성 처리와 공급자 모델 학습 금지·최대 30일 보관은 후속 [ADR-025](025-ephemeral-audio-and-provider-retention.md)를 따른다. 위의 공급자 보관 미정 표현은 당시 상태이며, 이 ADR의 앱 전사문 수명은 유지한다.

## 후속 상태 연결 (2026-10-21)

임시 전체 원문의 앱 복원용 백업 제외는 [DEC-027](../../DECISIONS.md#dec-027), 기한 작업의 지속 목록·정시 실행은 [ADR-028](028-durable-scheduled-work-list.md)로 구체화했다. B-00 임시 기록은 [ADR-015](015-nextjs-typescript-local-prototype.md)의 실행 중 세션 메모리 범위다. 위 미확정 목록은 각 후속 합의 전 당시 범위다.

## DEC-040 후속 합의 · 평가 자료 경계 (2026-10-23)

- 동의 근거: 사용자가 평가 자료의 추천안에 동의했다. 2026-10-23 문서 정리 승인에 따라 기존 ADR-040의 이 근거를 이곳으로 이관한다.
- 결정·대안·이유: 실제 발화·교정의 별도 평가 사본을 만들지 않고 합성 사례와 발화 내용 없는 평가 결과를 사용한다. 실제 사본은 상세 오답 재현에 유리하지만 접근·삭제 계약과 민감 자료 보관을 추가하므로 현재 범위에서 제외한다.
- 영향·검증: 사후 발화 분석이 제한된다. 평가 자료·결과에 발화 내용이 섞이지 않는지 확인하며 실제 구현·실험은 아직 없다. 평가 집계의 별도 저장 위치·수명은 미정이고 외부 평가·실제 사본이 필요해지면 재논의한다. 기존 학습용 원문·근거 보관 정책은 유지한다.
