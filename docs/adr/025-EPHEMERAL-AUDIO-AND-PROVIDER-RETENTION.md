# ADR-025 · DEC-025 · 임시 음성 처리와 공급자 보관 상한

- 결정일: 2026-10-21
- 상태: Partially Superseded · 비공개 로컬 합성·본인 음성 시험의 학습/보관 조건은 DEC-056으로 대체, 실제 사용자 정책과 앱 음성 미저장은 유지
- 동의 근거: 앱의 원본 음성 버퍼 처리 공통안과 공급자 A(처리 후 무보관)/B(모델 학습 금지·최대 30일 보관)/C(공급자 표준 조건)을 비교했다. 사용자는 모델 학습 허용의 비용·후보 확대 효과를 질문했고, 일부 계정·모델의 무료 사용량 혜택은 있지만 Talkie의 실시간 음성 할인이 확인되지 않았다는 공식 자료 검토를 받은 뒤 “b안하고 다음”이라고 명시했다.
- 배경·확정 제약: DEC-008은 원본 음성 기본 장기 미보관, DEC-016은 로컬 실험에서 앱의 파일·DB 미저장과 합성 대화·개발자 본인 음성을 정했다. DEC-012의 전체 대화 글 수명과 DEC-021의 앱 관리 데이터·백업 기한은 공급자 데이터에 자동 적용되지 않는다. 실제 공급자·모델·연결 경로는 아직 선택하지 않았다.
- 검토한 대안과 장단점:
  - A · 공급자 처리 후 음성·전사문 무보관: 외부 잔존을 가장 줄이지만 실시간 기능을 제공하는 적합 후보·가격은 미확인이고 선택·일정이 제한될 수 있다.
  - B · 모델 학습 금지, 공급자 보관 최대 30일: 후보 비교를 허용하면서 목적과 수명을 제한한다. 앱 삭제 뒤에도 공급자에 데이터가 남을 수 있으며 계약·설정·예외 확인과 사용자 고지가 필요하다.
  - C · 공급자 표준 조건을 후보 선정 뒤 수용: 후보 폭이 넓을 수 있지만 외부 보관 기간을 사전에 정하지 못한다.
- 결정: 로컬 실험과 실제 제품의 입력·출력 음성은 전송·재생에 필요한 동안만 앱의 휘발성 버퍼에서 처리한다. 완료·취소·연결 종료 후 불필요한 버퍼를 해제하고 원본 음성을 앱의 파일·DB·진단 로그·오류 본문·백업에 저장하지 않는다. 재연결·노트 생성은 확인된 전사문과 진행 상태를 사용하며 음성 원본을 복구하지 않는다. 공급자에게 전달되는 음성·전사문과 관련 입력·출력은 모델 학습에 사용하지 않으며 보관은 최대 30일로 제한하는 B안을 채택한다. 실제 계약·설정에서 해당 조건을 확인하지 못한 후보에는 음성을 전달하지 않는다. 학습 허용을 통한 무료 사용량·할인은 기본 정책에 포함하지 않는다.
- 이유: 사용자 음성을 외부 모델 학습에 제공하는 데이터 영향을 피하면서 실시간 후보 비교의 여지를 두기 위해서다. 확인되지 않은 할인 혜택을 제품 데이터 정책의 근거로 사용하지 않는다.
- 비용·일정·사용자 경험·데이터·운영 영향: 앱은 음성 재생/전송 중 버퍼 수명과 중단·오류 경로를 검증해야 하고 녹음 재생/원본 복원은 제공하지 않는다. 30일 상한을 충족하는 후보가 없으면 실제 음성 통합이 지연되고 정책을 다시 논의해야 한다. 공급자에 최대 30일 데이터가 남을 수 있으므로 앱 탈퇴 후 24시간 서비스 데이터 삭제·7일 백업 기한과 차이를 사용자에게 고지한다. 학습 금지와 보관 상한을 제공하는 계약·기능·가격은 아직 확인하지 않았으며 지출·품질 영향도 미측정이다. 버퍼 해제는 이미 전송된 공급자 데이터나 브라우저·운영체제의 통제 밖 임시 처리를 삭제한다는 뜻이 아니다.
- 검증 범위: 후보별 공식 계약·문서·계정 설정에서 음성·전사문·관련 입력/출력의 모델 학습 사용, 보관 기산점·상한·예외, 접근 주체·하위 처리자·처리 지역·탈퇴 시 삭제 지원을 확인한다. 상한 예외나 대상 범위가 조건과 충돌하면 음성 호출 전에 재논의한다. 앱에서는 정상 완료·끼어들기·연결 중단·오류 후 버퍼 해제와 파일·DB·로그·오류 본문·백업에 음성이 남지 않는지 검증한다. 로컬 실험 데이터는 DEC-016 범위를 지킨다. 실제 공급자 확인이나 음성 호출은 아직 수행하지 않았다.
- 남은 상세: 공급자 후보·실제 가격·삭제 요청 방식, 앱 관리 전사문·평가 결과의 실험 수명, 진단 로그 접근/보관 기간, 체험 만료·임시 원문의 백업 처리, 인증·삭제 실행 기술은 D-02/D-03에서 정한다.
- 재검토 조건: 후보가 학습 금지 또는 30일 상한을 지원하지 않거나, 실시간 품질·비용·지연 평가에서 통과하지 못하면 대안·영향을 다시 논의한다.
- 대체 관계: DEC-008의 원본 음성 방향과 DEC-016의 로컬 실험 범위를 실제 제품·공급자 조건으로 구체화한다. DEC-012/021의 앱 관리 데이터 수명은 변경하지 않는다.

## 후속 상태 연결 (2026-10-21)

앱 인증·임시 원문 백업·작업 실행 방향은 [ADR-026](026-APP-MANAGED-EMAIL-LINK-AUTHENTICATION.md)·[DEC-027](../DECISIONS.md#dec-027)·[ADR-028](028-DURABLE-SCHEDULED-WORK-LIST.md), 비교 후보·경로 범위는 [DEC-029](../DECISIONS.md#dec-029)·[DEC-030](../DECISIONS.md#dec-030)으로 정했다. 위 관련 미정 표현은 당시 상태다. 후보의 실제 계약·가격·정책 충족과 최종 공급자·모델·경로는 미검증·미채택이다.

## 후속 상태 연결 (2026-10-26)

[DEC-052](../DECISIONS.md#dec-052)로 보관 일수를 확인하지 못한 후보도 합성 대화·개발자 본인 음성 실험에 한해 학습 금지를 확인하면 시험할 수 있게 했다. 이 결정의 학습 금지·최대 30일 상한은 바꾸지 않았으며 실제 사용자 음성에는 그대로 적용한다. Gemini Developer API의 악용 감시 로그 55일 등 보관 상한 충돌은 측정 후 완화 여부를 별도로 논의한다.

## 후속 상태 연결 (2026-10-27)

[DEC-056](../DECISIONS.md#dec-056)이 개인정보 없는 합성·개발자 본인 음성의 비공개 로컬 시험에 한해 학습 사용·표준 보관을 허용한다. 실제 사용자 대상의 학습 금지·최대 30일과 앱 음성 미저장은 유지한다.
