# ADR-001 · DEC-001 · 제품 형태는 반응형 웹서비스

이 문서는 2026-10-20에 기존 결정 원문을 ADR로 옮긴 기록이다. 결정일·승인 근거·당시 비교 범위는 유지했다. 기존에 기록되지 않은 대안이나 실측 결과를 소급해 추가하지 않는다. 현재 구조는 [design.md](../../design.md), 상태와 대체 관계는 [결정 목록](../../DECISIONS.md)을 참고한다. 초기 기록에 상세 대안 비교가 없으며 이는 기록의 한계다.

- 결정일: 2026-10-15
- 상태: Accepted
- 근거: 사용자 지시
- 배경: 초기 계획은 영어 회화 앱을 가정했으나 사용자가 웹서비스를 원한다고 명확히 했다.
- 결정: 모바일과 PC 브라우저에서 이용할 수 있는 반응형 웹서비스로 설계한다.
- 이유: 사용자가 지정한 제품 형태를 반영한다.
- 영향: 경쟁 앱의 학습 흐름을 조사하되 화면과 조작 방식은 웹에 맞게 새로 설계한다. 네이티브 앱 출시 작업은 현재 범위에 넣지 않는다.
- 대체 관계: 없음
