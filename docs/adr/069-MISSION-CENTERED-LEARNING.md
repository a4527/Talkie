# ADR-069 · 미션 중심 학습과 수행 평가·횟수 이용량

- 결정일: 2026-11-03
- 상태: Partially Superseded · 구현 전
- 후속: [DEC-072](../DECISIONS.md#dec-072)가 당시 언어 영역별 배점을 대체한다. 목표 60/언어 40과 나머지 방향은 유지하며 현행 기준은 PRD를 따른다.
- 동의 근거: 사용자가 자유 대화 대신 미션 중심 전환, 긴 상황 허용, 기본/AI/사용자 지정, 목표별 이진 채점과 언어 품질, 현재 배점, 난이도 확장 구조, 연습 무감점, 상대역 마무리 후 종료, 연결 성립 차감·24시간 미재개 차감 유지와 일수 제외에 순차 동의했다. 80% 이상 일수 인정과 당일 다른 인정 미션의 기록 유지도 명시했다. 이후 기존 문서 최신화·정합성 점검·커밋을 요청했다.

## 배경과 선택 이유

범용 자유 대화와 차별화하려면 사용자가 실제 해결할 상황과 결과를 중심으로 학습 경험을 구성할 필요가 있다. 단순 의도 전달만으로 높은 평가를 주지 않고 수준에 맞는 명확성·자연스러움도 평가한다. 직접 제작의 일관성과 생성의 다양성을 결합하고, 긴 상황을 강제 분할하지 않는다.

연습 도움을 감점하면 연습 목적과 충돌하므로 모드 조건을 별도로 남긴다. 이용량은 미션 연결 시 차감해 진행 중 계정 잔여량 소진으로 끊기는 경험을 피한다. 달성 일수는 평가 기준을 충족한 수행을 인정하되 재개 기한을 넘긴 미완료는 제외한다. 현행 상세 정책은 [PRD](../PRD.md#4-주요-사용자-흐름), 구현 계약은 [미션 설계](../design/MISSIONS.md)에 둔다.

## 대안과 영향

자유 대화 유지안은 범위가 작지만 분명한 완료·차별화가 약하다. 모든 상황을 짧게 분할하면 비용 예측은 쉬워져도 복잡한 리허설 수요를 제한한다. 모든 평가표를 매번 생성하면 다양하지만 일관성과 검증이 어려워 사전 기준·검증된 구조를 재사용한다. 미션 차감은 비용 편차·장애 차감 복구·동시성 처리 부담이 있으며 평균 시간만으로 비용을 보장하지 않는다.

로그인·공급자·분리형 음성·저장/원문 수명은 유지한다. 새 보상 경제나 경품·소셜 기능은 승인하지 않았고 초기 보상 범위는 일수만이다. 실전 차등 보상은 후보다. 단계 수·루브릭·자동 생성 품질·무진전 임계값·환급 예외·횟수 단위·일수 날짜는 미정이며 실측 후 구체화한다.

## 대체 관계와 재검토

DEC-003/011의 자유 대화 지속·단일 즉시 교정, DEC-023의 자동 소재 선택 강제 범위, DEC-040의 종료 제한, DEC-059의 짧은 세션 전제, DEC-062/063 및 DEC-064의 시간 이용권 집행 부분을 대체한다. DEC-010의 AI 판단/앱 기록 경계, DEC-024/031/032의 중단·저장·진행 대화 제한, DEC-062의 주간 비용 대조·지출 보호, DEC-058/064/065의 종료 선별·호출 보호는 유지한다. 평가 품질·원가 분산·연결 차감 관측에 문제가 있으면 구체 설계를 재검토한다. 역사적 ADR 본문은 당시 근거로 보존한다.
