# ADR-003 · DEC-003 · 대화 흐름의 핵심 규칙

이 문서는 2026-10-20에 기존 결정 원문을 ADR로 옮긴 기록이다. 결정일·승인 근거·당시 비교 범위는 유지했다. 기존에 기록되지 않은 대안이나 실측 결과를 소급해 추가하지 않는다. 현재 구조는 [DESIGN.md](../DESIGN.md), 상태와 대체 관계는 [결정 목록](../DECISIONS.md)을 참고한다. 초기 기록에 상세 대안 비교가 없으며 이는 기록의 한계다.

- 결정일: 2026-10-15
- 상태: Partially Superseded (명시적 종료만 허용한 부분은 DEC-024 예외로 대체)
- 근거: 사용자가 제공한 튜터 요구사항
- 배경: 자연스러운 회화와 적극적인 표현 개선을 함께 제공해야 한다.
- 결정: 영어 중심으로 한 번에 질문 하나를 하고, 사용자의 명시적 종료 전까지 대화를 이어간다. 교정이나 새 표현 소개 뒤에는 영어로 다시 말하기를 기다린다. 종료 요약은 실제 대화에만 근거한다.
- 이유: 학습자가 직접 말하고 고친 표현을 즉시 사용하도록 하기 위해서다.
- 영향: 구현 시 대화 상태 관리와 실제 발화에 연결된 교정 기록이 필요하다.
- 대체 관계: 명시 종료만 허용한 부분은 후속 [ADR-024](024-AUTO-CLOSE-INTERRUPTED-SESSION-AFTER-ONE-DAY.md)로 대체. 다른 규칙은 유지한다.

## 후속 결정 (2026-10-21)

사용자의 명시적 종료를 기본으로 유지하되, 외부 환경으로 중단된 뒤 24시간 재개되지 않은 세션의 자동 종료·노트 생성 예외가 [ADR-024](024-AUTO-CLOSE-INTERRUPTED-SESSION-AFTER-ONE-DAY.md)로 채택됐다. 이 문서의 명시 종료만 허용한 부분은 Partially Superseded이며 다른 대화·교정 규칙은 유지한다.
