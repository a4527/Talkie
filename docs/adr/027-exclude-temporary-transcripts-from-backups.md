# ADR-027 · DEC-027 · 임시 전체 대화 글의 복원용 백업 제외

- 결정일: 2026-10-21
- 상태: Accepted
- 동의 근거: 임시 원문 백업 제외(A), 일반 백업 포함(B), 모든 기록의 백업 생략(C)을 비교한 뒤 사용자가 `2-a`를 선택했다.
- 배경: DEC-012는 종료 후 임시 전체 원문을 성공 즉시, 늦어도 24시간 안에 삭제한다. DEC-021은 탈퇴 데이터의 백업 기한을 정하지만 일반 세션의 임시 원문 백업 처리까지 정하지 않았다.
- 대안: A는 삭제된 전체 원문의 복원 위험을 줄이지만 별도 임시 저장이나 백업 제외 설정이 필요하다. B는 장애 복원 범위가 넓어지는 대신 앱에서 삭제한 원문이 백업에 남을 수 있다. C는 단순하지만 지속 노트와 계정 기록의 장애 복구 능력도 잃는다.
- 결정과 이유: A를 채택한다. 앱이 관리하는 복원용 백업·스냅샷에 임시 전체 대화 글을 포함하지 않는다. 24시간 삭제 정책과 복원 결과를 일치시키기 위해서다. 요약·학습 항목·짧은 근거 등 지속 기록의 백업 정책을 없애지 않는다.
- 영향: 임시 저장 계층의 분리 또는 백업 제외를 지원하는 구성이 필요해 저장 설계와 운영 검증 비용이 증가한다. 장애 후 마지막 지속 저장 이후의 임시 대화는 복구하지 못할 수 있으며 노트 완성이 실패할 수 있다. 사용자에게 이 복원 한계를 안내해야 한다. 저장 공급자의 내부 복제·백업은 기능과 계약을 확인해야 하며 현재 제외를 보장하지 않는다.
- 검증: 실제 백업·복원 테스트에서 임시 원문이 나타나지 않는지, 지속 기록과 탈퇴 삭제 상태는 필요한 범위에서 복원되는지 확인한다. 정상·실패·만료 경로의 삭제와 재시도 기한을 확인한다. 기술 선택·구현·복원 테스트는 아직 없다.
- 재검토 조건: 후보 저장 기술이 제외를 지원하지 않거나 복원 한계가 핵심 사용자 경험을 해치면 저장 방식과 비용을 다시 비교한다.
