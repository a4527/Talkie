# ADR-004 · DEC-004 · 경쟁 서비스 분석의 증거 기준

이 문서는 2026-10-20에 기존 결정 원문을 ADR로 옮긴 기록이다. 결정일·승인 근거·당시 비교 범위는 유지했다. 기존에 기록되지 않은 대안이나 실측 결과를 소급해 추가하지 않는다. 현재 구조는 [design.md](../../design.md), 상태와 대체 관계는 [결정 목록](../../DECISIONS.md)을 참고한다. 초기 기록에 상세 대안 비교가 없으며 이는 기록의 한계다.

- 결정일: 2026-10-15
- 상태: Superseded
- 근거: REA를 활용하라는 사용자 요청과 조사 범위
- 배경: 공개 홍보 자료, 패키지 정적 분석, 실제 실행 관찰은 확인할 수 있는 범위가 다르다.
- 결정: 경쟁 서비스의 관찰·추정·미확인을 구분하고 REA 결과에는 대상 버전과 Evidence ID를 기록한다.
- 이유: 확인하지 못한 유료 기능이나 서버 동작을 구현 사실로 오해하지 않도록 하기 위해서다.
- 영향: 비교표와 제품 요구사항에는 각 주장에 맞는 출처와 조사 한계를 남긴다.
- 대체 관계: [DEC-006 / ADR-006](006-prototype-first.md)에 의해 대체됨
