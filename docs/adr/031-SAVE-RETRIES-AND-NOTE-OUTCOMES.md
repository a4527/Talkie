# ADR-031 · DEC-031 · 저장 실패 누적 재시도와 재개·노트 처리

- 결정일: 2026-10-23
- 상태: Accepted
- 동의 근거: 사용자는 재개 확인 없이 즉시 재개(2A), 종료 후 노트 정리 중 표시(3B), 노트 자동 재시도만 제공(4A), 근거 검증 실패 항목을 제외한 부분 노트 저장(5A)을 선택했다. 이어 주기적 저장 성공·실패를 표시하고 실패 분량을 다음 주기에 함께 저장하자고 제안했다.
- 배경: DEC-013의 주기적 묶음 저장과 메모리 손실 한계, DEC-012의 근거 검증·종료 후 최대 24시간 원문 보관, DEC-028의 지속 작업 목록을 유지하며 미정 실패 동작을 구체화한다.
- 대안·이유: 저장 실패 시 대화를 멈추면 미저장 분량 증가를 줄이지만 학습이 끊긴다. 계속 대화하면서 다음 저장에 실패 분량을 포함하면 흐름을 유지하지만 메모리 손실 위험이 커진다. 사용자는 후자를 선택했다. 재개 전 확인 화면은 복원 범위를 설명할 수 있지만 한 동작이 늘어 즉시 재개를 선택했다. 노트 완성을 기다리게 하는 대신 종료와 생성을 분리한다. 수동 재시도는 즉시 요청할 수 있지만 중복 호출 제어·화면 구현이 늘어 자동 재시도만 제공한다. 한 항목 때문에 노트 전체를 실패시키는 대신 검증된 부분을 남겨 유용한 결과를 보존하고 추가 호출을 줄인다.
- 결정: 주기적 저장 성공·실패를 표시하고 대화를 계속한다. 성공 미확인 기록을 메모리에 유지하고 다음 주기에 새 기록과 함께 재시도한다. 재개는 별도 확인 화면 없이 저장된 마지막 확인 턴·상태에서 바로 수행한다. 종료 후 노트는 정리 중으로 표시하고 사용자는 떠날 수 있다. 노트 실패는 기한 내 자동 재시도만 제공한다. 근거 검증 실패 항목을 제외하고 나머지를 저장하며 누락을 표시한다. 유효한 내용이 없으면 실패, 사용자 발화가 없으면 빈 노트 없이 정리한다.
- 정합성·삭제: 재전송은 중복·순서·진행 상태 불일치를 만들지 않아야 한다. 부분 노트도 검증·저장 완료 시 임시 원문을 즉시 삭제하고 누락 항목 추가 생성은 보장하지 않는다. 재시도는 최초 기한을 연장하거나 탈퇴·만료 기록을 되살리지 않는다.
- 영향: 저장 상태 표시·미확인 기록 버퍼·중복 방지·비동기 노트 상태와 부분 결과 검증의 구현 및 시험이 추가된다. 저장 실패가 이어지면 메모리 사용과 유실 위험이 커진다. 저장/AI 재시도 비용은 미측정이며 비용 통제는 유지한다. 전체 원문 보관·음성 미저장·백업 제외 정책은 확대하지 않는다.
- 미확정·미검증: 저장 간격·묶음 크기·버퍼 상한·상한 도달 시 기록 유지/포기 규칙, 노트 재시도 횟수·간격·공급자 비용 및 실제 복원 동작은 아직 검증하지 않았다. 부분 노트의 학습 유용성은 별도 AI 평가 대상이다.
- 검증: 실패 다음 주기 누적 저장, 응답 유실 뒤 재전송, 새 기록이 생기는 동안의 저장 응답, 지속 실패·메모리 손실, 바로 재개, 화면 이탈 후 노트 처리, 기한 내 자동 재시도, 일부/전체 근거 검증 실패 및 부분 노트 완료 후 원문 삭제를 확인한다.
- 재검토 조건: 장기 실패의 메모리 증가·유실 또는 부분 노트 누락이 허용하기 어려우면 후속 대응을 논의한다.
- 대체 관계: DEC-012/013/024/028의 미정 동작 구체화. 기존 채택 결정을 대체하지 않는다.
- 연결: PRD 6·8절, DESIGN.md, B-02/B-05/B-06. B-00 범위를 확대하거나 구현 완료를 뜻하지 않는다.

## DEC-040 후속 합의 · 장기 저장 실패에도 대화 지속 (2026-10-23)

- 동의 근거: 사용자가 “대화 진행이 더 중요”, “멈추지말고”, “실패하는걸로 두자”라고 하며 일시정지를 거부하고 반복 실패를 줄이는 구현을 요청했다. 2026-10-23 문서 정리 승인에 따라 기존 ADR-040의 이 근거를 이곳으로 이관한다.
- 결정·절충: 저장 실패가 지속돼도 대화를 정지하지 않고 기존 누적 재시도·실패 표시를 유지한다. 일시정지는 메모리·유실 증가를 줄이지만 대화 연속성을 우선해 장기 실패 시 기록 유실 위험을 수용한다. 실패를 숨기거나 성공으로 표시하지 않는다.
- 영향·검증: 저장 처리를 음성 진행과 분리하고 DB 연결·트랜잭션·재시도의 반복 실패 원인을 진단·개선한다. 중복·응답 유실·일시/지속 장애·복구에서 대화 지속과 기록 정합성을 확인한다. 구현·실험은 아직 없으며 버퍼 상한·도달 시 유지/포기 규칙은 미정이다. 무제한 누적·자동 폐기·저장 무실패를 약속하지 않는다.
- 재검토·연결: 버퍼 자원·유실이 감당하기 어려우면 재논의한다. DEC-032의 종료 후 저장 대기와 기존 삭제 기한은 유지하며 PRD 4.4·8절, B-05/B-06의 수용 기준을 따른다.

## 버퍼 상한 후속 (2026-10-23)

[DEC-047](047-RETAIN-RECENT-UNSAVED-RECORDS-AT-BUFFER-LIMIT.md)로 최근 완결 미저장 기록 우선 유지·오래된 미저장 단위 제거·누락 표시를 합의했다. 앞의 상한 도달 시 유지/포기 미정은 합의 전 상태이며 상한 수치·큰 단위 처리·저장/복원 정합성과 실제 장애 시험은 남는다.
