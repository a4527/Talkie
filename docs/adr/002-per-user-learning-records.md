# ADR-002 · DEC-002 · 학습 이력은 사용자별 별도 저장소가 기준

이 문서는 2026-10-20에 기존 결정 원문을 ADR로 옮긴 기록이다. 결정일·승인 근거·당시 비교 범위는 유지했다. 기존에 기록되지 않은 대안이나 실측 결과를 소급해 추가하지 않는다. 현재 구조는 [design.md](../../design.md), 상태와 대체 관계는 [결정 목록](../../DECISIONS.md)을 참고한다. 초기 기록에 상세 대안 비교가 없으며 이는 기록의 한계다.

- 결정일: 2026-10-15
- 상태: Accepted
- 근거: 사용자 지시
- 배경: 웹서비스 전환 후 학습 내용을 별도로 저장하기로 했다.
- 결정: 계정별 대화·표현·교정·복습 이력을 서비스의 별도 저장소에 보관한다. 날짜별 Markdown 파일은 다운로드용 내보내기로 제공한다.
- 이유: 다음 대화에서 실제 기록을 활용하고 기기 간 학습을 이어가기 위해서다.
- 영향: 인증, 계정별 접근 제어, 기록 조회·삭제, 보관 정책 설계가 필요하다. 저장소 제품과 세부 보관 기간은 아직 미결정이다.
- 대체 관계: 없음

## 후속 상태 연결 (2026-10-21)

현재 보관·탈퇴 범위는 [ADR-017](017-plan-based-learning-record-retention.md)~[ADR-021](021-scheduled-account-deletion-and-backup-deadlines.md), 임시 원문 백업 제외는 [ADR-027](027-exclude-temporary-transcripts-from-backups.md)을 따른다. 위 저장소·기간 미정 표현은 최초 결정 당시 상태다.
