# ADR-030 · DEC-030 · 음성 직접 연결 경로 우선 검증

- 결정일: 2026-10-21
- 상태: Accepted (검증 순서)
- 동의 근거: 브라우저 직접 연결(A), 서버 음성 중계(B), 직접 연결 후 필요하면 중계 비교(C)를 제시했고 사용자가 `5-c`를 선택했다.
- 배경: DEC-008은 서버 측 비밀값 관리, DEC-016은 비용 상한, DEC-025는 음성 처리·공급자 조건을 정했다. 최종 연결 경로는 미정이다.
- 대안: A는 서버 중계 부하를 줄일 수 있지만 사용량 통제·재생 범위·취소·기록 동기화를 검증해야 한다. B는 서버 통제 지점을 제공하지만 스트리밍 구현·서버 지연·전송비가 증가할 수 있다. C는 순차 검증으로 두 경로의 필요성을 판단하지만 비교 일정이 늘 수 있다.
- 결정과 이유: C를 채택한다. 적합 후보별로 서버가 짧은 수명의 연결 자격을 발급하는 브라우저 직접 경로를 먼저 확인하고, 비용·사용량 차단·취소·실제 재생 범위·기록 동기화가 충족되지 않으면 서버 중계를 비교한다. 영구 공급자 비밀키를 브라우저에 전달하지 않는다. 최종 경로의 채택은 실험 결과와 후속 동의를 따른다.
- 영향: 브라우저 권한·연결 실패·재발급·종료/탈퇴 직후 차단, 서버의 예산·동시 연결 제한을 검증해야 한다. 중계가 필요하면 대역폭·지연·운영비가 추가될 수 있다. 직접 경로가 요구를 만족한다는 근거는 아직 없다.
- 검증: 같은 시나리오에서 끼어들기 지연, 늦은 생성/재생 차단, 확인된 전사문과 학습 상태의 정합성, 비밀값 노출, 사용자별·전체 비용 제한을 측정한다. 특정 공급자 경로를 최종 채택하지 않았다.
