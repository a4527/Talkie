# ADR-008 · DEC-008 · 서비스 부담의 실시간 음성 AI와 제한된 학습 맥락

이 문서는 2026-10-20에 기존 결정 원문을 ADR로 옮긴 기록이다. 결정일·승인 근거·당시 비교 범위는 유지했다. 기존에 기록되지 않은 대안이나 실측 결과를 소급해 추가하지 않는다. 현재 구조는 [DESIGN.md](../DESIGN.md), 상태와 대체 관계는 [결정 목록](../DECISIONS.md)을 참고한다. 학습 상태 책임 부분은 2026-10-21 [ADR-010](010-AI-LED-LEARNING-APP-RECORDS.md)으로 대체·구체화했다. 아래 본문은 당시 결정 원문이며, 그 밖의 결정은 유지한다.

- 결정일: 2026-10-16
- 상태: Partially Superseded (학습 상태 책임만 DEC-010으로 대체)
- 동의 근거: AI 사용의 9가지 쟁점과 대안을 논의한 뒤 사용자가 각 항목의 정리된 방향을 표로 명시했다. 단계별 음성 처리 추천 대신 실시간 음성 대화를 선택했다.
- 배경: 일반 고객의 시작 부담을 줄이면서 자연스러운 음성 대화, 학습 품질, 누적 기록의 비용 및 서비스 확장을 함께 관리해야 한다.
- 검토한 대안과 장단점: 고객 API 키 연결은 서비스의 AI 비용 부담을 줄이지만 고객 설정 부담이 크다. ChatGPT 구독 연결은 지원 범위·음성 제약 확인이 필요하다. 서비스 API 제공은 시작이 쉽지만 비용과 한도 관리 책임이 있다. 단계별 음성 처리는 중간 텍스트와 교정을 제어하기 쉽지만 대화 대기가 생길 수 있다. 실시간 음성은 끼어들기 경험에 유리하지만 취소·재생 범위·기록 동기화 검증이 추가된다. 전체 이력 전달은 구현이 단순하지만 비용·지연이 늘고, 선택된 맥락은 분량을 통제하지만 누락·요약 품질 검증이 필요하다.
- 결정: Talkie가 API와 비용을 부담하고 초기 고객 키·구독 연결을 제외한다. 실시간 음성을 채택해 끼어들기·재생 및 생성 중단·사용자 발화 전환을 우선 검증한다. 초기 공급자는 하나로 단순화하되 역할별 모델 분리는 허용한다. 학습마다 새 세션을 만들고 현재 대화·짧은 학습 정보·관련 복습 기록만 활용한다. 고객별 연결·기록·접근을 분리하며 키는 서버에서 관리한다. 원본 음성은 기본 장기 보관하지 않는다. 앱이 학습 상태를 관리하고 AI가 대화·교정을 맡는다. 불확실한 교정은 확인·보류하며, 복구와 노트는 확인된 대화 범위를 기준으로 한다. 무료 체험·이용량 제한 요금제를 지향하고 서버의 사용자별·전체 비용 제한과 단계적 용량 확장을 적용한다.
- 채택 이유: 고객의 설정 부담 없이 대화의 자연스러움을 우선 검증하면서 누적 이력·비용·접근 및 복구 상태를 앱에서 관리한다. 세부 동작의 기준은 PRD 4·6·8·9.2절에 둔다.
- 영향: 실시간 취소·재생 범위·동시 연결 검증으로 구현 및 테스트 시간이 추가된다. 10분 세션·사용자별 월 비용과 응답·중단 지연·끊김을 측정해야 한다. 실제 공급자·모델·연결 기술, 가격·포함량·제한값·테스트 예산, 전사문·교정 및 공급자 보관·삭제 정책은 미확정이다. D-03은 방향 합의만 진행됐으며 테스트와 최종 선택 전에는 완료 처리하지 않는다. D-02·D-05와 B-02/B-09 및 관련 검증 기준에 반영한다. DEC-006의 가짜 응답 텍스트 프로토타입 선행 순서는 유지한다.
- 대체 관계: DEC-002·DEC-003·DEC-006·DEC-007을 구체화한다. 학습 상태 책임 부분은 [ADR-010](010-AI-LED-LEARNING-APP-RECORDS.md)으로 대체됐으며 나머지는 유지한다.
