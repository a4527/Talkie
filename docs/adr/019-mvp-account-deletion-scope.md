# ADR-019 · DEC-019 · MVP 삭제 기능은 회원 탈퇴로 한정

- 결정일: 2026-10-21
- 상태: Accepted
- 동의 근거: 세션별 삭제·전체 학습 기록 삭제·회원 탈퇴 제공안을 제안하자 사용자는 “굳이? 회원탈퇴하면 다 삭제하고 아니면 그대로 남겨두는거지. 체험판 같은 경우는 한달 뒤에 학습기록 삭제 . 세션별 삭제는 없어도 돼”라고 명시했다.
- 배경·확정 제약·측정 근거: DEC-017의 학습 종료 후 30일 체험 기록 만료와 기한 전 유료 전환, DEC-018의 구독 만료 후 유료 기록 보존을 유지한다. 세션별·전체 학습 기록 삭제 기능은 직전 제안이며 채택된 기능이 아니었다.
- 검토한 대안과 장단점: 세 가지 삭제 조작을 각각 제공하면 계정을 유지하며 기록을 정리할 수 있지만 화면·연결 데이터 정리·테스트 범위가 늘어난다. 탈퇴만 제공하면 구현과 안내가 단순해지지만 일부 기록만 지우려는 사용자는 계정 전체를 삭제해야 한다. 사용자는 후자를 선택했다.
- 결정: MVP의 사용자 조작 삭제는 회원 탈퇴로 한정한다. 탈퇴 시 계정 정보와 연결된 학습 데이터를 모두 삭제한다. 계정을 유지하는 세션별 삭제·전체 학습 기록 삭제 기능은 포함하지 않는다. 탈퇴하지 않은 유료 보존 기록은 유지한다. 무료 체험 기록은 학습 종료 후 30일에 자동 삭제하되 기한 전 유료 전환한 기록은 기존 보존 합의를 따른다. DEC-012의 임시 전체 원문 자동 삭제도 유지한다.
- 이유: 사용자가 원하는 보관·탈퇴 흐름에 맞춰 MVP의 사용자 조작과 구현 범위를 줄인다.
- 영향·단점: B-01/B-05·V-03에 탈퇴 시 계정과 연결 기록의 정리·접근 차단 검증이 필요하다. 부분 삭제와 계정 유지형 전체 기록 초기화는 지원하지 않는다. 삭제는 노트·근거·교정·진행 상태 등 연결 데이터 전체를 대상으로 해야 한다. 통합 요약을 도입한다면 해당 사용자 데이터 삭제에 포함해야 한다.
- 검증하지 못한 가정: 탈퇴 처리 기한·재시도·백업 삭제·공급자 측 데이터 처리·식별자 로그 처리 상세는 후속 합의 대상이다. 이번 기능 범위 결정은 이들 처리의 완료나 즉시/동시 삭제를 검증한 것이 아니다. 삭제·계정·결제 구현은 아직 없다.
- 재검토 조건: 일부 기록 삭제 요구가 실제로 확인되거나 삭제 처리 제약이 드러나면 영향과 대안을 논의한다.
- 대체 관계: DEC-017·DEC-018의 사용자 삭제/탈퇴 표현을 MVP의 회원 탈퇴로 구체화한다. 기존 기간·무료 기록 만료·구독 만료 후 보존 정책은 유지한다.

## 후속 합의

탈퇴 처리 기한·일괄 삭제·백업 기한은 DEC-021로 구체화했다. 기능 범위는 유지하며 현재 일정·기한은 PRD 8.2절을 따른다. [ADR-021](021-scheduled-account-deletion-and-backup-deadlines.md)을 참고한다.
