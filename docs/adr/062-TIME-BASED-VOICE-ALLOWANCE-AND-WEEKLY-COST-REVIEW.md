# ADR-062 · DEC-062 · 연결 허용 시간과 주간 과금 대조

- 결정일: 2026-10-30
- 상태: Accepted
- 동의 근거: 사용자가 토큰 사용량을 계속 확인하지 않고 앱의 사용자 수·이용 시간과 주간 실제 과금액으로 Talkie 자체 기준을 만들자고 제안했다. [시간만 집계·시간 이용권과 최소 계측·토큰 집행의 비교](../proposals/API-USAGE-BUDGET.md#새-방향-검토-시간활동량과-주간-과금-대조)를 제시한 뒤 추천한 시간 이용권과 경로별 주간 대조에 “동의해. 관련 문서 하나도 빠짐없이 변경해줘”라고 명시적으로 동의했다.
- 배경: DEC-060/061의 토큰 종류별 원장과 응답·노트 예약은 Live·Soniox 브라우저 직접 연결에서 서버 독립 계측/사전 차단을 입증하지 못했고 구현·운영 부담이 크다. 분리형 서버의 Gemini 사용량 추출은 부분 구현됐지만 차단 원장은 없다. 앱의 사용자 수·학습 시각만으로 공급자 비용을 알 수는 없으므로 별도 연결 허용 시간과 실제 과금 대조가 필요하다.
- 결정과 이유: 서버가 계정/이용 기간의 공급자 **연결 허용 시간**, 동시 연결, 연결당 상한과 발급 횟수를 관리한다. 요청별 토큰을 지속 계측·차감하거나 토큰 비용을 사전 예약하지 않는다. 노트는 음성 연결 시간과 별도의 호출/재시도 제한을 둔다. 사용자 수·연결 허용 시간·대화/문답 수·노트 호출/실패를 내용 없이 집계하고, 매주 공급자의 실제 과금 총액과 대조해 시간당 기준을 보정한다. Live·분리형·노트의 기능별 실제액은 공급자 보고로 분리되는 범위에서만 사용하고 나머지는 추정으로 구분한다. 사용 전 이용 상태와 경계 마무리를 안내하고, 시간 소진 시 새 유료 음성 연결을 막되 확인된 기록의 저장·정리와 24시간 재개 범위의 기록 처리를 유지한다. 토큰 원장 없이도 사용자가 이해할 수 있는 이용 단위와 비용 검토 주기를 제공하기 위한 선택이다. 현행 제품 약속은 [PRD 6절](../PRD.md#6-대화-상태와-예외)·[9.2절](../PRD.md#92-ai-제공맥락이용량-정책), 구현 경계는 [음성 설계](../design/VOICE.md#시간-기반-이용과-비용-대조)를 따른다.
- 대안과 절충: 시간만 모아 주간 총비용을 전체 시간으로 나누는 안은 구현이 짧지만 경로/모델/노트 비중 변화와 주중 과다 사용을 설명하거나 제한하기 어렵다. DEC-060/061의 토큰 집행은 소비량을 직접 반영하지만 원장·예약/정산·늦은 보고·직접 연결 검증이 필요하다. 채택안도 같은 시간의 비용을 보장하지 않는다. Gemini Live의 누적 맥락·문답 수·전사/출력, 경로 구성과 노트 호출이 비용을 바꾸므로 경로별 실측·공급자 지출 경계와 과다 사용 대응이 필요하다. 지속 시간 상태와 정리 작업, 재접속/동시성 검증으로 일정·운영 부담은 남으며 사용자에게는 시간 경계에서 마무리 안내가 필요하다.
- 데이터·운영 경계: 학습 세션의 경과 시각과 실제 공급자 연결 시간은 다르다. 서버가 승인한 연결 시간과 단일 사용 자격/공급자 상한을 기준으로 우회 가능성을 검증하고, 브라우저가 보고한 종료 시각만으로 잔여 시간을 환급하지 않는다. 집계에는 원문·음성·노트 본문·비밀값을 넣지 않는다. 보존 기한, 계정 탈퇴/복원과의 관계, 주간 공급자 비용 확인 절차는 구현 전에 구체화한다. 무료 등급의 0원 표본을 유료 비용 기준으로 사용하지 않는다.
- 미정·재검토: 기간·연결당 허용 시간, 재접속/미사용 시간 처리, 노트 호출/재시도 상한, 기간 갱신/체험량, 시간 경계의 교정·종료 경험, 지출 상한·주간 비용 편차/대응, 실제 유료 표본, 최종 공급자/경로는 측정과 후속 합의로 정한다. 시간 대비 비용 분산이나 주간 비용이 허용 범위를 넘으면 기준·연결/호출 제한과 경로를 재검토한다. 이 결정만으로 공개 운영 비용 통제나 데이터 보관 검증이 완료되지 않는다.
- 대체 관계: DEC-060의 세션/기간 토큰 한도와 DEC-061의 종류별 정규화 원장·응답/마무리/노트 토큰 예약·환산식은 대체한다. DEC-059의 짧은 회화 방향, DEC-024의 외부 중단 후 24시간 재개·자동 종료, DEC-032의 계정당 진행 대화 하나, DEC-058의 별도 노트 요청과 근거 없는 자동 대체 금지는 유지한다. DEC-016의 최초 유료 후보 실험 3만 원 예산·사전 비용 제한도 유지한다.
