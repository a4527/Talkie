# ADR-060 · DEC-060 · 시간 상한 대신 토큰 사용량 한도

- 결정일: 2026-10-30
- 상태: Superseded by DEC-062
- 동의 근거: 사용자가 세션·구독 기간 한도와 노트 예산 분리 구조에 동의한 뒤, “15분이 아니라 토큰 사용량으로 제한을 둔다고 결정했었는데”라고 기존 합의를 명시적으로 바로잡았다.
- 배경: DEC-059의 15분 강제 종료 기록과 후속 사용량 한도 논의가 문서에 동시에 남아 있었다. 시간은 실제 토큰 소비나 비용을 일정하게 제한하지 못한다. [사용량 검토안](../proposals/API-USAGE-BUDGET.md)의 15분은 산정 사례다.
- 결정과 이유: 짧은 회화를 자주 하는 제품 방향은 유지하되, 한 대화의 15분 강제 종료를 폐기한다. 세션과 구독 기간의 토큰 사용량 한도를 두고 종료 노트 예산을 분리한다. 서로 다른 대화 길이·문답 수의 실제 사용량을 제한 기준으로 삼기 위해서다. 현행 제품 약속은 [PRD](../PRD.md#92-ai-제공맥락이용량-정책)를 따른다.
- 대안과 절충: 고정 시간 상한은 구현·안내가 단순하지만 문답 수와 누적 맥락에 따른 사용량 차이를 반영하지 못한다. 토큰 기반 한도는 짧은 세션도 사용 방식에 따라 더 일찍 끝날 수 있고, 공급자별 토큰 종류와 늦은 사용량 보고·동시 요청을 집계해야 한다. 서버 원장·예약/정산과 초과 오차 검증이 필요하다.
- 미정·재검토: 토큰 종류별 집계 단위·수치, 한도 근접/초과 시 발화·생성·노트·재시작 처리, 사용자 표시, 구독 갱신 주기와 공급자별 집행 방식은 후속 합의·측정으로 정한다. 10분 평균과 15분 산정 사례는 한도나 보장 시간이 아니다. 실제 사용량·비용·사용성 측정에서 예상과 다르면 한도와 안내를 재검토한다.
- 대체 관계: DEC-059의 짧은 회화 방향은 유지하고 15분 시간 상한·그에 따른 정상 연결 중 자동 종료만 대체한다. DEC-024의 외부 중단 후 24시간 재개·자동 종료, DEC-058의 종료 노트, DEC-032의 계정당 진행 대화 하나는 유지한다.

후속: [DEC-061](061-USAGE-ACCOUNTING-AND-GRACEFUL-SESSION-END.md)이 종류별 집계·예약/정산·마무리·안내 방식을 구체화했다. 위 미정 목록은 2026-10-30 최초 결정 당시의 범위다.

후속 상태: [DEC-062](062-TIME-BASED-VOICE-ALLOWANCE-AND-WEEKLY-COST-REVIEW.md)가 토큰 사용량 한도를 연결 허용 시간 이용권과 주간 비용 대조로 대체했다. 당시의 이유·절충은 역사적 기록으로 남긴다.
