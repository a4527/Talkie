# ADR-017 · DEC-017 · 무료 체험 1개월·유료 기간 제한 없는 학습 기록 보관

- 결정일: 2026-10-21
- 상태: Accepted
- 동의 근거: 사용자는 저장 기간 자체의 요금제별 차등 의도를 밝혔다. 이용 지속성 조사·비용 비교·무료 3개월/유료 1년 대안과 구독 하향 유예 제안 후 “무료체험은 1개월 유료는 무제한으로 하자”라고 명시했다.
- 배경·확정 제약·측정 근거: DEC-012의 임시 전체 원문과 지속 학습 기록을 구분한다. 공개 자료는 장기 이용 집단의 존재를 보여주지만 Talkie의 적정 보관 기간을 도출하지 못한다. [비용 추정](../proposals/retention-cost-estimate.md)은 가정 기반이며 실측·유료 무기한 비용의 상한이 아니다.
- 검토한 대안과 장단점: 삭제/탈퇴 전까지 모든 사용자에게 장기 보관하면 복습 이력을 유지하지만 체험 이탈자의 데이터도 누적된다. 무료 3개월/유료 1년은 최대 보존 범위를 제한하지만 장기 유료 이용자의 오래된 기록도 만료된다. 사용자가 선택한 무료 1개월/유료 기간 제한 없음은 체험 데이터 누적을 더 제한하고 유료 장기 이력을 유지하지만 지속 유료 사용자 데이터가 누적되어 비용·백업·삭제 운영 부담이 증가한다.
- 결정: PRD 8절의 지속 학습 기록에 무료 체험 1개월, 유료 기간 제한 없는 보관을 적용한다. 사용자 삭제·탈퇴 시 삭제 원칙은 유지한다. 학습 이용량과 임시 전체 원문 보관 기간은 변경하지 않는다. 원본 음성·진단 로그·결제 기록 등 모든 데이터에 같은 기간을 적용하는 결정이 아니다.
- 이유: 사용자가 저장 기간을 요금제 차이로 선택했다. 제한된 체험 기록 보존과 유료 장기 복습 이력 유지를 함께 지원한다.
- 영향·단점: D-02와 B-05에 요금제별 보존·삭제 검증이 필요하다. 유료 기록의 용량은 1년에서 멈추지 않으므로 장기 누적 코호트·백업·통합 요약 비용 재산정이 필요하다. 구독/권한 판정과 정책 변경이 데이터 삭제에 영향을 준다. 구체 결제 구현·가격·공급자·DB 선택·공개 운영 구조는 채택하지 않는다.
- 검증하지 못한 가정: 1개월의 기산점·달력/일수 기준, 업그레이드 적용·구독 종료/하향·유예, 삭제된 기록의 복구 불가 안내, 백업 삭제·통합 요약 만료 정보 처리, 실제 누적 비용은 미확정이다. 직전 30일 유예 제안은 승인되지 않았다. 통합 요약 방식과 주기도 아직 채택하지 않았다.
- 재검토 조건: 누적량·비용·장기 복습 가치·삭제 운영의 측정 결과로 변경이 필요하면 사용자 영향과 기존 기록 처리 방식을 논의해 새 결정으로 변경한다. 기존 사용자의 기록에 임의로 보관 제한을 추가하지 않는다.
- 대체 관계: DEC-012의 지속 학습 기록 기간과 DEC-014의 요금제별 기록 차이를 구체화하며 임시 원문 24시간 규칙을 대체하지 않는다.

- 후속 [ADR-018](018-learning-records-after-subscription-expiry.md)에서 미정이던 구독 종료 후 기존 유료 기록의 유지·조회·다운로드와 재구독 시 이력 활용을 확정했다. 위 미정 목록은 최초 결정 시점의 범위다.

## 2026-10-21 후속 합의 · 무료 기록의 기산점과 유료 전환

- 동의 근거: “각 학습 종료일부터 30일, 그전에 유료로 전환하면 아직 남아 있는 체험 기록도 기간 제한 없이 보관”을 제안했고 사용자가 “그러자”라고 동의했다.
- 결정: 무료 체험의 1개월은 각 학습 종료 시점부터 30일로 구체화한다. 보관 기한 전에 유료로 전환하면 남아 있는 체험 기록에도 유료 보존 정책을 적용한다. 해당 기록은 이후 구독 만료 때에도 ADR-018에 따라 유지한다. 기한 경과로 이미 삭제된 기록의 복원은 보장하지 않는다.
- 대안·이유: 가입일이나 체험 종료일로 기한을 일괄 설정하는 대신 학습별 종료 시점을 사용해 각 학습 기록에 같은 기간을 제공한다. 달력 월마다 길이가 다른 한 달 대신 30일로 안내와 만료 계산을 명확히 한다. 기존 체험 기록을 유료 전환 시에도 만료시키는 대안보다 첫 학습부터 이력을 이어 쓰기 쉽다.
- 영향·단점: 기록마다 종료 시점과 만료 여부, 유료 전환으로 보존 대상이 됐는지를 확인해야 한다. 전환이 기록을 새로 생성한 것으로 처리되거나 구독 만료로 다시 무료 만료 대상이 되면 안 된다. 업그레이드로 데이터 누적·백업 비용이 늘 수 있다. 경계 시각의 유료 권한 반영·삭제 경쟁과 지연 이벤트는 구현 설계/테스트에서 다룬다. 전환 지연을 위한 별도 유예는 합의하지 않았다.
- 검증과 남은 범위: 학습별 30일 만료·만료 전 전환·전환 후 구독 만료에도 보존·이미 삭제된 기록의 복원 미보장을 검증한다. 백업 삭제·통합 요약의 만료 정보 처리와 실제 비용은 여전히 미정이며 유료 처리/삭제 구현은 미수행이다. 위 최초 결정의 미정 목록은 이 후속 합의 범위에서 해소됐다.

- 후속 [DEC-019](../../DECISIONS.md#dec-019)에서 MVP 사용자 조작 삭제를 회원 탈퇴로 한정했다. 위 사용자 삭제/탈퇴 표현의 현재 기능 범위는 해당 ADR을 따른다.
