# ADR-063 · DEC-063 · 관찰한 음성 연결 시간과 계정별 이용권 상태

- 결정일: 2026-10-30
- 상태: Accepted
- 동의 근거: 사용자가 발급 최대 시간의 즉시 차감 대신 웹 브라우저에서 실제 연결 시간·대화 수를 관찰하는 방향에 “그러자”라고 동의했다. 종료 미보고 때 마지막 서버 확인 뒤 짧은 유예 시간까지만 차감하는 A안과 계정당 동시 음성 연결 하나인 A안을 차례로 선택했다. 이용 시간 상태는 학습 대화 기록과 분리해 계정에 연결된 별도 이용권 테이블에 두자고 명시했다. 시간 경계에서 대화를 마치는 4번은 “일단 a”라는 잠정 선택으로 이 결정의 확정 범위에서 제외한다.
- 배경: DEC-062는 계정·기간별 공급자 연결 허용 시간과 주간 비용 대조를 채택했지만 발급한 최대 시간과 실제 연결 시간의 차감 관계, 비정상 단절, 동시 연결, 저장 위치는 남겨 두었다. 현행 `users`에는 계정 식별·가입·탈퇴 정보만 있고 학습 세션의 보관 기한은 이용권 기간과 다르다.
- 결정과 이유: 웹 브라우저가 공급자 연결이 열린 시간과 대화 수를 관찰해 서버로 보내고, 서버는 연결 중 수신한 신호·서버 시각과 대조해 관찰한 연결 시간을 이용권에서 누적 차감한다. 발급 최대 시간을 즉시 사용량으로 차감하지 않는다. 실제 연결이 열리지 않은 발급은 사용 시간으로 차감하지 않는다. 종료 보고가 없으면 마지막으로 서버가 확인한 시각 뒤 짧은 유예 시간까지만 차감한다. 발급 전에는 남은 시간과 연결당 최대 시간을 확인하고, 계정당 활성 음성 연결은 경로·기기를 합쳐 하나로 제한하며 동일 발급 요청의 재전송으로 새 권한을 만들지 않는다. 계정·이용 기간의 허용/사용 시간과 활성 연결을 판단할 상태는 지속 DB의 계정 연결 별도 이용권 테이블에 두고 학습 대화·노트의 만료와 독립적으로 유지하며 탈퇴 때 함께 삭제한다. 구체 기간/시간·유예 길이·발급 이력 테이블 구성은 설계·검증 후 정한다.
- 대안과 절충: 발급 최대 시간을 즉시 차감하면 초과 사용 제어는 단순하지만 짧은 연결·미사용 발급에 불리하다. 브라우저의 종료 시각만 믿는 사후 차감은 사용 시간에 가깝지만 보고 누락·조작·연결 잔존을 독립 확인하지 못한다. 경로별 동시 연결은 기기 전환에 편하지만 계정 한도 경쟁과 비용을 늘린다. `users` 열 추가는 초기 구현이 작지만 이용 기간 갱신·체험에서 구독 전환·기간 상태를 계정 식별 행에 누적한다. 학습 대화 행에 보관하면 기록 만료·삭제가 이용 가능 시간을 바꿀 수 있다. 별도 이용권 테이블은 이관·조회·정리 비용이 들지만 기간별 상태와 기록 수명을 분리한다.
- 위험·재검토: 브라우저 관찰과 서버 신호만으로 공급자 연결의 실제 시작·종료를 독립 증명하지 못한다. 유예 중 차감은 실제 단절 뒤 시간을 더 사용할 수 있고, 서버가 신호를 받지 못하면 관찰 시간과 차이가 난다. 공급자 측 최대 연결 지속시간, 중단·재접속·다중 기기·프로세스 재시작과 보고 누락의 오차를 검증한다. 연결이 남아 있는데 서버가 발급 자리를 풀거나 한도를 초과할 수 있으면 중계·경로 제한을 재논의한다. 유예 길이·해제/정정 기준·이용권 기간·보존 기한·공개 운영 수치는 후속이다.
- 대체 관계: DEC-062의 시간 이용권 집행을 구체화하며 토큰 원장·예약을 복원하지 않는다. DEC-032의 진행 대화 하나와 별개로 음성 연결 하나를 제한한다. 시간 경계의 교정/재시도 종료는 사용자 잠정 선택만 있어 이 ADR의 승인 범위에 포함하지 않는다. 현행 제품 약속은 [PRD 9.2절](../PRD.md#92-ai-제공맥락이용량-정책), 구현 경계는 [음성 설계](../design/VOICE.md#시간-기반-이용과-비용-대조)와 [DB 설계](../design/DATABASE.md#저장소와-스키마-경계)를 따른다.
