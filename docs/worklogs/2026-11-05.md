- 사용자 “다음진행하자” 요청에 따라 PROGRESS의 첫 재개 지점·B-03/B-04/B-12·전날 최종 기록·미션 설계·PRD·ADR-069를 확인했다. 다음 논의로 미정인 실전 무진전 종료 경계를 골랐다.
- [첫 미션 검토안](../proposals/FIRST-MISSION-DETAILS.md#실전-무진전-종료--dec-082-채택)에 진전 정의·연속 3회 시험 후보·초기화/제외·실패 제안 검증·연습/평가 분리의 다섯 항목과 대안·경험/비용 영향을 작성했다. 3회는 측정값이나 운영 확정값이 아니며 사용자 동의와 사례 검증이 남는다.

- 문서 대조: 기준 PRD·DEC-069/076/081·미션 설계의 침묵 미종료·자연스러운 재확인·복수 경로·결과/점수 분리와 제안을 대조했다. PRD·결정·TASK 상태는 변경하지 않았다. 기존 자유 대화 구현과 승인·미구현 미션 계약의 차이는 유지한다.
- 검증: 수정/신규 문서 3개의 로컬 상대 링크 63개 경로 존재 확인·`git diff --check` 통과. 정책 채택·기능 완료가 없어 PROGRESS·CHANGELOG의 상태는 유지했다.

## 실전 무진전 경계 승인 반영

- 사용자가 다섯 방향과 사례 검증 준비에 “그러자”로 동의했다. PRD 4.2.2절을 먼저 추가하고 DEC-082·미션 설계·B-03 수용 기준·PROGRESS·CHANGELOG·검토안/색인을 맞췄다. 앞 절의 미승인 표시는 제안 작성 당시 상태다.
- 연속 3회는 검증 후보로만 채택했다. 운영 임계값 확정·실제 AI 호출/품질 검증·미션 구현 완료로 확대하지 않았다. 고정 사례는 설계로 이관하고 제안서에는 대안·절충과 채택 링크만 남겼다.
- PRD의 모드·자연스러운 재확인·침묵 미종료·상황 결과/점수 분리와 B-03의 완료 경계를 대조했다. DEC-069의 기존 방향 구체화로 기록하고 역사적 ADR 내용은 변경하지 않았다. TASK 상태와 기존 E2E 보류는 유지한다.
- 코드·DB·외부 호출·사용자 데이터 접근/로그 변경은 없다. 앱 테스트는 실행하지 않았다. 실제 AI의 수준별 판정 일관성·운영 임계값·API/DB 및 마지막 대사 재생 실패 계약은 후속으로 남는다.
- 검증: 변경/신규 문서 9개·로컬 상대 링크 313개 경로 존재·DEC-082 앵커 단일 정의·PRD 4.2.2절 존재·`git diff --check` 통과. 승인 범위와 미구현 표시·B-03 상태를 대조했으며 승인된 미션 계약과 자유 대화 코드의 차이는 계속 남는다.

## 수준별 합성 평가 사례 구체화

- 사용자 “진행해” 요청으로 [수준별 사례 초안](../proposals/FIRST-MISSION-EVALUATION-CASES.md)을 작성했다. 외부 기준을 새로 조사하거나 CEFR의 공식 채점표로 제시하지 않고 기존 PRD·수준 설명·승인 배점/근거 정책에 따라 자체 합성 사례를 구성했다.
- A1~C2의 완결 대화 6개·총 40발화·수준별 12개 기준의 근거/한계 대조·등급 경계 변형 8개·입력 변형 대조 항목을 준비했다. 재제조/환불·경로 전환·짧은 수락·수정 후 독립 적용·반복 오류·저장 누락·높은 수준의 관찰 기회 부족을 구분했다.
- 구체 등급은 검토 후보로 두었다. 특히 짧은 카페 대화의 C1/C2 안정성 판정과 모든 수준/기준/등급 조합은 미완성이며 실제 채점 정답표나 평가 품질 완료로 표시하지 않았다. 후속 판정 경계 합의·실제 호출 계획과 검증이 남는다.
- 검토안·색인·PROGRESS에 새 자료와 다음 검토를 연결했다. PRD·DEC-082·B-03/B-12의 기존 정책/완료 기준을 대조했고 새 정책 승인·TASK 완료·CHANGELOG의 사용자 동작 변경으로 기록하지 않았다. 기존 자유 대화 구현과 미션 계약의 차이와 E2E 보류를 유지한다.
- 코드·DB·외부 호출·사용자 데이터 접근/로그 변경은 없다. 문서 대조만 수행하고 앱 테스트·AI 호출은 실행하지 않았다.
- 검증: 이번 수정/신규 문서 5개의 상대 링크 129개 경로 존재·대화 6개/40발화·기준 대조 12행·변형 8개 구조 확인·`git diff --check` 통과. 사례별 발화 ID·경로별 처리 조건·사용자/직원 근거 구분을 대조했다. 의미적 채점 재현성은 미검증이다.

## 수준별 판정 경계의 문서 검토

- 사용자 “진행해” 요청으로 수준별 합성 사례와 PRD 4.5/4.5.2절을 수동 대조했다. [사례 초안](../proposals/FIRST-MISSION-EVALUATION-CASES.md#판정-경계의-문서-검토-결과--미승인-추천)에 관찰 범위·안정성·실제 어려움/근거 부족·짧은 표현·결과 설명의 다섯 경계와 대안/영향을 적었다.
- A2 기본 대화의 12개 기준별 충족 후보와 사용자 근거를 작성하고 조건부 합산 100/100, P-01의 구조만 부분 충족일 때 98.5/100을 비교했다. 실제 AI 판정이나 확정 정답표로 취급하지 않는다.
- A1 원래 주문 표현의 모호성·변형 대본의 미고정·C1/C2 전체 능력 미관찰과 이번 미션 점수 제외를 혼동할 위험을 발견했다. 기본 사례 수정안과 후속 입력 고정을 제안했으며 미승인 수준별 기준을 PRD에 적용하지 않았다.
- 검토안 색인·PROGRESS를 맞췄다. 기존 배점·판정 불가·중복 감점 금지·짧은 답 무감점은 유지하고 이번 미션 관찰 범위/안정성의 새 구체화는 동의 전 미승인으로 두었다. DEC·TASK 상태·CHANGELOG의 정책 채택 표시는 변경하지 않았다.
- 문서 작업만 수행했다. 실제 AI 호출·앱 테스트·추가 E2E·코드/DB·사용자 데이터 접근/로그 변경은 없다. 운영 임계값·판정 품질·완결 변형 입력·평가/노트 호출 및 API/DB 계약은 미완료다.
- 검증: 이번 수정 문서 4개의 상대 링크 98개 경로 존재·A2 판정 후보 12개·조건부 합산 산술·`git diff --check` 통과. PRD의 기존 계약과 미승인 추천의 구분을 대조했다. 실제 의미 판정 재현성은 미검증이다.
