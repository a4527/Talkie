# 2026-11-20 작업 기록

## 디자인 방향 탐색과 기본 경험 결정(DEC-099)

- 디자인 캔버스(Claude Design, 비공개 아티팩트 `Talkie 디자인 방향 4종`)에 라이프스타일·교육형 시안 3종(E 여행 일지·F 시즌 에피소드·G 코치 동행, 각 홈·미션 완료)을 추가했다. 사용자 요구는 하루 단위의 가벼운 사용, 이야기·테마, 메인 캐릭터, 달성 표현, 약간만 둥근 모서리였고, 참고 이미지 5개의 문제(지저분함·색감·단순함·긴 경로 스크롤·추천 표현을 크게 띄우는 홈)를 피했다. 공통 캐릭터는 앵무새 ‘토키’로 그렸다.
- 연속 접속 표현은 DEC-095(누적 일수만 표시, 연속 일수·달력 미제공)와 충돌해 넣지 않고 누적 일수 마일스톤·스탬프로 대신했다. 기존 B안 홈의 요일 점도 이 결정과 맞지 않는다는 점을 사용자에게 알렸다(시안이므로 수정하지 않음).
- 사용자가 E안을 기본으로 제안했다. 사전 제작 부담과 시즌의 연관성 문제를 논의한 뒤, 시즌 틀만 직접 만들고 미션은 챕터 안에서 AI가 생성, 평가표는 유형 단위, 시즌 밖 미션은 번외편, 공유 탭은 보류하는 추천안과 ‘한 달 살기’ 콘셉트, 첫 시즌 미국 뉴욕에 동의했다. [ADR-099](../adr/099-CITY-MONTH-SEASONS-AS-DEFAULT.md)로 기록했다. 국가 비교의 ‘미국식 영어가 국내 학습자에게 익숙하다’는 조사 없는 추정이다.
- 반영: [PRD 4.1·7절·F-07·10절·11절 색인](../PRD.md#7-주제와-표현-정책), [MISSIONS 시즌과 번외편](../design/MISSIONS.md#시즌과-번외편)(승인·미구현), [USER-FLOWS 1. 시작](../design/USER-FLOWS.md#1-시작), [TASKS B-13](../TASKS.md#첫-학습-흐름과-기능-구현) 신설, [PROGRESS](../PROGRESS.md), [CHANGELOG](../CHANGELOG.md#2026-11-20). 캔버스 E안의 문구를 런던에서 뉴욕 시즌(브루클린 셰어하우스 챕터)으로 바꾸고 번외편 진입을 더했다.

### 문서 대조

- DEC-099와 PRD 4.1·7·10절, F-07, MISSIONS, USER-FLOWS, TASKS B-13, PROGRESS의 결정 ID·링크·상태를 대조했다. B-13은 미착수(TODO)다. 코드는 바꾸지 않았다.
- 남은 불일치: USER-FLOWS의 앱 화면 지도는 현재 구현 화면이라 시즌·번외편 화면을 넣지 않았다(B-13 구현 때 갱신). 시즌 틀·유형 평가표 저장 방식, 챕터 진행 조건, 스토리 상태 상한, 문화 소재 검토 기준은 PRD 11절 색인에 미정으로 남겼다.

## 시즌 후속 결정(DEC-100)

- 사용자가 시즌·챕터를 순서 없이 자유롭게 고르게 하고, 그래서 이야기 상태를 저장하지 않으며, 문화 소재는 사실 검토 대신 안내 문구로 갈음하기로 했다. 저장 위치는 추천안(시즌 틀·유형 평가표는 DEC-086 방식의 코드 레지스트리, 생성 미션 정의는 DB)과 생성 지시의 고정관념·비하 묘사 금지에 동의했다. 진행 표시는 결과 집계에 시즌·챕터 ID를 붙여 계산한다. ADR-099는 고쳐 쓰지 않고 [DEC-100](../DECISIONS.md#dec-100) 짧은 결정으로 대체 범위를 연결했으며 DEC-099 상태를 Partially Superseded로 바꿨다.
- 반영: [PRD 7·11절](../PRD.md#7-주제와-표현-정책), [MISSIONS 시즌과 번외편](../design/MISSIONS.md#시즌과-번외편), [TASKS B-13](../TASKS.md#첫-학습-흐름과-기능-구현), PROGRESS, CHANGELOG. 캔버스 E안에서 잠긴 ‘다음 이야기’와 이어지는 예고를 자유 선택형 표현으로 바꿨다.
- 문서 대조: DEC-099/100과 PRD·MISSIONS·TASKS·PROGRESS의 ID·링크·상태를 대조했고 스토리 상태·출처 검토 문구가 남지 않았음을 확인했다. 남은 미정은 초기 유형 목록과 생성 검증(PRD 11절)이다.
