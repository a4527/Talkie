# 2026-10-21 작업 기록

## 결과와 사용자 답변

- 사용자가 실제 기능 연동의 다섯 선택을 `1C 2A 3A 4C 5C`로 명시했다. PRD 8·8.1·8.2·9.2절을 기준으로 DEC-026~030/ADR-026~030을 채택하고 design·D-02/D-03/B-01/B-02/B-05/B-09·결정 목록·진행 상태·변경 이력·진행표를 연결했다. 앱 직접 인증의 보안·운영 부담과 임시 원문 백업 제외의 복원 한계를 기록했다. 두 AI 후보·직접/중계 경로는 비교 범위만 확정했으며 최종 선택·실제 음성 호출·유료 지출·제품 구현은 아직 없다.

- 사용자가 실제 MVP에 필요한 결정을 다시 다섯 개씩 제시해 달라고 요청했다. B-00과 실제 기능 D-02/D-03의 선행 관계를 대조하고 인증 구현 책임, 임시 전체 전사문의 백업 포함 여부, 지속 작업 실행 방식, 두 실시간 AI 후보의 비교 범위, 음성 연결 경로의 비교 범위를 미채택 제안으로 정리했다. Supabase 인증·세션·백업·Cron과 OpenAI Realtime·Gemini Live의 공식 문서에서 확인한 기능과 Talkie 적합성 미검증을 구분했다. 실제 공급자 선택·유료 호출·자원 생성은 하지 않았다.
