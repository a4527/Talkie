# 2026-11-03 작업 기록

## 미션 중심 전환 계획

- 사용자 요청에 따라 [별도 계획서](../proposals/MISSION-CENTERED-LEARNING-PLAN.md)를 작성했다. 달성 일수 외 보상은 제외하고 긴 상황 수행·기본/AI/사용자 지정 미션·목표 판정·미션 이용량·연습/실전·간결한 노트의 방향과 미정 범위를 구분했다.
- 현재 코드와 관련 PRD·TASKS·DECISIONS·음성/학습 저장 설계를 대조했다. 현재도 과거 맥락 전체를 공급자에게 전달하지 않는다는 점을 계획에 명시했다.
- 문서 대조: 계획만 작성했으므로 현행 정책·TASK 상태·PROGRESS·CHANGELOG는 변경하지 않았다. 기존 시간 이용권·즉시 교정·노트 계약과 전환 방향의 차이를 계획서 후속 결정 목록에 남겼다. 구현 완료나 비용 절감은 주장하지 않는다.
- 검증: 문서 상대 링크 존재 검사와 `git diff --check` 통과. 코드 변경이 없어 테스트는 실행하지 않았다.

- 후속 요청 반영: 초기 범위에 달성 일수만 추가했다. 집계·표시의 미정 조건을 명시하고 가상 재화·성장·꾸미기·경품은 후속 검토로 남겼다. 코드와 현행 정책은 변경하지 않았다.

## 대표 미션 구체화

- 계획서에 짧은 카페 상황·복잡한 납기 협상·사용자 지정 면접의 목표와 달성/부분 달성/미해결/판정 보류 사례를 추가했다. 모두 논의용 초안이며 공급자 호출이나 실제 판정 품질 검증은 하지 않았다.
- 설명형과 합의형의 근거 차이, 종료와 달성의 분리, 미재생·저장 누락 시 판정 보류, 연습 도움과 실전 평가의 구분을 명시했다. 실시간 단일 AI와 종료 별도 평가의 품질은 후속 검증으로 남겼다.
- 문서 대조: 계획서와 직접 연결된 현행 PRD·TASK·결정은 아직 대체하지 않는다. 목표 집계·종료·일수 인정의 미정 사항을 명시했으며 코드·완료 상태는 변경하지 않았다. `git diff --check` 및 상대 링크 존재 검사 통과.

## 목표별 달성률 후속 논의

- 사용자 합의인 목표별 배점·회화 품질 포함 최종 달성률과 50% 이상 달성 일수 기준을 계획서에 반영했다. 60/40 비중과 세부 배점은 검토용으로 구분했다.
- 단문 요청 사례의 한계를 명시하고 숙소 조건 협의·납기 협상·프로젝트 꼬리 질문으로 대표 상황을 보강했다. 짧은 마무리 대사의 의미와 상황 해결/점수/일수의 차이를 설명했다.
- 기존 기준 문서는 유지했다. 제안서의 선행 미정 항목 중 후속 합의와 충돌하는 표시를 조정했다. 코드 변경·실제 AI 평가는 없으며 `git diff --check` 통과.

- 후속 합의 반영: 상대역 마무리 대사 후 종료·초기 배점 60/40 유지. 사용자 발언의 80%는 기존 달성 일수 기준의 상향으로 해석해 계획서에 명시했다. 언어 평가의 난이도별 기대 수준과 평가표 버전 고정은 설계 방향으로 추가했으며 세부 평가표·실제 품질은 미검증이다. 기존 기준 문서·코드는 유지하고 `git diff --check`를 확인했다.

- 후속 합의: 개인별 추천 후보는 AI가 생성하고 선택한 후보만 상세 미션·평가 기준을 구성·검증·고정하는 절차를 반영했다. 직접 제작 미션은 사전 기준을 사용하고, 채점 항목은 충족/미충족으로 평가하는 방향을 정리했다. 역사적 예시의 부분 달성은 전체 결과 설명이며 채점 항목의 부분 점수와 구분한다. 코드·현행 기준 문서는 변경하지 않았고 `git diff --check` 통과.

- 후속 합의: 난이도 단계를 코드에 고정하지 않고 고유 ID·순서·대화 설정·언어 평가표·버전을 데이터로 관리하는 방향을 계획서에 반영했다. 시작 시 적용 기준 보존과 과거 결과 비소급 원칙을 명시했다. 단계 수·이름·수준 결정 방식은 미정이며 코드·스키마·현행 기준 문서는 변경하지 않았다. `git diff --check` 통과.

- 후속 합의: 연습의 힌트·교정·다시 말하기는 감점·점수 상한·달성 일수 제외 사유로 삼지 않는다. 모드와 도움 여부는 점수와 분리하고, 실전 보상 차등은 미래 후보로 남겼다. 초기 범위는 달성 일수만 유지한다. 평가할 시도 범위와 모드 전환은 미정이다. 코드·현행 기준 문서 변경 없이 `git diff --check` 통과.

- 후속 합의: 연습은 도움으로 진행하고 실전은 일정 수준 이상 무진전이면 실패로 종료하는 방향을 반영했다. 임계값·진전 근거·장애 구분은 초안/미정으로 남겼다. 실패 결과와 최종 점수·80% 일수 기준 간 경계는 후속 확인 사항으로 명시했다. 코드·현행 기준 문서는 유지하고 `git diff --check` 통과.

- 후속 합의: 실전 실패여도 80% 이상이면 달성 일수를 인정하고 최종 해결·합의 항목의 배점을 높이는 방향을 반영했다. PRD 6절·ADR-024로 중단 24시간 재개/자동 종료를 확인해 재사용 경계와 미션 점수·차감의 미정 사항을 구분했다. 코드·현행 기준 문서는 변경하지 않았으며 `git diff --check` 통과.

- 후속 합의: AI·사용자 세션 연결 성립 시 횟수 차감, 동일 미션 재개는 중복 차감 없이 처리, 24시간 미재개 자동 종료는 차감 유지·달성 일수 제외로 계획을 갱신했다. 기존 종료 시 차감 확정 제안을 대체하고 만료 시 80% 일수 기준의 예외를 명시했다. 연결 신호·장애 환급·날짜 귀속 등은 미정으로 유지했다. 코드·현행 기준 문서 변경 없이 `git diff --check` 통과.

- 후속 명확화: 당일 인정 조건을 충족한 다른 미션이 있으면 이후 미션 중단·실패·만료와 무관하게 해당 일의 달성 기록을 유지한다. 만료 제외는 해당 미션에만 적용한다. 계획서만 수정했으며 `git diff --check` 통과.

## 기준 문서 최신화와 커밋 전 대조

- 사용자 요청으로 오늘 합의를 PRD에 이관하고 DEC-069/ADR-069를 추가했다. 기존 ADR은 당시 근거를 보존하면서 후속 대체 안내를 추가했다. 미션 설계에 승인·미구현 계약과 미정을 구분했다.
- PRD의 자유 대화 지속·교정 단일 모드·시간 이용권 문구를 전환하고 관련 TASK의 수용 기준을 조정했다. B-12는 점수·일수 구현 TODO로 추가했다. 기존 작업을 완료로 바꾸지 않았다.
- 인증·음성 포트·분리형·저장/원문 수명·24시간 재개는 유지한다. API/DB의 구체 확장은 미정이며 현 구현 계약과 구분했다. 노트는 간결화 방향만 승인되었으므로 새 고정 형식·보관 기한은 만들지 않았다.
- PROGRESS·CHANGELOG와 제안서/색인을 연결했다. 제안서의 선행 초안·사례는 역사적 기록으로 표시하고 현행 기준을 PRD/설계/TASK로 지정했다.
- 남은 미정: 수준별 평가표, 생성 검증 품질, 무진전 임계값, 판정 보류·반올림·재시도 평가, 연결 신호·장애 환급·차감 규모·이용 기간, 일수 날짜 귀속·표시/소급. 모두 구현 전 구체화 대상으로 기록했다.
- 코드 변경이 없어 앱 테스트는 실행하지 않는다. 상대 문서 링크·변경 diff·스테이징 목록·민감 파일/값 및 데이터 접근/로그 변경 부재를 점검하고 pre-commit의 민감 파일명·Gitleaks 검사 후 커밋한다.

- 커밋 전 검증 결과: 상대 링크 395개 경로 존재·스테이징 diff 공백 검사 통과. 스테이징은 문서 21개만 포함한다. `.githooks/pre-commit`의 민감 파일명 검사와 Gitleaks에서 누출 발견 없음으로 통과했다. 실제 키·계정 정보를 추가하지 않았고 코드·사용자 데이터 접근·로그 동작 변경은 없다. 미정 항목은 위 목록과 미션 설계에 남겼으며 구현 완료로 표시하지 않았다.
