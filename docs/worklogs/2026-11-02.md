# 2026-11-02 작업 기록

## 분리형 TTS 후보 공식 자료 조사

- 사용자 보고의 Gemini TTS 무료 RPM/RPD 한도에 따른 후속으로 [비용 절감 검토안](../proposals/VOICE-COST-REDUCTION.md#2026-11-02--분리형-tts-후속-후보-조사-미승인)에 Soniox TTS, Google Cloud TTS, Cartesia, 브라우저 음성, OpenAI Speech API의 공개 가격·처리량·제약을 비교했다. 각 수치의 공식 출처는 검토안 표에 연결했다. OpenAI 항목은 OpenAI Docs의 공식 모델·Speech API 문서로 확인했다.
- Soniox TTS REST는 기본 100 RPM·동시 3요청, Google Cloud TTS는 음성 종류별 200~1,000 RPM, Cartesia는 요금제별 동시 2~15요청으로 확인했다. 서로 다른 계량 방식이므로 RPM과 동시성을 같은 처리량으로 환산하지 않았다. 기존 15분 세션·AI 음성 6분 가정으로 Soniox 약 $0.0705, Google Cloud Standard/WaveNet 약 $0.0216의 TTS 부분 비용만 계산했다. 실제 청구액·Talkie 계정 할당량은 확인하지 않았다.
- Soniox를 기존 STT와 결합하는 첫 청취 후보, Google Cloud Standard/WaveNet을 저가 비교 기준으로 제안했다. 공급자 선택·요금제 변경·API 호출·코드 변경은 수행하지 않았다. 실제 한영 발음·지연·끼어들기·데이터 보관/학습 조건은 미확인이다. DEC-054의 요소별 비교와 PRD 공급자 정책에 맞춘 후속 확인이 필요하다.
- 문서 대조: 제안서는 미승인 후보로 기록하고 [PROGRESS](../PROGRESS.md#다음-재개-지점)의 다음 지점을 갱신했다. 채택 결정·제품 약속·구현 변경이 없어 DECISIONS·PRD·DESIGN·TASKS·CHANGELOG의 현행 계약과 상태는 바꾸지 않았다. 링크와 상태를 대조했고 발견된 불일치는 없다.

## Soniox·Google Cloud TTS 비교 준비와 Soniox 호출

- 사용자 요청에 따라 고정된 가상 영어·한국어 문장 각 1개를 두 공급자에 보내는 `app/scripts/compare-tts.ts`와 `npm run tts:compare`를 추가했다. 저장 위치는 Git 제외 `app/.local/tts-compare/`이며 사용자 기록·키·공급자 오류 본문을 파일이나 로그에 남기지 않는다. Google Cloud 경로는 Gemini API 키를 재사용하지 않고 별도 OAuth 액세스 토큰을 요구한다. `/voice`의 TTS 공급자는 바꾸지 않았다.
- Soniox 실제 호출: `npm run tts:compare -- soniox` 1회, `tts-rt-v2`·Daniel 음성·WAV 24 kHz. 영어 50자 188,494바이트/3,162ms, 한국어 24자 168,014바이트/2,723ms. 두 파일은 RIFF/WAVE, 16비트 mono PCM 24 kHz로 확인했다. 이 수치는 네트워크 포함 전체 요청 시간으로 첫 음성 지연이나 청취 품질 판정이 아니다. Soniox 청구액은 미확인이다.
- Google Cloud 실제 호출은 하지 못했다. 현재 환경에 Cloud TTS 프로젝트 자격 정보와 `gcloud`가 없다. 사용자에게 Cloud TTS와 Gemini Developer API가 별도이며 프로젝트·API 활성화·결제·ADC가 필요함을 안내했다. 별도 인증 라이브러리 설치 요청은 중단됐고 설치/의존성 변경은 없다. 비교 스크립트는 짧은 OAuth 액세스 토큰을 받아 Cloud REST API를 호출하도록 준비했다.
- 검증: `npm run typecheck` 통과, `git diff --check` 통과. WAV 형식은 `file`로 확인. 실제 재생 청취, Google Cloud 호출, 같은 조건의 비용/지연 비교는 남는다. TASK 상태 변경 없음.
- 문서 대조: 실행법은 [README](../../README.md#tts-후보만-비교하기), 시험 상태는 PROGRESS에 기록했다. 공급자 채택·제품 정책·음성 경로 설계의 변경은 없어 PRD·DECISIONS·DESIGN·TASKS·CHANGELOG는 변경하지 않았다. 링크·상태 불일치는 발견하지 못했다.
- Cloud TTS 인증 절차를 다시 확인해 REST 요청에 사용자 인증의 과금 프로젝트용 `x-goog-user-project` 헤더를 추가했다. 스크립트는 `GOOGLE_CLOUD_PROJECT`를 요구한다. Google Cloud 호출은 여전히 미실행이며 수정 뒤 `npm run typecheck`·`git diff --check`가 통과했다.

## 두 TTS 후보의 동일 문장 생성 결과

- 사용자가 Cloud TTS 프로젝트 인증을 설정한 뒤 `npm run tts:compare -- google-cloud` 실행 결과를 공유했다. 영어 50자 171,514바이트/898ms, 한국어 24자 162,152바이트/347ms. 결과 파일을 직접 확인해 둘 다 24 kHz·16비트·mono WAV이며 재생 길이는 3.572초/3.377초로 읽혔다. Soniox의 앞선 동일 문장 결과는 188,494바이트/3,162ms와 168,014바이트/2,723ms다. 각각 단 1회·순차 호출이고 네트워크/초기 연결 조건이 달라 안정적인 지연 비교나 첫 음성 지연으로 해석하지 않는다.
- Soniox가 스트리밍 WAV의 RIFF·`data` 길이를 `0xffffffff`로 남긴 것을 파일 검사에서 발견했다. 기존 로컬 WAV 두 개의 헤더 길이만 실제 파일 길이로 보정했고, 비교 스크립트에도 보정을 추가했다. 보정 후 Soniox 영어/한국어 재생 길이는 3.925초/3.499초다. 음성 샘플 데이터는 수정하지 않았다. 네 파일 모두 WAV 파서로 다시 열렸다.
- 비교 결과는 가상 문장 두 개의 생성 성공·파일 형식·전체 요청 시간까지만 보여준다. 사용자의 영어 교정 발음·한국어 도움·한영 혼용·끼어들기 청취 판정과 실제 공급자 청구액·계정 한도는 남는다. `/voice`의 Gemini TTS는 변경하지 않았고 공급자 선택은 미승인이다.
- 검증: 수정 후 `npm run typecheck`와 `git diff --check` 통과. 문서 대조: PROGRESS의 Cloud 미실행 표기를 실제 확인 범위로 갱신하고, TASKS·PRD·DECISIONS·DESIGN의 상태·계약 변경은 없음을 확인했다. 링크·상태 불일치는 발견하지 못했다.

## 분리형 공급자 선택 시험 연결

- 사용자 범위 확정: 이번 비공개 앱 시험은 기존 STT Soniox·LLM Gemini를 유지하고 TTS에만 Google Cloud Standard를 추가한다. `/voice`는 STT·LLM·TTS 선택을 각각 표시하며 현재 앞의 두 단계는 한 후보만 있다. Soniox TTS는 앞선 WAV 비교에만 남긴다. 제품의 최종 공급자 채택이나 공개 배포 결정은 아니다.
- 코드: 선택을 연결 발급 요청에서 검증하고 서버 연결 토큰에 저장한다. 이후 음성 요청에서 브라우저가 보내는 공급자 값을 신뢰하지 않고 연결 토큰의 TTS로 호출한다. Google Cloud는 별도 프로젝트·OAuth 토큰·과금 프로젝트 헤더로 요청하고 WAV에서 24 kHz·16비트·mono PCM만 추출해 기존 재생·중단·근거 흐름에 전달한다. 한글 포함 여부로 한국어/영어 Standard 음성을 고르는 초기 시험 규칙을 적용했다. 5,000바이트 입력 한도 초과·오디오 형식 오류는 실패로 처리한다. 실제 사용자 음성 저장이나 공개 연결은 하지 않았다.
- 검증: `npm test` 117개 통과(선택 검증·연결 토큰 고정·Cloud 요청/PCM 검증 추가), `npm run typecheck` 통과. `npm run test:e2e -- voice.spec.ts`는 첫 실행에서 Chromium의 `libasound.so.2` 부재로 6개 모두 시작 실패했다. 시스템 설치는 sudo 비밀번호가 없어 실패했으며 `/tmp`에 Ubuntu `libasound2t64` 패키지를 추출해 `LD_LIBRARY_PATH`로만 제공한 재실행에서 기존 PC/모바일 6개 통과했다. 선택 UI의 PC/모바일 표시·화면 폭 2개와 선택값 발급 요청 전달 2개를 추가한 뒤 전체 10개 통과했다. 시스템 패키지·프로젝트 의존성은 변경하지 않았다.
- 한계: 새 Cloud TTS의 실제 `/voice` 연결·전체 학습/재생 청취·한영 혼용 발음·토큰 만료·실제 청구액은 미검증이다. 3분 단일 프로세스 비공개 시험의 기존 시간/횟수 제한을 유지하며 B-10의 공개 비용 집행과 다르다. TASK 상태 변경 없음.
- 문서 대조: 구현 계약은 [음성 설계](../design/VOICE.md#분리형-비공개-시험-경로), 실행 조건은 [README](../../README.md#gemini-live-비공개-음성-시험), 현황은 PROGRESS, 사용자 의미 변경은 CHANGELOG에 연결했다. PRD의 제품 약속·DEC-055/056의 로컬 시험 범위·B-09 수용 기준과 대조했고 새 결정은 기록하지 않았다. 발견된 링크·상태 불일치는 없다.

## Cloud TTS 토큰 자동 발급

- 사용자가 매번 `export`해야 하는 불편을 지적했다. 로컬 비공개 시험 경로에서 `gcloud auth application-default login`으로 만든 ADC를 읽어 `gcloud auth application-default print-access-token`을 앱 서버에서 자동 실행하게 했다. CLI가 PATH에 없으면 홈의 `google-cloud-sdk/bin/gcloud`를 찾는다. 단기 토큰은 서버 메모리에 45분까지만 재사용하고 파일·응답·로그에 저장하지 않는다. 만료된 수동 환경 변수 토큰이 우선되지 않도록 앱 시험 경로에서는 이를 읽지 않는다. 프로젝트 ID는 `app/.env`의 `GOOGLE_CLOUD_PROJECT`로 지정한다.
- 검증: 가짜 CLI 시험을 포함한 `npm test` 118개, `npm run typecheck`, `npm run build`, `git diff --check` 통과. 실제 로컬 ADC로 토큰 발급 성공(값 출력 없음), 같은 경로로 Cloud TTS의 고정 합성 영어 문장에서 PCM 105,626바이트 수신. 수동 토큰 환경 변수 없이 `npm run tts:compare -- google-cloud` 실행도 성공해 영어/한국어 WAV를 다시 생성했다. 이는 별도 합성 요청 확인이며 실제 `/voice`의 마이크·학습 E2E는 아니다. 공급자 청구액은 확인하지 않았다.
- 문서 대조: 기준 설계의 Cloud 인증 흐름, README·`.env.example`의 실행법, PROGRESS의 시험 범위, CHANGELOG의 사용자 의미 변경을 갱신했다. 제품 정책·공급자 선택·TASK 상태는 바꾸지 않았으며 링크·상태 불일치는 발견하지 못했다.

## Cloud TTS 앱 청취와 Amazon Polly 후보 보완

- 로컬 앱 서버와 두 DB를 가동하고 마이그레이션을 완료했다. 사용자는 `/voice`의 분리형 Google Cloud Standard 경로를 직접 시험한 뒤 "문제 없어"라고 보고했다. 시험 발화 수·재생 지연·청구액·계정 한도는 측정하지 않았으므로 품질과 비용의 일반화 근거로 쓰지 않는다.
- 누락된 AWS TTS 후보를 공식 [Polly 가격](https://aws.amazon.com/polly/pricing/), [할당량](https://docs.aws.amazon.com/polly/latest/dg/limits.html), [음성 목록](https://docs.aws.amazon.com/polly/latest/dg/available-voices.html)으로 조사해 [비용 절감 검토안](../proposals/VOICE-COST-REDUCTION.md#2026-11-02--분리형-tts-후속-후보-조사-미승인)에 추가했다. Standard $4/100만 문자·80 TPS 기본 한도, Neural $16/100만 문자·8 TPS 기본 한도는 공식 공개값이며 Talkie 계정 실측값이 아니다. 동일 5,400문자 가정의 Standard 비용은 $0.0216으로 Cloud Standard와 같다. Polly 실제 호출·청취·청구·데이터 조건 확인은 하지 않았다.
- DEC-053의 AWS 분리형 경로 제외와 Polly 단독 TTS 요소 후보 조사는 범위가 다르다. 공급자 채택·코드·제품 약속·TASK 상태는 바꾸지 않았다. PROGRESS의 현재 확인 범위와 다음 지점을 갱신했고 PRD·DECISIONS·DESIGN·TASKS·CHANGELOG와 대조해 링크·상태 불일치는 발견하지 못했다.
