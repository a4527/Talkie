# 2026-10-31 작업 기록

## 종료 노트 선별 방향 합의(DEC-064)

- 사용자와 B-06의 종료 노트 AI 선별 연결 조건을 논의했다. 승인: 분리형 Gemini 텍스트 모델 재사용, 합성 사례 평가 기준(근거 인용 일치·지시문 비실행·연습일 비추정·숙달 비단정은 필수, 교육 품질은 직접 판정), 실패 시 자동 대체 없음, 저장 확정 원문 크기 기준 분할(대화 중 중간 요약 없음), 연결당 별도 상한 제거(계정/기간 허용 시간만 유지).
- 정정: 초기 설명에서 "15분 전후 세션 상한"을 확정으로 오해할 수 있었으나 문서상 15분 고정은 DEC-060/062로 대체돼 미채택이다. 연결당 상한은 수치 미정이었고 이번에 제거했다.
- 문서: DECISIONS(DEC-064)·PRD 6/9.2절·VOICE·LEARNING-NOTE·TASKS B-10·PROGRESS·검토안·CHANGELOG를 맞췄다. ADR-062/063의 과거 본문은 역사 기록이라 수정하지 않았다(DEC-064에서 변경 연결).
- 미정: 크기 한도·분할 크기·출력 한도·호출/재시도·시간 제한·평가 호출 수. 코드·모델 호출·TASK 상태 변경 없음.
- 남은 불일치: ADR-063과 API-USAGE-BUDGET 제안의 "연결당 최대 시간" 표현은 과거 기록으로 남아 있다. 발급 최대 시간을 남은 허용 시간으로 둘지는 B-10에서 정한다.

## 종료 노트 선별 순수 함수 구현

- `app/src/voice/note-extraction.ts`: 원문 크기 기준 턴 경계 분할(교정·재시도 묶음 유지, 분할 불가 블록은 자르지 않고 표시), 모델 결과 항목별 검증(턴 ID·화자·인용 일치, 응용 예문 표시 강제, 모델이 준 연습일 제거), 구간 병합(규칙 기반, 실패 구간 수 보고). 모델 호출·크기 한도 값·라우트 연결은 없다.
- 검증: `tests/note-extraction.test.ts` 10개와 전체 `npm test` 96개 통과(가짜 입력 한정). 실제 모델 출력·품질은 검증하지 않았다.
- 한계: `tsc --noEmit`은 `.next` 생성 타입이 없는 `src/app/api/learning/route`를 참조해 실패한다. 이번 변경 파일과 무관한 기존 생성물 문제로 보이나 원인은 조사하지 않았다.
- TASK 상태 변경 없음(B-06은 IN PROGRESS 유지). 남은 일: 프롬프트·공급자 요청 연결, 크기 한도·재시도 수치 결정, 합성 평가.

## 종료 노트 선별 프롬프트·요청 흐름 구현

- `note-extraction.ts`에 제안서의 시스템 프롬프트 반영(`NOTE_EXTRACTION_SYSTEM_PROMPT`), 구간을 JSON 데이터로만 직렬화하는 `buildExtractionInput`, 구간별 제한 재시도·검증·병합을 하는 `extractNote`를 추가했다. 모델 전송은 주입된 `generate` 함수이며 실제 모델 호출·라우트 연결·크기 한도/재시도 값 선택은 없다(호출자가 명시).
- 검증: `tests/note-extraction.test.ts` 13개, 전체 `npm test` 99개 통과(가짜 생성기 한정). 재시도 상한 내 복구, 모든 시도 실패 시 대체 노트 없이 실패 구간 보고, 지시문 포함 발화의 JSON 이스케이프를 확인했다. 실제 모델 출력·품질은 미검증.
- TASK 상태 변경 없음. 남은 일: Gemini 텍스트 `generate` 어댑터, 크기·재시도·시간 제한 수치 결정, 합성 평가.

## 종료 노트 선별 초기 수치 합의(DEC-065)와 반영

- 사용자와 크기·출력·재시도·시간·호출 상한·평가 호출 수·통과 기준을 논의해 추천안대로 승인(DEC-065). 기한 내 자동 재시도 구간당 누적 3회와 코드 상수 방식도 포함. 수치는 실측이 없고 실제 평가 후 조정하기로 했다.
- 코드: `NOTE_EXTRACTION_LIMITS`, 재시도 불가 오류 클래스, 시도/전체 시간 제한, 동시 3구간 제한, 구간 6개 초과·한도 2배 초과 블록의 미전송·`omittedChunks` 표시를 `extractNote`에 반영. 기한 내 자동 재시도(누적 3회)와 Gemini 어댑터는 미구현.
- 검증: `npm test` 102개 통과(가짜 생성기). 실제 시간 제한 동작은 단위 시험에서 직접 확인하지 않았다(기본값 상수 일치만 확인). 실제 모델 호출·품질·비용은 미검증.
- 문서 대조: DECISIONS·LEARNING-NOTE 설계·제안서·CHANGELOG에 연결. TASKS B-06/B-10 수용 기준은 "상한 확정" 부분이 충족돼 상태 변경 없음, PROGRESS는 아래 항목 반영.

## 마무리 정합성 점검

- 변경 파일의 상대 링크 깨짐 없음. `tsc --noEmit`은 기존 `api/learning/route` 생성 타입 문제 외 오류 없음. PROGRESS·DECISIONS에 남아 있던 "호출 한도 미정" 표현을 DEC-065 연결로 정리. ADR-062/063의 "연결당 최대 시간" 표현은 과거 기록으로 유지(DEC-064 연결). 스테이지된 diff에서 비밀값 패턴 없음.
