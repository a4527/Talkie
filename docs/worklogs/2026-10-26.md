- 구분: 테스트 환경 실험. 운영 장애·운영 성능 검증이 아니다.
- 연결 요구사항·작업: PRD 8.1의 이메일 공통 30초 발급 간격, B-01/D-02 관련 조사. TASK 완료 기준 충족이나 상태 변경을 뜻하지 않는다.
- 증상·가설과 판단 기준: 별도 제한 테이블 대신 인증 요청의 최신 발급 시각을 인덱스로 조회할 수 있는지 비교한다. 조회 지연뿐 아니라 발급 트랜잭션·동일 이메일 직렬화·저장 공간을 본다. 모든 조건에서의 일관된 우위와 반복 간 변동을 확인하며, 작은 차이만으로 채택을 결정하지 않는다.
- 실험 조건:
  - Node v24.22.0, PostgreSQL 16.15 Docker, Linux, i5-1335U, 논리 CPU 12개, OS 보고 메모리 약 15.5 GiB. Docker 자원 할당·동시간대 호스트 부하·CPU 사용률·I/O는 별도 계측하지 않았다.
  - 기존 로컬 records PostgreSQL 서버에 고유 이름의 `talkie_test_auth_bench_*` DB를 만들고 합성 이메일만 넣었다. 기존 앱 테이블/행/환경 파일은 수정하지 않았다. 서버 CPU·메모리·I/O는 개발 DB와 공유하므로 물리적 자원 격리는 아니다.
  - 1천 이메일 × 요청 3건(3천 행), 10만 이메일 × 요청 10건(100만 행). 동일한 로그인 목적 요청을 1~10시간 전 발급 상태로 채워 현재 보관 기간 내 데이터를 가정했다. 실제 이메일 수·목적별 비율·분포를 추정한 값은 아니다.
  - 분리안: 기존 이메일 기본 키 제한 테이블 + 요청 테이블. 통합안: 제한 테이블 없이 요청 테이블에 `(email_address, auth_link_issued_at DESC)` 인덱스 추가. 두 안 모두 기존 이메일·목적 인덱스, 토큰 고유 인덱스·관련 컬럼/검사를 재현했다.
  - 동시 연결 1/8/16개, 각 조합 3회, 회차마다 실행 순서 교대. 각 측정 직전 100건 준비 요청. 조회는 회차당 2천 건, 발급·경쟁은 각 400건. 측정 108회·총 100,800건(준비 요청 제외). 연결 풀 대기와 Node 왕복 시간을 지연에 포함했다.
  - 조회: 기존 이메일을 결정적 순서로 분산 조회. 발급: 서로 다른 새 이메일로 잠금→DB 시각→간격 조회→(분리안만 제한 행 갱신)→기존 링크 무효화→요청 삽입→커밋. 경쟁: 새 이메일 하나에 400건을 보내 최초 한 건 허용·399건 제한 검증.
  - 발급 트랜잭션은 `users` 조회, 로그인 세션 확인, HTTP/Next.js, 토큰 해시 계산, SMTP 전송을 제외했다. 전체 앱의 응답 시간이 아니다. 잠금·DB 시각·요청 기록 쓰기는 두 방식에 공통으로 포함했다.
  - 준비 후 VACUUM ANALYZE, 조회 EXPLAIN ANALYZE/BUFFERS와 인덱스 포함 테이블 크기를 저장했다. 캐시를 비우지 않은 준비된 캐시 위주 실험이며 콜드 캐시·장시간 부하·삭제 정리·테이블 팽창·큰 이메일 편중은 미검증이다.
  - 중단 기준: 쿼리 5초·잠금 3초 제한, 전체 실행 4분 제한, 최대 연결 16개. 오류 또는 기대한 발급/제한 건수 불일치 시 실패 판정. 종료 시 생성한 시험 DB만 삭제한다. 유료 API·실제 메일 전송 없음.

### 조사 · AI 후보 평가 계획 (D-03)

- 구분: 문서 조사와 제안서 작성. 유료 API 호출·구현·실험 없음. 외부 자료는 공식 문서와 2차 자료를 구분해 [계획 초안](../proposals/ai-candidate-evaluation-plan.md)에 출처와 한계를 남겼다.
- 사용자 결정: 후보를 OpenAI Realtime·Gemini Live·AWS 분리형으로 갱신(DEC-050). 구독 연결은 공식 문서상 호스팅 앱 대상 제한 시범이며 오디오 입력이 미지원이라 PRD 10절을 유지했다.
- 확인한 사실(공식): Gemini Developer API 악용 감시 로그 55일(사용자 제공 표와 공식 usage-policies 검색 결과 일치)로 DEC-025의 30일 상한 미충족. OpenAI gpt-realtime-2.1 가격·컨텍스트 128k·단기 키 기본 10분(최대 2시간)·오디오 토큰 환산(사용자 1토큰/100ms, AI 1토큰/50ms)·대화 전체 재전송과 캐시. WebRTC에서는 서버가 재생량을 알고 미재생 오디오를 자동 절단하지만 절단된 전사문은 제공하지 않는다. Polly 한국어 음성·가격, Transcribe 한국어 스트리밍·US East 예시 가격.
- 미확인·한계: OpenAI 한국어 지원 공식 목록, Gemini Vertex 경로의 실제 적용 조건(사용자 제공 표 기준), Transcribe 서울 리전 가격·보관, Transcribe·Polly의 AI 서비스 옵트아웃 필요성(2차), Speak 한국 앱스토어 요금제 매핑(조회 결과 불명확), 정기결제 PG 수수료. 분당 비용은 실측이 아닌 가정 계산이다.
- 사용자가 붙여 넣은 Gemini API 추가 서비스 약관(2026-03-23 시행)에서 만 18세 미만 접근 가능 서비스 사용 금지, 유료 서비스의 국외 일시 저장·캐시, Cloud Billing 활성화 시 유료 취급을 확인해 계획 초안에 반영했다. 약관에는 보관 일수가 없으며 55일은 별도 정책 페이지 값이다. OpenAI는 공식 under-18 가이드상 미성년 서비스를 금지하지 않지만 COPPA 준수·연령 확인·13세 미만 개인정보의 ZDR 없는 처리 금지를 안내하며 Business Terms 본문은 403으로 읽지 못했다. AWS는 Polly·Transcribe·Bedrock 연령 조항을 찾지 못했고 서울 리전은 Transcribe 스트리밍·Bedrock runtime만 2차로 확인했다.
- 사용자가 붙여 넣은 Gemini 데이터 로깅·공유 문서(2026-10-14 갱신)는 개발자 소유 프로젝트 로그(기본 55일, AI Studio에서 7·14·28·55일 설정)를 다루며 악용 감시 로그와 별개다. 악용 감시 로그는 정책 페이지에서 55일을 직접 재확인했고 설정 변경 가능 여부는 문서에 없다. 따라서 Gemini Developer API의 DEC-025 30일 상한 미충족은 바뀌지 않는다. 데이터 세트 공유와 참여자 등급은 학습 사용이라 사용하지 않는다.
- 사용자가 붙여 넣은 OpenAI 서비스 계약(효력 2026-01-01)과 이용정책(시행 2026-11-20)에서 고객 콘텐츠의 서비스 개선 미사용(4.2), 미성년자의 부모 동의 없는 사용 허용 금지(3.3 c), 지원 국가 밖 접근 금지(16.12), 베타 서비스 무보증(12.3) 등을 확인해 계획 초안에 반영했다. AWS 서비스 약관(2026-09-15 개정본)·고객 계약(2026-08-14) 한국어 번역 PDF는 사용자가 poppler를 설치한 뒤 텍스트로 추출해 읽었다. Transcribe·Polly는 50.3에 따라 옵트아웃 정책 미적용 시 AWS가 AI 콘텐츠를 서비스 개선에 쓰고 다른 리전에 저장할 수 있어 DEC-025 충족에는 AWS Organizations 옵트아웃 정책이 필요하다. Polly·Transcribe·Bedrock에는 연령 제한 조항이 없고 최종 사용자 개인정보 고지·동의는 고객 책임이다(50.4). Bedrock 오용 탐지 대상 모델은 입출력 최대 30일 저장(50.12.2), Transcribe·Polly 보관 일수는 약관에 없다. 번역본이며 영문본이 우선하므로 실제 적용 전 영문본 확인이 필요하다.
- 사용자 결정: 대상 연령은 만 18세 이상 전용(DEC-051). PRD 2절, DECISIONS, TASKS D-02, PROGRESS, CHANGELOG에 연결했다. 가입 시 연령 확인 방식은 미정이다.
- 사용자 결정: 보관 일수를 아직 확인하지 못한 AWS·Gemini도 스모크에서 함께 시험하고, OpenAI 비용이 과도하면 보관일수 완화를 논의한다(DEC-052). 학습 금지는 유지한다. 음성 전달 금지의 유예는 합성 대화·개발자 본인 음성 실험에 한정하며 보관 상한 변경은 채택하지 않았다.
- 사용자 결정: AWS 분리형을 제외하고 저가형 분리형을 추가했으며 시험 순서는 저가형 분리형 → Gemini Live → OpenAI Realtime이다(DEC-053). 이유는 저렴한 후보가 성능을 충족하면 비싼 후보가 필요 없다는 판단이다. 같은 날 저가형 구성 요소(음성 인식·텍스트 모델·음성 합성)의 한국어 지원·공식 가격·데이터 조건을 조사했고 결과를 계획 초안의 '저가형 분리형 후보 구성'에 제안으로 정리했다. 한국어 품질과 정확도 수치는 확인하지 못했고 여러 업체의 학습·보관 조건이 미확인이다. 가격은 조회 시점 값이며 일부는 2차 자료다.
- 사용자 결정: 구성 요소별로 2~3개씩 후보를 두고 한 요소씩 바꿔 시험하며, 성능 기준은 사전에 정하지 않고 직접 말하고 들으며 정한다. Gemini Live와 OpenAI Realtime도 한 번씩 시험한 뒤 최종 결정한다(DEC-054). DEC-053의 상위 후보 시험 생략 전제를 대체했다. 같은 날 Claude Haiku 5.5의 가격(입력 $0.10·출력 $0.50, 100K 이하 프롬프트, Anthropic API 가격표 2026-10-06 캐시), 학습 미사용(기본), 보관(고객센터는 30일 이내 삭제, 개발자 문서는 기본 미보관으로 서술이 다름), 한국어(공식 표에는 Haiku 4.5만 영어 대비 93.3%, Haiku 5.5는 미확인)를 확인했고 OpenAI 소형 모델·전사·TTS의 공식 가격, Gemini TTS의 한국어·스트리밍 지원, Soniox 보안 문서, Pipecat의 서비스 지원 표를 확인해 계획 초안에 반영했다.
- 하니스 작성(D-03): 사용자가 후보 세트·기본 조합과 하니스 제작을 승인했다. `harness/voice-eval/`에 Pipecat 1.14 기반 시험 도구를 만들었다(구성 매트릭스 9개, 호출 전 최대 비용 예약 장부, DEC-052 학습 정책 확인 게이트, 발화 내용 비저장 결과 기록과 7일 정리, 청취 점수 CLI). 서비스 클래스와 생성자는 설치본의 공식 CLI 템플릿과 소스로 확인했다. 검증: `uv run pytest` 22개 통과(구성·단가·장부·기록 삭제·모든 요소 가짜 키로 생성), 9개 구성의 파이프라인 오프라인 조립 확인, `--check`의 키 존재·정책·비용·한도 출력 확인. 한계: 네트워크·유료 호출과 브라우저 음성 세션은 실행하지 않았고 공급자 키·결제는 사용자가 설정해야 한다. 단가표 일부는 2차 자료·가정이다(Gemini TTS 초당 토큰, OpenAI TTS 토큰 환산). Deepgram `mip_opt_out`은 넣지 않았다. 이전에 PDF 추출용 라이브러리 설치가 권한 검사에서 거부되어 사용자가 poppler를 설치했고 그 임시 파일은 삭제했다.
- 후속: 예산 배분·시나리오 수·월 한도·역할 B 후보를 합의하고 DEC-025 충족 후보만 스모크한다.
