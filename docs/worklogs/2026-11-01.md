## 종료 노트 선별의 요청·정비 작업 연결

- 사용자 승인: AI 호출을 트랜잭션 밖에서 하는 방식. 확인 중 `db/index.ts`의 `idle_in_transaction_session_timeout` 15초·`statement_timeout` 10초 때문에 잠금 안 호출은 설계상 불가능함도 확인했다.
- 코드: `learning.ts`의 `completeLearningNote`를 (1) 짧은 트랜잭션에서 상태 확인·행 캡처 → (2) 잠금 없이 `extractVoiceNote` → (3) 다시 잠그고 상태 재확인 후 저장 3단계로 분리했다. `finalizeLearningNote`는 음성 세션에 추출 결과가 없으면 아무것도 저장하지 않는다. 정비 작업은 사용자 트랜잭션에서 대상만 모으고 트랜잭션 밖에서 호출한 뒤 별도 트랜잭션에서 저장한다. 사용 가능한 구간이 하나도 없으면 `pending`·작업 행을 유지해 다음 실행에서 재시도하고 기한이 지나면 기존대로 `expired`가 된다. `note.ts`는 학습 상세 항목을 `extra-N` 앵커로 렌더링하고(응용 예문 표시, 일부 실패 시 누락 안내) 상단 맥락 읽기는 바꾸지 않는다. 상태 값은 추가하지 않았다.
