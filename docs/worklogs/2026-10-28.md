# 2026-10-28 작업 기록

## Google 로그인 병행 문서 반영

- 사용자 승인에 따라 PRD 8.1을 먼저 갱신하고 DEC-057/ADR-057, DEC-020 후속 상태, design, D-02/B-01 수용 기준, PROGRESS, CHANGELOG를 대조했다.
- 이메일 링크 유지·Google 추가·공통 앱 계정/세션 방향만 확정했다. 계정 연결/중복/해제·Google 전용 가입자의 이메일/탈퇴 재확인 등은 미정이다.
- 코드·의존성·DB·키 설정은 변경하지 않았다. Google 구현·검증은 없고 작업 완료 상태도 변경하지 않았다.
- 점검: 관련 문서의 DEC-057·ADR 링크와 상태를 확인하고 git diff --check를 수행했다. 미확정 상세는 D-02/B-01에 연결했으며 이번 변경 범위의 남은 문서 불일치는 없다. 문서 변경으로 실행 테스트는 수행하지 않았다.

## 문서 위치·파일명 정리

- 사용자 요청으로 AGENTS.md·README.md·CLAUDE.md를 기존 위치에 유지하고 나머지 Markdown 문서를 docs/로 모았다. 기존 docs/ 하위 분류를 유지하고 하니스 안내는 docs/harness/voice-eval/로 이동했다. 파일명은 대문자, 확장자는 .md를 유지한다.
- AGENTS의 경로·문서 규칙, README와 문서 간 상대 링크, 하니스의 문서 안내 경로를 갱신했다. 제품 요구사항·결정 내용·작업 완료 상태는 이 정리로 변경하지 않았다.
- 검증: 46개 문서의 이동·이름 변경과 이동 전후 파일 대응·본문 보존을 점검했다. 로컬 Markdown 링크 대상 299개가 모두 존재하며 이전 파일 경로는 남아 있지 않다. 이전 경로 참조 검색 결과는 새 docs/ 경로 안에 포함된 부분 문자열뿐이었다. git diff --check를 통과했고 PRD·TASKS·DECISIONS의 상태와 PROGRESS·CHANGELOG 연결을 대조했으며 이번 변경 범위의 남은 불일치는 없다. 실행 로직 변경이 없어 앱 테스트는 생략한다.

## 문서별 책임과 기록 기준

- 사용자 요청으로 PRD·DESIGN·ADR·DECISIONS의 책임을 검토했다. [AGENTS의 문서별 책임](../../AGENTS.md#document-ownership)에 기준 위치·허용 요약·변경 순서·충돌/이관 규칙과 주변 문서의 역할을 구체화하고 PRD·DESIGN·DECISIONS의 안내를 맞췄다. 결정 기록 형식의 상세 규칙은 DECISIONS에 유지한다.
- 핵심 조건을 ADR에서 모두 지우지 않고 결정 당시 승인 범위를 식별할 만큼 보존한다. 현행 제품 명세와 구현 계약은 각각 기준 문서로 연결하며 기존 결정의 동의·상태·대체 관계는 변경하지 않았다.
- 제품 동작·DB/API 계약·작업 상태·기존 ADR 본문은 변경하지 않았다. DESIGN의 상세 분리와 기존 본문의 중복 축약은 후속이다. DESIGN의 음성 미구현 표현과 비공개 연결 구현 설명, DB 스키마 미정 표현과 현행 테이블 설명, 버퍼 상한 미정 표현과 초기값 설명의 범위 구분도 남는다. 앞선 이관 점검의 “불일치 없음”은 경로 변경 범위의 점검이며 본문 전체의 최신성 판정이 아니다.
- 점검: 변경 파일의 문서 책임과 DECISIONS의 ADR 분리/대체 규칙을 대조했다. 변경 문서 7개의 로컬 링크 대상 114개와 문서 책임 앵커를 확인했고 git diff --check를 통과했다. TASK 수용 기준·승인된 제품/기술 결정을 변경하지 않아 해당 기준 본문은 유지한다. 문서 변경으로 실행 테스트는 생략한다.

## 승인된 1차 설계 분리

- 사용자가 변경 위치·이유를 설명한 1차 변경안에 “그래 승인할게”라고 동의해 실행했다. DESIGN 본문을 API·DATABASE·AUTHENTICATION·LEARNING-PERSISTENCE·VOICE·LOCAL-OPERATIONS의 6개 상세 문서로 나누고 전체 구조·데이터 흐름·상태/제약·기술적 가정은 DESIGN에 남겼다. 169줄의 진입점을 63줄로 정리했다.
- 제품 정책은 PRD, 선택 이유는 기존 DECISIONS/ADR, 날짜별 결과는 기존 worklog, 하니스 장부 호환성은 기존 하니스 README로 연결했다. 새로운 정책·기술 결정을 채택하지 않았다. Google 로그인은 승인된 미구현 범위로 유지했다.
- 실제 라우트·서비스·타입·스키마·정리 코드를 읽어 현재 요청/응답·9개 테이블·저장/복원·초기값을 대조했다. 기존 DESIGN의 음성 토큰 응답 `{token, seconds}`를 현행 `{voiceConnectionToken, testDurationSeconds}`로 설명했다. 실제 공급자 스모크와 전체 학습 통합, 로컬 초기값과 운영 목표, 현행 스키마와 미정 운영 구성을 구분했다. 코드/API 자체의 변경은 없다.
- 기존 DESIGN 절 앵커를 새 상세 문서 안내에 보존하고 기존 참조 8곳을 새 문서 또는 범위 요약으로 갱신했다. AGENTS의 단일 표에 상세 문서 탐색 경로를 연결하고 PROGRESS·CHANGELOG를 갱신했다. 다른 ADR·제안서·이전 worklog의 변경은 링크 목적지에 한정했다.
- 점검: 문서 전체의 로컬 링크 406개(절 앵커 92개 포함), 기존 DESIGN 앵커 전체와 소스 파일 71개의 해시 보존을 확인했다. 변경 Markdown 17개(신규 6개 포함)의 공백·본문 변경 범위와 AGENTS의 단일 표를 점검하고 git diff --check를 통과했다. PRD·TASKS·DECISIONS 본문과 수용 기준·상태는 작업 시작 시점과 동일하다. 문서 변경으로 앱 실행 테스트·실제 공급자 호출은 하지 않았다.
- 남은 범위: 결정/ADR 본문 중복 정리·DEC-055의 ADR 이관, PROGRESS 과거 이력 및 제안서 분류, TASKS 명세 중복 축약은 후속 승인 대상이다. 이들의 기존 표현 불일치를 이번 상세 분리로 모두 해결했다고 판정하지 않는다.

## 문서 책임에 따른 정리와 재로그인 범위 확정

- 문서 검토 결과에 대해 사용자가 시험 예외의 표현·로컬 MVP/실제 운영 분리와 제안 2·3·4의 이관·중복 축약에 동의했다. 로그인과 재로그인은 이메일 또는 Google을 모두 지원한다고 명시했다. PRD를 먼저 갱신하고 DEC-057 후속·DEC-020/046의 대체 범위, 인증 설계와 D-02/B-01 수용 기준을 맞췄다. 백업 복원 후 인증 전체 무효화와 Google 계정 연결·탈퇴 재확인의 미정 범위는 유지한다.
- PRD의 공급자 조건을 실제 사용자·무료 비공개 로컬 시험·유료 후보 실험으로 구분했다. DEC-056을 유료 호출 승인 확대로 해석하지 않고 DEC-052의 기존 시험 유예 범위를 연결했다. 무료 시험 예외를 실제 사용자/공개 배포에 적용하지 않는다. 로컬의 확정 구성·초기값과 운영 결정/검증을 분리했다.
- 주제 선택은 PRD 7절, 저장 실패·노트 선별·임시 원문·지속 기록·음성/공급자는 PRD 8절의 주제별 절을 기준으로 삼는다. 개발 순서·비교 순서는 TASKS, 연결/포트 경계는 VOICE, 기한 작업은 LOCAL-OPERATIONS, 실험 절차는 ENGINEERING-VALIDATION으로 연결했다. 기존 제품 동작의 검증 가능한 경계와 예산·보관 기한은 유지한다.
- FIRST-LEARNING-FLOW의 실제 제품 보관 정책 반복을 링크로 바꾸고 B-00의 화면·상태·검증 기준은 유지했다. HTTP 출처/캐시 규칙은 API, 인증/소유자 검증은 AUTHENTICATION에 둔다. 로컬 로그의 제품 제약은 PRD로 연결하고 구현 문서의 반복을 줄였다.
- ADR-024/034의 긴 시험 목록은 결정별 위험 요약과 TASKS/설계 연결로 축약했다. ADR-049의 상세 컬럼/삭제 절차는 DB·학습 저장·인증 설계로 연결했다. 결정일·승인 근거·이유·대안·위험 수용·이관 보존 계약은 유지하며 결정 당시 미구현/미정 상태를 최신 구현에 맞춰 다시 쓰지 않았다.
- DATABASE에서 이관 작업 이력을 현행 호환성 계약과 분리했다. 이관 사실의 원래 근거는 2026-10-25 worklog(DEC-049 이관 시 초기 0번·순번·snapshot_hash·대화·확정 위치·과거 NULL 시각 보존)와 2026-10-27 worklog(런타임 명명 정리 시 기존 JSON 키·해시 보존, 해당 명명 정리로 SQL/데이터 이관 없음)다. 이번 작업에서 이관을 다시 실행하거나 검증한 것은 아니다.
- DESIGN·VOICE에는 현재 구조와 미통합 경계를 남기고 실제 공급자 스모크 결과는 PROGRESS/기존 worklog로 연결했다. PROGRESS·CHANGELOG에 이번 승인 범위와 남은 일을 반영했다. Google·운영 기능의 구현/검증 완료나 TASK 상태 변경은 없다.
- 점검 결과: 변경 문서의 상대 링크·절 앵커, 기존 DESIGN 앵커, ADR 결정일/승인 근거와 TASK ID/완료 상태를 대조했다. git diff --check를 통과했다. 재로그인 방법 확정 이외에 보관 기한·예산·탈퇴 재확인·계정 자동 병합 정책을 변경하지 않았다. 앱 코드·의존성·DB 변경이 없어 실행 테스트·외부 공급자 호출은 수행하지 않았다.
- 남은 범위: Google 계정 연결·전용 가입자의 탈퇴 재확인·운영 인증/백업·장기 저장 실패·음성 전체 통합은 해당 TASK의 미완료 범위를 유지한다. DEC-055 ADR 이관·PROGRESS 과거 이력/제안서 분류·TASKS 전반의 명세 중복 축약은 이번 검토에서 제안한 정리 범위 밖의 후속이다. 이번 변경 범위의 링크/승인 상태 불일치는 없다.
