# 사용자 흐름 설계

작성일: 2026-10-29. 제품 기준은 [PRD 4절](../PRD.md#4-주요-사용자-흐름)·[6절](../PRD.md#6-대화-상태와-예외)이고, 이 문서는 그 약속이 사용자 눈에 어떤 순서로 나타나는지를 단계별로 풀어 쓴다. 요구사항·정책 조건을 새로 정하지 않으며, 조건이 필요하면 PRD·DEC 링크로 연결한다.

순서도는 흐름이 확정된 뒤 추가한다. 지금은 글 목록으로만 적는다.

## 범위와 읽는 법

- 대상은 실제 제품의 학습 흐름이다. B-00 가짜 AI 프로토타입의 화면·상태·검증은 [FIRST-LEARNING-FLOW](FIRST-LEARNING-FLOW.md)를 따른다.
- 각 흐름은 **시작 조건 → 단계 → 분기·예외 → 관련 항목** 순서로 적는다. 관련 항목은 요구사항 ID(F-*)와 작업 ID(B-*)다.
- 표기: **현재 구현**은 로컬 시험으로 확인된 범위, **승인·미구현**은 결정됐지만 구현 전, **미정**은 합의 전이다. 구현 상태의 기준은 [TASKS](../TASKS.md)·[PROGRESS](../PROGRESS.md)이며 이 문서는 구현 완료를 뜻하지 않는다.

## 1. 시작

승인·미구현: 기존 진행 세션 확인 → 후보 추천/직접 선택 → 선택한 미션 구성·검증 → 역할·목표·모드·수준 확인 → 연결·이용량 차감. 정의·버전·선택 조건을 같은 세션에 고정한다. 상세는 [미션 설계](MISSIONS.md)를 따른다.

## 2. 일반 대화

기존 앵커를 유지하며 현행 흐름은 상대역과 미션 수행이다. 확인된 발화와 목표 상태를 기록한다. 복잡한 상황은 내부 목표를 유지하며 이어간다. 모드별 도움·무진전 처리는 PRD 4.2~4.3절을 따른다.

## 3. 교정과 다시 말하기

연습에서 교정·힌트·재시도를 제공하고 실전에서는 상대역의 자연스러운 확인만 제공한다. 교정 상태는 목표 상태와 별도로 기록하며 도움은 감점하지 않는다. 전달/재생이 확인되지 않은 응답은 근거로 확정하지 않는다.

## 4. 종료와 복습

목표 충족 또는 실전 무진전 실패 → 상대역의 마지막 대사 → 잔여 기록 저장 → 종료 평가·노트 정리 → 결과 표시. 사용자 명시 종료도 기존 정리 경로를 사용한다. 기록 저장 대기·부분 노트·실패는 기존 저장 설계를 따른다. 점수 미달로 대화를 되살리지 않는다.

## 5. 중단·재개·자동 종료

브라우저 이탈·연결 장애는 중단으로 기록하고 마지막 확정 상태에서 재개한다. 기존 24시간 기한·자동 종료/재개 경쟁 제어는 유지한다. 미션 정의·난이도·모드·목표 상태도 복원하며 같은 미션을 중복 차감하지 않는다. 만료는 이미 획득한 당일 다른 미션의 달성 기록을 취소하지 않는다. 노트 날짜와 달성 일수 날짜를 임의로 동일시하지 않는다.

## 앱 화면 지도

전환 전 로컬 데모의 화면 구성이다(DEC-068). 미션 화면은 승인·미구현이며 아래는 현 구현을 설명한다. 각 화면의 상태·데이터 계약은 위 흐름과 [API](API.md)를 따른다.

| 화면 | 역할 | 연결 흐름 |
| --- | --- | --- |
| `/` | 소개·시작. 로그인 상태면 홈으로 안내 | 1 |
| `/try` | 로그인 없는 텍스트 체험(가짜 튜터·메모리만) | B-00 |
| `/login`, `/account/confirm` | 이메일 링크·Google 로그인, 메일 링크 확인 후 홈 | PRD 8.1 |
| `/home` | 오늘 대화 시작 또는 멈춘 대화 이어서 하기, 요약, 최근 노트 | 1, 5 |
| `/talk` | 방식(음성·텍스트)·음성 경로 선택과 데이터 안내 확인 → 대화(전사·오늘의 표현·남은 연결 시간·멈추기/종료) → 종료 피드백 노트 | 1~5 |
| `/notes`, `/notes/[날짜]` | 한국 종료일별 노트 목록·상세·Markdown 다운로드 | 4 |
| `/account` | 로그인 수단·Google 연결/해제·로그아웃·탈퇴 확인/확정 | PRD 8.1/8.2 |

진행 중인 대화가 있으면 대화 화면은 그 방식으로만 이어서 하게 하고, 다른 방식은 그 대화를 마친 뒤 시작한다(DEC-032의 계정당 진행 대화 하나).

## 이 문서에 쓰지 않는 것

- 정책 수치·보관 기한·비용은 PRD, 선택 이유는 [DECISIONS](../DECISIONS.md), 저장·API·음성 계약은 각 상세 설계에 둔다.
- 날짜별 구현·검증 결과는 worklog에 둔다.
