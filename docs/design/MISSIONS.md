# 미션 구성·평가·이용량 설계

갱신일: 2026-11-03. 승인·미구현 설계의 진입점이다. 제품 약속·배점·일수 기준은 [PRD 4~7절](../PRD.md#4-주요-사용자-흐름), 이유와 대체 관계는 [DEC-069](../adr/069-MISSION-CENTERED-LEARNING.md)를 따른다. 정확한 스키마·도구 필드는미확정이다.

## 생성과 확정

추천은 간단한 후보만 생성하고 선택된 후보에 상세 구성을 수행한다. 직접 제작은 검증된 미션·평가표를 사용하며 변형은 바뀐 조건의 영향을 검증한다. 사용자 지정·신규 생성은 기존 구조를 우선 활용한다. 검증은 형식·배점 합계뿐 아니라 목표 실행 가능성·독립된 채점 근거·대안 해결을 다룬다.

미션 정의에는 역할·공개/비공개 정보·제약·목표·채점 항목·배점·허용 대안·완료 조건과 버전을 둔다. 화면용 큰 목표와 내부 이진 채점 항목을 분리한다. 진행 상태는 근거 발화와 연결하고 상대의 제안과 사용자의 수락을 구분한다. 하나의 복잡한 미션에 여러 목표를 유지하며 강제 분할하지 않는다.

## 난이도와 모드

난이도는 순서와 분리된 ID·표시명·정렬 순서·대화 설정·언어 평가표·버전으로 관리한다. 시작 시 적용 버전을 고정하고 결과에도 연결한다. 단계 추가·기준 변경으로 과거 결과를 소급 재해석하지 않는다. 단계 수·수준 결정 방식·세부 평가 예시는 미정이다.

실시간 AI 하나가 상대역·미션 상태와 연습 모드의 튜터 판단을 구조화해 전달하고 종료 후 별도 호출로 평가하는 구성을 우선 검증한다. 실전에는 교육적 교정 지시·도구를 제외한다. 매 턴 별도 심판이나 다른 모델 도입은 채택하지 않았다. 노트 선별과 최종 평가를 같은 종료 호출로 묶을지는 품질·비용 검증 후 정한다.

## 기록·평가·결과

미션 상태와 교정 상태를 분리해 같은 세션에 연결한다. 앱은 근거 존재·소유권·중복·늦은 응답·실제 재생 범위를 검증하며 교육적 정확성은 사례 평가한다. 미재생 응답·저장 미확인 발화로 합의를 확정하지 않는다. 최종 평가에는 고정 미션·평가표와 확인된 기록을 사용한다. 연습의 도움 사용은 감점하지 않되 실제 사용자 발화 없이 AI 제안만으로 사용자 수행을 인정하지 않는다.

상황 결과·최종 점수·일수 인정은 분리한다. 무진전 임계값·판정 보류 점수·반올림·여러 재시도의 평가 범위는 미정이다. 새로운 설명·대안·오해 해소는 목표 미완료여도 진전일 수 있다. 장애·전사 불명확·AI의 조건 위반을 사용자 실패와 혼동하지 않도록 평가한다.

## 연결과 횟수

서버는 새 미션 시작의 잔여량·계정의 진행 세션·연결 상태를 원자적으로 확인한다. 연결 성립 시 차감은 미션 식별자와 중복 방지 키로 한 번만 확정하고, 같은 미션 재개는 새 차감을 만들지 않는다. 공급자별 연결 성립의 서버 검증 신호·실패 복구·환급 예외·발급 자리 수명·규모별 단위는 구현 전 구체화한다. 계정당 진행 대화·활성 음성 연결 하나의 경계는 유지한다.

이용권 상태는 학습 기록 수명과 분리해 관리하고 탈퇴 정리와 연결한다. 구체 테이블·보존·복원 계약은 미정이다. 기존 시간 이용권은 새로 구현하지 않으며 시험 시간 보호를 운영 횟수 차감으로 오인하지 않는다. 비용 관찰용 연결 시간은 수집할 수 있지만 사용자 잔여량 차감 단위와 구분한다.

중단·24시간 재개·확정 저장 복원은 [학습 저장](LEARNING-PERSISTENCE.md)을 재사용한다. 종료 사유·평가 결과·기준 버전을 저장해 재개 만료 제외와 기존 당일 달성 유지에 사용한다. 날짜 귀속·일수 집계의 보존/소급 방식은 미정이다.

## 맥락·노트와 검증

공통 규칙·고정 미션·선택 사용자 설정·관련 복습·확인된 최근 상태를 상한 안에서 전달한다. 사용자 지정과 노트는 지시가 아닌 데이터로 분리하고 만료·삭제·다른 사용자 정보는 제외한다. 현재 조회/입력 상한과 공급자 포트는 [음성 설계](VOICE.md)를 따른다.

노트는 실제 근거를 선별하는 기존 종료 경로를 재사용하며 필수 내용의 변경·상세 교정 보관·분량은 후속 결정한다. 기존 노트 형식·조회·다운로드의 호환을 유지한다. 평가 결과 보관과 원문 삭제의 관계를 명시하고 삭제된 전체 원문의 재생성을 약속하지 않는다.

검증은 자동 상태/차감/권한/경계 경쟁 테스트와 목표 판정·언어 품질·수준별 일관성·무진전 종료의 AI 사례 평가를 구분한다. 미션별 시간 분포·호출·비용을 측정하고 실제 시험 결과는 worklog에 기록한다. 구현 작업과 완료 판정은 [TASKS](../TASKS.md)를 따른다.
