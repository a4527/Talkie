# 음성 연결 설계

갱신일: 2026-10-30. `/voice`는 로컬 로그인 후 사용하는 비공개 본인 음성 시험이다. 화면 메모리만 쓰는 기존 시험과 계정별 저장·재개·교정 상태·근거 노트를 연결한 저장 학습을 제공한다. 실제 공급자의 구조화 교정·재시도 품질과 전체 P0 노트 선별은 미검증/미완성이며 검증 상태는 [PROGRESS](../PROGRESS.md)를 따른다.

## 포트·어댑터 경계

공통 학습 코드가 공급자 SDK·WebSocket 메시지를 직접 다루지 않도록 `app/src/voice/port.ts`에 음성 연결·입력·전사·출력·중단·종료 계약을 둔다. 초기에는 Next.js 한 앱에서 구현한다. Gemini Live 어댑터와 분리형 STT→LLM→TTS 어댑터가 공급자 메시지를 이 이벤트로 바꾸고 브라우저 장치 처리는 별도 `BrowserAudio`가 담당한다. 별도 음성 서버·MSA·독립 배포는 채택하지 않았다. 실제 확장·장시간 연결·실행 환경 필요가 관측되면 원격 통신 어댑터와 서버 분리를 재논의한다.

음성 메모리 항목은 `VoiceTranscriptTurn`, 갱신 함수는 `updateVoiceTranscriptTurns`, 파일은 `voice/transcript.ts`다. Gemini 전용 설정은 `gemini-live-setup.ts`에 둔다. 내부 단위는 `sampleRateHz`·`testDurationSeconds`·`nextPlaybackTimeSeconds`로 명시하고 외부 Web/공급자 API 필드는 유지한다.

구현: [음성 포트](../../app/src/voice/port.ts), [전사 처리](../../app/src/voice/transcript.ts), [Gemini 설정](../../app/src/voice/gemini-live-setup.ts), [서버 토큰](../../app/src/server/voice-token.ts). 채택 근거는 [DEC-055](../DECISIONS.md#dec-055)를 따른다.

## 직접 연결과 자격 증명

브라우저는 로그인·동일 출처·시험 확인을 거쳐 [토큰 API](API.md#비공개-음성-토큰-api)를 호출하고 받은 단기 토큰으로 공급자에 직접 연결한다. 장기 API 키는 서버 환경에만 두고 본문·오류·로그에 출력하지 않는다. 브라우저 직접 경로부터 검증하고 사용량 차단·취소·실제 재생 범위·기록 동기화 조건을 충족하지 못하면 서버 중계도 비교한다. 최종 운영 경로를 확정한 것은 아니다([DEC-030](../DECISIONS.md#dec-030)).

## 생성·재생·전사 범위

입력 전사에는 영어·한국어 언어 힌트와 `VERBATIM` 모드를 사용한다. 영어 발화를 한글 음차로 표시하거나 인식 단계에서 문법을 먼저 고치는 일을 줄이기 위한 설정이며 언어 고정이나 정확도 보장은 아니다. 앱은 공급자 전사문을 임의 번역·역음차하지 않는다. 튜터에는 영어 원문/실제 한국어를 보존하고 불확실하면 교정보다 확인을 요청하도록 지시한다.

포트의 `response-complete`는 생성 완료이며 재생 완료가 아니다. `transcript.ts`는 생성 전사문을 미확인으로 표시하고 브라우저 출력 큐가 끝난 경우에만 재생 완료를 표시한다. 중단된 응답은 정확한 단어별 청취 위치를 알 수 없어 전체를 근거에서 제외하는 보수적 초기 구현이다. 이는 실제 청취나 학습 성공의 증거가 아니다. 저장 학습은 `record_learning_result` 도구의 구조화 결과를 포트 이벤트로 받는다. 사용자 입력 완료·AI 생성 완료·재생 완료를 구분하고 원문 일치와 실제 재생된 교정 표현의 존재를 확인한 뒤 교정·재시도 상태를 반영한다. 중복/취소된 결과·중단/늦은 출력은 근거에서 제외한다. 도구 결과가 없거나 근거와 다르면 앱이 교정을 추정하지 않는다. 프롬프트와 도구 설명에는 매 사용자 발화의 기록 호출, 교정 제시/다시 말하기 요청 시 대기 상태, 실제 재시도 성공 시 일반 대화 복귀·실패 시 짧은 수정 후 재요청을 명시한다. 기존 교정의 재시도는 새 교정으로 복제하지 않고 시도 결과만 전달한다. 인식이 불확실하면 판정을 보류하고, 주제 변경/재시도 거절을 실패로 기록하거나 대화를 차단하지 않는다. 이는 기존 PRD 4.3/F-05의 구현 지시이며 프롬프트만으로 AI 준수를 보장하지 않는다. 도구만 출력한 단계의 `turnComplete`는 답변 완료로 내보내지 않는다. 해당 도구의 입력/출력 연결을 유지해 뒤따르는 실제 전사·음성 출력과 묶고, 그 전에 중단되면 대기 근거를 버린다. 공급자가 도구를 출력하는 시점·전사 정확도·판정 품질과 중단 중 공급자 내부의 미재생 맥락까지 정확히 동기화하는 검증은 남는다.

## 장치와 로컬 시험 제한

마이크는 PCM16을 휘발성 작업 버퍼로만 보내고 응답 PCM은 Web Audio로 재생한다. 중단 시 출력 큐를 비우며 종료·실패·화면 이탈 시 장치·연결·재생 자원을 해제한다. 화면 전사문은 최대 최근 100개·각 6천 자로 메모리에만 유지한다. 3분 타이머·토큰 1회 사용·발급 후 1분 새 연결·4분 토큰 만료와 계정당 4분 발급 간격은 로컬 시험 보호다. 공급자 계정의 무료 상태는 AI Studio에서 수동 확인하며 앱이 검증하지 못한다. 프로세스 재시작 후 제한 지속, 탈퇴 직후 이미 발급한 직접 연결의 강제 해지, 운영 비용 차단은 보장하지 않는다. 유료 프로젝트로 전환해 이 경로를 사용하지 않는다.

## 학습·저장 통합과 실험 통제

앱은 음성 원본을 전송·재생 동안의 휘발성 버퍼로 처리하고 파일·DB·로그·백업에 보관하지 않는다. 저장 학습은 [학습 저장 설계](LEARNING-PERSISTENCE.md)의 같은 저장/연결 계약을 사용한다. `VoiceLearningRecords`는 입력 완료된 사용자 턴과 생성/재생 완료된 AI 턴만 기존 snapshot으로 바꾸고, `VoiceLearningStore`는 같은 순번/본문의 저장 재시도를 직렬화한다. 중단·연결 실패·3분 시험 타이머는 재개 가능한 중단, 학습 종료 버튼은 서버 종료와 잔여 저장·노트 정리로 연결한다. 잔여 저장에 실패하면 화면 메모리를 유지하며 재시도하고 마지막 확정 저장분은 기존 기한 작업으로 정리한다.

저장 학습 토큰은 본인 계정·학습 연결 소유와 유효성을 확인한 뒤 학습 도구 설정을 제한해 발급한다. 재개 시에는 해당 진행 대화의 확인된 최근 최대 20턴·텍스트 합계 20 KiB와 그 안에 근거가 있는 최근 교정 최대 3개를 전달한다. 설명은 각 500자, 재시도는 선택된 턴 중 최근 3개로 제한한다. 전체 과거 이력을 그대로 공급자에 전달하지 않는다. 이전 세션 복습 표현은 아래 컨텍스트 경계의 별도 경로로 선별한다. 개인별 장기 수준 상태·이력 기반 소재 선택/반복 회피·전체 AI 노트 선별은 후속이다.

구현: [확인 기록](../../app/src/voice/learning.ts), [저장 클라이언트](../../app/src/client/learning.ts), [음성 근거 노트](../../app/src/voice/note.ts). 현재 음성 노트는 최근 근거/교정 일부를 모으는 통합 시험용이며 전체 P0 노트·AI 선별 품질의 완료를 뜻하지 않는다.

공급자의 실제 사용자 데이터 처리 조건과 비공개 합성·본인 음성 시험 예외, 총 예산·신규 호출 차단의 기준은 [PRD의 공급자 데이터 조건](../PRD.md#provider-data-policy)·[9.2절](../PRD.md#92-ai-제공맥락이용량-정책), 이유는 [ADR-025](../adr/025-EPHEMERAL-AUDIO-AND-PROVIDER-RETENTION.md)·[ADR-056](../adr/056-LOCAL-TEST-PROVIDER-TRAINING-EXCEPTION.md)를 따른다. 현재 무료 시험 보호는 운영 비용 차단 구현이 아니다.

로컬 통합·후보 비교의 순서와 완료 판정은 [TASKS](../TASKS.md#선행-관계)를 따른다. 비교 후보·역할·제안된 시험 배분·미확인 조건은 [평가 계획](../proposals/AI-CANDIDATE-EVALUATION-PLAN.md)을 따른다. 최종 공급자·모델·연결 경로와 공개 배포는 아직 확정하지 않았다.

실행은 [README](../../README.md#gemini-live-비공개-음성-시험), 가짜 연결/단위·합성 실제 연결 스모크의 조건과 한계는 [2026-10-27 worklog](../worklogs/2026-10-27.md)에 둔다. 독립 평가 하니스의 비용 장부·기록 호환성은 [하니스 README](../../harness/voice-eval/README.md#구조)를 따른다.

구조화 교정/재시도의 실제 연결 진단은 `npm run voice:smoke:learning`으로 수행한다. 로컬 `espeak-ng`로 고정 합성 문장 두 개를 만들고 같은 어댑터/기록 조립기에 전달한다. 시험에서는 합성 음성의 자동 발화 감지 누락을 피하기 위해 토큰 제약과 연결 설정 양쪽에 자동 감지 해제를 동일하게 적용하고 발화 시작/끝을 명시한다. 실제 마이크의 자동 발화 감지 설정은 유지한다. 토큰 하나·연결 하나·연결 시험 60초로 제한하며 자동 재시도하지 않는다. 재생 완료는 모의 신호이며 DB 저장·실제 청취·마이크·교육 품질의 증거가 아니다. 전사/음성/비밀값은 출력하지 않고 연결·전송량·도구/기록 개수와 제한된 오류 코드만 출력한다. 실제 시험 결과와 실패 단계는 [2026-10-29 worklog](../worklogs/2026-10-29.md#구조화-학습-합성-음성-스모크)를 따른다.

## 튜터 프롬프트와 컨텍스트 경계

실행 원문은 [tutor-prompt.ts](../../app/src/voice/tutor-prompt.ts)에서 관리한다. 토큰 제약과 브라우저 초기 설정은 공통 생성 함수를 사용하며, 기록 도구 지시는 저장 학습에만 포함한다. 연속 난이도·질문 구성은 [PRD 3절](../PRD.md#3-제품-원칙)을 따르고 실제 AI 준수는 별도 평가한다.

앱이 컨텍스트를 조회·선별·전달하고 AI는 전달된 범위에서 활용한다. 재개 대화의 최근 확인 턴·교정/재시도 상태와 이전 세션의 복습 표현을 별도 입력으로 보낸다. 이전 표현을 현재 재시도 대기나 숙달 근거로 취급하지 않도록 데이터임을 표시한다. 프롬프트에는 전달된 정보만 활용하도록 지시한다.

이전 학습은 토큰 발급 시 로그인·본인 음성 연결을 확인한 같은 인증 트랜잭션에서 조회한다. 본인의 종료·노트 준비 완료된 음성 세션 중 보관 기한이 남고 한국 종료일이 최근 6개월 범위에 있는 노트를 DB 조회 단계에서 선별하며 현재 세션·텍스트 가짜 학습·다른 계정·만료 노트는 제외한다. 전체 원문은 조회하지 않고 새 저장/보관 기간도 추가하지 않는다. 정확한 타입과 선택 구현은 [prior-learning.ts](../../app/src/voice/prior-learning.ts), 조회는 [학습 서비스](../../app/src/server/learning.ts)를 따른다.

현재 로컬 방식은 [새 노트 형식](LEARNING-NOTE.md)의 상단 세 맥락을 읽고 하단 근거 참조를 확인한다. 구형 시험 노트의 ‘다음 복습’도 명시적인 구형 경로로 읽되 마지막 노트 등장일을 실제 연습일로 반환하지 않는다. 같은 표현을 합쳐 최대 2개를 선택하고 관찰을 함께 전달한다. 확인된 연습일이 없으면 후보의 최신 노트 등장일을 정렬 참고로 사용하며 실제 연습일은 생략한다. 표현 UTF-8 1,200바이트·이전 맥락 전체 4 KiB의 기존 임시 상한을 유지한다. 주제는 기간 내 노트에서, 난이도는 기간과 별개로 보관 중인 노트의 최신 유효 관찰 날짜에서 읽는다. 초과 항목은 통째로 생략한다. 이 개수·상한·정렬은 최종 품질 기준으로 확정되지 않았다.

브라우저에는 토큰과 선택 결과만 반환하고 공급자에는 현재 대화와 구분한 데이터 메시지로 전달한다. 전송만으로 즉시 응답하거나 새 학습 결과를 만들도록 요청하지 않는다. 계정 정보·노트 전문·세션 ID·원문 근거·과거 재시도 상태는 이 이전 학습 데이터에 넣지 않으며 로그에도 남기지 않는다. 이는 표현 복습의 부분 구현으로, 주제·난이도 상단 항목의 읽기/전달은 구현했지만 실제 AI 종료 추출·소재 선택/반복 회피·난이도 조절 품질과 난이도 선택 입력은 미완료다. 음성 종료 의사의 확인 후 앱 종료 연결도 별도 미완료 범위다.


### 최근 6개월 조회 경계

기간 정책의 기준은 [PRD 7절](../PRD.md#7-주제와-표현-정책)이다. 현재 노트 기반 부분 구현에서는 DB 현재 시각을 한국 날짜로 바꾼 뒤 달력상 6개월 전 날짜부터 당일까지 포함해 조회한다. 대상 월에 같은 일이 없으면 그 월의 마지막 날을 사용한다(예: 8월 31일의 6개월 전은 2월 말일). 180일 고정 기간으로 환산하지 않는다. 경계 밖 본문은 조회·파싱하지 않고, 노트 조회/다운로드와 보관 기한에는 이 필터를 적용하지 않는다.

연습일·주제/난이도 생성의 현행 한계와 새 형식 읽기 계약은 [학습 노트 설계](LEARNING-NOTE.md#현재-구현과-남은-연결)를 따른다.

## 노트 기반 학습 맥락의 저장 기준

[PRD의 노트 구성](../PRD.md#일일-노트와-다운로드)에 따라 학습 맥락은 노트 상단의 주제·난이도·복습 표현 세 항목에서 읽고, 세부 내용과 근거는 하단에 함께 둔다. 별도 맥락 테이블이나 별도 영속 사본을 추가하지 않는다. 현재 코드는 새 형식의 생성·읽기와 구형 복습 읽기를 지원하며 실제 AI 추출은 후속이다. 상단 표기·하단 근거 참조·생성/검증/읽기 계약은 [학습 노트 설계](LEARNING-NOTE.md)에 구체화했다. 전체 AI 추출 연결과 선별 수치·품질 평가는 남는다.

## 분리형 비공개 시험 경로

`/voice`에서 연결 전에 Gemini Live 또는 분리형을 선택한다. 분리형은 같은 `VoicePort` 뒤에 Soniox 실시간 전사 → Gemini 3.5 Flash-Lite 텍스트 응답 → Gemini 3.8 Flash-Lite TTS를 연결한다. 확정된 사용자 전사와 제한된 확인 맥락만 텍스트 모델에 보낸다. 생성된 음성의 재생 완료를 따로 확인하고, 끼어들기나 중단으로 듣지 못한 응답은 교정 근거와 다음 맥락에서 제외한다. 공통 학습 기록·저장·노트 형식은 경로별로 분기하지 않는다.

분리형 API는 로컬 동일 출처·로그인·학습 연결 소유를 확인하고 Soniox 단일 사용 임시 키를 발급한다. Google과 Soniox의 장기 키는 서버에만 둔다. 연결 토큰은 사용자와 학습 세션에 묶고, 텍스트·음성 요청 횟수와 동시 요청을 제한한다. TTS는 같은 연결에서 서버가 직전에 생성한 문구에 한해 한 번 허용한다. 이 제한은 비공개 단일 프로세스 시험 보호이며 공개 서비스의 계정/기간별 연결 허용 시간, 서버 재시작/다중 인스턴스 집행과 DEC-062의 주간 비용 대조를 충족하지 않는다. 클라이언트가 보내는 전사·맥락과 재생 확인도 서버가 독립 검증하지 못한다. 공개 연결은 B-09·D-03의 공급자 데이터 조건과 비용·인증·상태 계약을 검증한 뒤 별도 승인한다.

2026-10-30 사용자 직접 시험에서는 짧은 분리형 대화 약 3회의 전사·응답·재생 성공을 보고했다. Soniox STT 사용액 $0.002298은 사용자 보고이며 전체 청구액은 확인되지 않았다. 끼어들기·저장 학습·장시간·실제 교육 품질은 미검증이다. 상세 조건과 테스트 결과는 [작업 기록](../worklogs/2026-10-30.md#분리형-음성-main-통합)을 따른다.

## 시간 기반 이용과 비용 대조

승인된 목표(DEC-062/063): 서버가 계정·이용 기간별 공급자 연결 허용 시간, 동시 연결과 발급 횟수를 관리한다. 학습 세션의 시작/종료 차이는 공급자 연결 시간이 아니므로 시간 차감에 그대로 쓰지 않는다. 브라우저가 공급자 연결의 열림/닫힘과 대화 수를 관찰해 서버로 보내고, 서버는 연결 중 신호의 수신 시각과 대조해 연결 사용 시간을 누적한다. 발급 최대 시간을 사용 시간으로 즉시 차감하지 않고 연결이 열리지 않은 발급도 사용 시간으로 세지 않는다. 종료 보고가 없으면 마지막 서버 확인 뒤 짧은 유예 시간까지만 차감한다. 유예 길이·신호 간격·정정 기준과 보고 오차는 검증 후 정한다. 직접 연결의 시작·끝을 서버가 독립적으로 보지 못하므로 서버 발급 권한과 공급자 측 연결 상한을 별도 안전 경계로 삼아 중단·재접속·중복 발급·재시작의 우회를 검증한다. 브라우저의 종료 보고만으로 차감을 즉시 멈추지 않는다. 정확한 시간·기간·이용 기록 수명은 구현 전에 정한다.

서버는 새 공급자 자격을 발급하기 전 남은 허용 시간과 계정의 기존 연결 상태를 원자적으로 확인한다. 계정당 활성 음성 연결은 Live·분리형과 기기를 합쳐 하나이며 동일 발급 요청의 재전송으로 새 권한을 만들지 않는다. 종료가 독립 확인되지 않은 연결의 발급 자리 해제와 재시도 응답은 공급자 최대 지속시간을 검증해 정한다. 연결 시간 경계(남은 허용 시간 소진, DEC-064로 연결당 별도 상한 제외)는 공급자 설정과 앱 안내를 맞추고, 시간 부족 때 새 유료 음성 연결·AI 요청을 막는다. 이미 확인된 대화의 저장·종료 정리와 24시간 재개 범위의 기록 처리는 유지한다. 경계에 가까워진 대화의 새 질문·교정·재시도와 마무리 안내의 세부 순서는 공급자 종료 동작을 검증해 정한다. 종료 노트에는 음성 연결 시간과 별도의 호출/재시도 제한을 두고 실패 상태를 유지한다. 노트의 종료 후 24시간 기한과 근거 검증은 PRD 8절·학습 노트 설계를 따른다.

계정·이용 기간별 허용/사용 시간과 현재 연결 발급 상태는 지속 DB의 계정 연결 이용권 테이블에 둔다(DEC-063). 학습 세션·노트의 보관 기한과 무관하게 현재 이용 기간의 잔여 시간을 유지하고 탈퇴 때 함께 삭제한다. 지난 기간 합계·발급 이력·중복 방지 ID의 열/테이블 배치는 갱신·보고 지연·복원 조건을 정한 뒤 확정한다. 현재 구현에는 이 테이블이 없다.

운영 계측은 사용자 수, 경로별 승인 연결 시간, 대화/문답 수, 노트 호출·실패 등 내용 없는 수치로 제한한다. 매주 Google/Soniox 실제 과금 총액을 활동량과 대조하고, 공급자 보고에서 분리 가능한 모델/경로/SKU만 실제 부분액으로 표시한다. Gemini 텍스트와 노트처럼 같은 과금 단위에 섞인 기능별 비용은 별도 귀속 근거가 없으면 추정·미확인으로 남긴다. 보고 지연·정정은 다음 주 대조에서 반영하고 기간/경로/모델 구성을 함께 기록한다. 무료 등급의 0원 표본으로 유료 시간당 비용을 확정하지 않는다. 공급자 지출 상한·알림과 앱 발급 제한은 시간 평균의 오차를 보완하는 별도 경계이며 설정·수치는 후속이다. 원문·음성·노트 본문·비밀값을 비용 계측에 넣지 않는다.

현재 구현: Live와 Soniox STT는 브라우저 직접 연결이다. 현행 180초 단일 시험 토큰·요청 횟수 제한은 비공개 로컬 시험값이며 위 기간 시간 이용권을 구현하지 않는다. 분리형 Gemini 텍스트·TTS에는 이전 DEC-061을 준비하며 만든 선택적 `usageMetadata` 추출 함수가 있지만 라우트에 연결되지 않고 지속 저장·차감도 없다. DEC-062는 토큰 원장 구현을 요구하지 않는다. 경로별 연결 지속시간의 서버 검증·시간 상태·주간 비용 대조와 공급자 지출 경계는 미구현이다.
