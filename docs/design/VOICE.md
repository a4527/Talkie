# 음성 연결 설계

갱신일: 2026-10-28. 현재 `/voice`는 로컬 로그인 후 사용하는 비공개 본인 음성 시험이며 `/learn`의 가짜 AI 저장 흐름과 별개다. 실제 음성과 저장·교정·노트를 함께 처리하는 전체 학습 통합은 후속이며 검증 상태는 [PROGRESS](../PROGRESS.md)를 따른다. [전체 구조](../DESIGN.md), [제품 AI 정책](../PRD.md#92-ai-제공맥락이용량-정책)을 따른다.

## 포트·어댑터 경계

공통 학습 코드가 공급자 SDK·WebSocket 메시지를 직접 다루지 않도록 `app/src/voice/port.ts`에 음성 연결·입력·전사·출력·중단·종료 계약을 둔다. 초기에는 Next.js 한 앱에서 구현한다. Gemini Live 어댑터가 공급자 메시지를 이 이벤트로 바꾸고 브라우저 장치 처리는 별도 `BrowserAudio`가 담당한다. 분리형은 같은 포트 뒤에 STT→LLM→TTS를 연결하는 어댑터로 추가한다. 별도 음성 서버·MSA·독립 배포는 채택하지 않았다. 실제 확장·장시간 연결·실행 환경 필요가 관측되면 원격 통신 어댑터와 서버 분리를 재논의한다.

음성 메모리 항목은 `VoiceTranscriptTurn`, 갱신 함수는 `updateVoiceTranscriptTurns`, 파일은 `voice/transcript.ts`다. Gemini 전용 설정은 `gemini-live-setup.ts`에 둔다. 내부 단위는 `sampleRateHz`·`testDurationSeconds`·`nextPlaybackTimeSeconds`로 명시하고 외부 Web/공급자 API 필드는 유지한다.

구현: [음성 포트](../../app/src/voice/port.ts), [전사 처리](../../app/src/voice/transcript.ts), [Gemini 설정](../../app/src/voice/gemini-live-setup.ts), [서버 토큰](../../app/src/server/voice-token.ts). 채택 근거는 [DEC-055](../DECISIONS.md#dec-055)를 따른다.

## 직접 연결과 자격 증명

브라우저는 로그인·동일 출처·시험 확인을 거쳐 [토큰 API](API.md#비공개-음성-토큰-api)를 호출하고 받은 단기 토큰으로 공급자에 직접 연결한다. 장기 API 키는 서버 환경에만 두고 본문·오류·로그에 출력하지 않는다. 브라우저 직접 경로부터 검증하고 사용량 차단·취소·실제 재생 범위·기록 동기화 조건을 충족하지 못하면 서버 중계도 비교한다. 최종 운영 경로를 확정한 것은 아니다([DEC-030](../DECISIONS.md#dec-030)).

## 생성·재생·전사 범위

포트의 `response-complete`는 생성 완료이며 재생 완료가 아니다. `transcript.ts`는 생성 전사문을 미확인으로 표시하고 브라우저 출력 큐가 끝난 경우에만 재생 완료를 표시한다. 중단된 응답은 정확한 단어별 청취 위치를 알 수 없어 전체를 근거에서 제외하는 보수적 초기 구현이다. 이는 실제 청취나 학습 성공의 증거가 아니다. 교정/재시도 구조화 이벤트, 확인 턴의 저장·재개·노트 통합과 정확한 미재생 맥락 동기화는 후속이다.

## 장치와 로컬 시험 제한

마이크는 PCM16을 휘발성 작업 버퍼로만 보내고 응답 PCM은 Web Audio로 재생한다. 중단 시 출력 큐를 비우며 종료·실패·화면 이탈 시 장치·연결·재생 자원을 해제한다. 화면 전사문은 최대 최근 100개·각 6천 자로 메모리에만 유지한다. 3분 타이머·토큰 1회 사용·발급 후 1분 새 연결·4분 토큰 만료와 계정당 4분 발급 간격은 로컬 시험 보호다. 공급자 계정의 무료 상태는 AI Studio에서 수동 확인하며 앱이 검증하지 못한다. 프로세스 재시작 후 제한 지속, 탈퇴 직후 이미 발급한 직접 연결의 강제 해지, 운영 비용 차단은 보장하지 않는다. 유료 프로젝트로 전환해 이 경로를 사용하지 않는다.

## 학습·저장 통합과 실험 통제

앱은 음성 원본을 전송·재생 동안의 휘발성 버퍼로 처리하고 파일·DB·로그·백업에 보관하지 않는다. 재개·노트는 확인된 전사문·진행 상태로 연결해야 하지만 현재 `/voice` 전사문은 DB·노트와 연결되지 않았다. 공통 프롬프트·선택된 학습 맥락·구조화 교정 이벤트·재연결 상태의 통합이 남는다.

공급자의 실제 사용자 데이터 처리 조건과 비공개 합성·본인 음성 시험 예외, 총 예산·신규 호출 차단의 기준은 [PRD의 공급자 데이터 조건](../PRD.md#provider-data-policy)·[9.2절](../PRD.md#92-ai-제공맥락이용량-정책), 이유는 [ADR-025](../adr/025-EPHEMERAL-AUDIO-AND-PROVIDER-RETENTION.md)·[ADR-056](../adr/056-LOCAL-TEST-PROVIDER-TRAINING-EXCEPTION.md)를 따른다. 현재 무료 시험 보호는 운영 비용 차단 구현이 아니다.

로컬 통합·후보 비교의 순서와 완료 판정은 [TASKS](../TASKS.md#선행-관계)를 따른다. 비교 후보·역할·제안된 시험 배분·미확인 조건은 [평가 계획](../proposals/AI-CANDIDATE-EVALUATION-PLAN.md)을 따른다. 최종 공급자·모델·연결 경로와 공개 배포는 아직 확정하지 않았다.

실행은 [README](../../README.md#gemini-live-비공개-음성-시험), 가짜 연결/단위·합성 실제 연결 스모크의 조건과 한계는 [2026-10-27 worklog](../worklogs/2026-10-27.md)에 둔다. 독립 평가 하니스의 비용 장부·기록 호환성은 [하니스 README](../../harness/voice-eval/README.md#구조)를 따른다.
