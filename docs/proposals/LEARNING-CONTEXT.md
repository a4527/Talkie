# 학습 맥락 저장·선별 검토안

작성일: 2026-10-29. 상태: 기존 저장 합의를 반영한 후속 검토안. 저장 형식 외의 추천은 미승인이다.

최근 6개월 조회는 승인된 [PRD 7절](../PRD.md#7-주제와-표현-정책)을 따른다. 현재 구현과 임시 상한은 [VOICE](../design/VOICE.md)에 설명하며, 이 제안으로 확정하지 않는다. AI 판단과 앱 기록의 책임은 [ADR-010](../adr/010-AI-LED-LEARNING-APP-RECORDS.md)을 유지한다.

노트 구성의 구체적인 형식·생성·검증·읽기는 사용자 요청으로 [학습 노트 설계](../design/LEARNING-NOTE.md)에 정리했다. 아래 비교안의 별도 후보 목록·선별 수치까지 채택한 것은 아니다.

## 제안하는 다섯 가지

| 논의 항목 | 추천안 | 대안과 절충 |
| --- | --- | --- |
| 1. 저장 형식(기존 합의) | 노트만 저장하며 상단에 주제·난이도·복습 표현의 세 가지 학습 맥락, 하단에 세부 내용과 근거를 정리한다. | 별도 구조화 맥락 저장 제안은 기존 합의를 놓친 오류로 철회했다. 구체적인 노트 표기·읽기 계약은 이 저장 방식 안에서 정리한다. |
| 2. 추출 시점 | 종료 후 기존 AI 노트 선별 결과에 학습 맥락을 함께 포함한다. 앱은 근거를 검증하고 유효한 항목만 저장한다. 정리 실패 시 새 맥락을 만들지 않는다. | 대화 중 매번 장기 맥락을 추출하면 일찍 반영할 수 있지만 호출·중복·부분 저장 처리가 늘어난다. 종료 추출은 다음 학습 시작까지 정리가 끝나지 않으면 최신 맥락을 활용하지 못한다. |
| 3. 주제 선택 | 앱이 최근 6개월의 유효한 주제·상황·대화 목적과 준비된 후보를 비교해 미경험 후보를 우선 고른다. 같은 주제라도 목적과 상황이 다른 후보를 허용한다. 명칭만 바뀐 후보를 별개로 세지 않는다. | AI에 이력 전체를 주고 고르게 하면 자유롭지만 전달량·누락 가능성이 커진다. 앱 후보 방식은 후보 목록 관리와 의미 중복의 사례 평가가 필요하다. 세부 후보 목록·전달 개수는 후속 검토한다. |
| 4. 난이도 참고 | 고정 등급 대신 어휘·문장 구조·질문 개방성·설명 부담·도움 필요에 대한 관찰과 근거를 저장한다. 최신 유효 관찰을 시작점으로 전달하고 상충하는 관찰은 함께 표시한다. | 숫자 하나는 간단하지만 무엇이 어려웠는지 잃는다. 관찰 저장은 설명 가능하지만 분량이 늘며, 일시 도움과 장기 수행 판단을 구분하는 AI 평가가 필요하다. 공백 뒤에는 현재 응답으로 조절하며 자동 등급 하락은 추가하지 않는다. |
| 5. 표현 복습 | 표현마다 추천·도움 필요·재시도 성공/실패·자발적 사용 관찰을 구분한다. 실제 사용·재연습 근거가 있을 때 마지막 연습일을 갱신하고, 노트 추천만으로 갱신하지 않는다. 최근 6개월 안에서 어려움 근거와 사용 빈도를 참고해 후보를 고르되 초기 전달은 최대 2개·전체 맥락 4 KiB를 평가용 상한으로 제안한다. | 현재의 오래된 노트 등장 순은 구현이 단순하지만 실제 연습·사용 빈도를 반영하지 못한다. 노트에서 표현 동일성·상충 관찰을 구분하는 처리가 추가된다. 상한은 품질·지연 실측 후 조정하며 숙달 여부를 앱이 추정하지 않는다. |

## 구현 순서와 영향

기존 노트 단일 저장 합의를 기준으로 상단 세 항목과 하단 근거의 형식을 정리한다. 나머지 추천안에 동의하면 근거 검증 계약과 노트 추출 출력 형식을 설계하고, 합성 결과로 저장/조회/계정 격리를 연결한다. 이후 기존 모델 평가 절차에서 실제 추출 품질을 확인하고 주제 선택·난이도·복습 전달을 단계적으로 연결한다. 모델·추가 호출 한도는 이 제안으로 선정하거나 승인하지 않는다.

비용은 같은 종료 추출의 출력량 증가와 노트 분량·조회 증가가 예상되며 금액·지연은 미측정이다. 일정에는 노트 형식 변경·기존 노트와의 호환·추출 검증·후보 목록 작업이 추가된다. 사용자는 주제 반복 감소와 이전 어려움 반영을 기대할 수 있지만 잘못된 추출로 부적절한 복습이 생길 수 있어 평가가 필요하다.

새 근거는 해당 세션의 접근·보관·삭제 경계에 연결하고, 만료·탈퇴로 사용할 수 없는 근거는 공급자 입력에서 제외하는 방향을 제안한다. 기존 노트를 소급 AI 처리하거나 보관 기간을 연장하지 않는다. 통합 요약을 별도 유지하는 방식은 이번 추천에 포함하지 않아 만료 근거가 요약에 남는 문제를 피한다. 상단 맥락도 노트의 일부로서 같은 접근·삭제·백업 복원 경계를 따른다.

## 완료 판정에 필요한 검증

- 근거 없는 항목·미재생 발화·누락 구간을 제외하고, 원문 삭제 후 짧은 근거 연결을 확인한다.
- 최근 6개월 경계·만료·탈퇴·다른 계정 제외와 근거의 삭제 후 재전달 차단을 확인한다.
- 추천만으로 연습일이 갱신되지 않고, 실제 재연습은 갱신되며 따라 말하기를 숙달로 해석하지 않는지 확인한다.
- 동일 주제의 다른 목적 허용과 표면적 바꿔 말하기 반복 회피를 사례 평가한다.
- 상충 수행·학습 공백·단일 실패에서 시작 난이도와 도움 조절을 평가하고 전달량·지연을 측정한다.

이 문서는 내부 계약과 미구현 경계에 근거한 제안이며 외부 공급자의 기능·비용을 조사하거나 실제 AI 품질을 확인한 결과가 아니다. 작업 상태는 B-03/B-05/B-06/B-07/B-09의 IN PROGRESS를 유지한다.
