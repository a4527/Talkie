# 최소 기술 스택 비교안

작성일: 2026-10-16. 상태: A안 채택 (`DEC-015`), 비교 당시 제안 보존. 작업: `D-04` 완료. 승인된 개발 접근은 `DEC-006`·`DEC-007`이며 채택 범위·근거·한계는 [ADR-015](../adr/015-NEXTJS-TYPESCRIPT-LOCAL-PROTOTYPE.md)를 기준으로 한다. 아래 추천·동의 요청은 채택 전 비교안이다.

## 이번에 결정할 범위

첫 로컬 학습 흐름을 실행할 프레임워크·언어와 애플리케이션 경계를 고른다. 클라우드·지역·배포 서비스·DB·인증·AI 공급자는 각각 D-02/D-03/D-05에서 비교한다. 이 선택으로 사용자 데이터 정책이나 외부 API 비용을 승인하지 않는다.

## 후보 비교

아래 일정·운영 평가는 이 프로젝트의 초기 구현에 대한 추정이다. 월 요금은 지역·사용량·운영 구조가 미정이므로 산정하지 않았다. 세 후보 모두 로컬 가짜 응답 단계에서는 클라우드와 AI 호출 비용 없이 검증할 수 있다.

| 기준        | A. Next.js + TypeScript                    | B. Vite/React + Node.js API               | C. Vite/React + FastAPI                |
| --------- | ------------------------------------------ | ----------------------------------------- | -------------------------------------- |

## 추천안 A의 적용 범위

Next.js와 TypeScript로 한 애플리케이션을 시작하되 화면, 대화 상태 규칙, 응답 공급자, 기록 처리의 책임을 구분하는 안을 추천한다. 서버 비밀값은 서버 전용 모듈에서만 다룬다. 로컬 가짜 응답 구현을 먼저 검증하고 승인된 실제 AI 연결을 서버에 추가한다.

한 언어·한 실행 프로젝트에서 첫 흐름을 빠르게 검증할 수 있다는 점이 추천 이유다. 클라우드 엔지니어링 근거는 선택한 환경의 배포·관측·복구·비용 개선으로 쌓는다. 특정 호스팅 플랫폼을 필수로 정하지 않는다.

정적 내보내기만으로 서버 기능이 제공되지는 않는다. 실제 AI 호출과 기록 처리를 서버에서 수행하는 단계에는 서버 실행 환경이나 별도 API가 필요하다. 음성 스트리밍 경로는 D-03에서 확인하고 그 결과가 운영 후보에 맞는지 검증한다. 프레임워크·의존성 버전은 선택 승인 후 호환성을 확인하고 잠금 파일로 고정한다.

## 승인 후 첫 구현

1. 로컬 프로젝트와 반복 가능한 실행·빌드 명령을 만든다.
2. [첫 학습 흐름](../design/FIRST-LEARNING-FLOW.md)에 따라 텍스트 입력과 가짜 응답을 연결한다.
3. 상태 전이·중복·종료 후 응답의 자동 테스트, 브라우저 흐름 확인, 최소 측정을 추가한다.
4. B-00 검증 결과와 한계를 기록하고 D-02/D-03의 비교를 이어간다.

## 확인한 사실과 미확인 사항

- 관찰: 2026-10-16 현재 로컬 실행 환경에 Node.js v24.22.0과 npm 11.19.1이 있다. 프레임워크 의존성 설치·빌드 검증은 아직 수행하지 않았다.
- 공식 문서: Next.js는 Node 서버·Docker 배포와 정적 내보내기를 지원하며 정적 내보내기의 기능에는 제한이 있다. [Next.js 배포](https://nextjs.org/docs/app/getting-started/deploying)
- 공식 문서: Vite는 정적 호스팅에 적합한 빌드 결과물을 생성하며 별도 백엔드 통합 안내를 제공한다. [Vite 빌드](https://vite.dev/guide/build), [백엔드 통합](https://vite.dev/guide/backend-integration)
- 공식 문서: FastAPI는 배포 시 HTTPS·재시작·복제·메모리 등을 검토하도록 안내하고 컨테이너 배포를 지원한다. [FastAPI 배포 개념](https://fastapi.tiangolo.com/deployment/concepts/), [컨테이너 배포](https://fastapi.tiangolo.com/deployment/docker/)
- 비교 당시 미확인: 사용자 선호 언어, 클라우드 제공자·지역·월 예산, 음성 연결 방식, 실제 동시 사용량. 이 항목을 확정하지 않고 특정 운영 서비스의 비용·성능 우위를 단정하지 않는다.

## 필요한 동의

추천안 A의 프레임워크·언어와 한 애플리케이션의 책임 분리 방식에 동의하면 해당 선택을 결정 기록에 남기고 B-00 구현을 시작한다. 중요 기술 선택을 사전 논의·합의하도록 정한 [AGENTS.md](../../AGENTS.md)에 따른 단계다.

## 2026-10-21 후속 합의

사용자가 Next.js + TypeScript 한 프로젝트와 로컬 가짜 AI 흐름 구현에 동의했다. 상세 모듈 경계나 헥사고날·MSA, 별도 백엔드·워커·클라우드는 확정하지 않았다. 현재 설계는 DESIGN.md, 결정 이유는 ADR-015를 따른다.
