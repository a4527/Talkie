# Talkie 진행 현황

2026-11-04: 첫 카페 미션의 시작 방식·A1~C2 참고 수준·목표/언어 세부 채점과 재시도 반영·판정 불가 제외·표시/반올림·재제조/환불 복수 해결을 합의했다(DEC-070~081). 현행 정책은 [PRD 4절](PRD.md#4-주요-사용자-흐름), 연결·검증 경계는 [미션 설계](design/MISSIONS.md)를 따른다. 문서와 B-03/B-04/B-12 수용 기준을 갱신했으며 앱 코드는 아직 자유 대화용이다. 다음은 [상세 검토안](proposals/FIRST-MISSION-DETAILS.md)의 수준별 평가 사례·무진전 기준과 미정인 평가/노트 호출 구성·API/DB 계약을 구체화하는 일이다. 실제 AI 연결·품질 검증은 미완료이며 미션 시작 구현으로 표시하지 않는다([오늘 기록](worklogs/2026-11-04.md)).

2026-11-03: [DEC-069](adr/069-MISSION-CENTERED-LEARNING.md)에 따라 미션 중심 정책과 관련 문서를 최신화했다. 미션 생성·평가·횟수 차감·달성 일수는 승인·미구현이며 기존 앱의 자유 대화/교정·시험 제한은 전환 전 구현이다. 작업 기준은 TASKS, 문서 정합성 점검은 [오늘 기록](worklogs/2026-11-03.md)을 따른다.

2026-11-02 로컬 시연용 앱 데모를 통합했다(DEC-068, B-11). 랜딩·로그인·홈·대화·종료 피드백·노트·계정 화면이 기존 톤의 공통 내비게이션으로 이어지고, 음성 경로 선택은 대화 시작 화면에 남았다. Google 로그인과 명시적 연결·해제 제한·탈퇴 재인증(DEC-067)을 구현했으며 가짜 신원 서버 시험만 통과했고 실제 Google OAuth 클라이언트 흐름은 미검증이다. 단위 121개·서버 26개(1개 생략)·빌드·PC/모바일 브라우저(데모·음성 22개, 실제 DB 저장 4개)가 통과했다([검증 기록](worklogs/2026-11-02.md#로컬-앱-데모-통합)).

2026-11-02 배포 전 로컬 E2E 실행 경로를 추가했다. 임시 PostgreSQL 두 개와 Mailpit에서 실제 백업/복원을 포함한 서버 시험 26개·프로덕션 빌드·PC/모바일 브라우저 24개(계정 간 기록 격리·탈퇴 후 이전 세션 차단 포함)를 통과했고, 실제 Gemini 고정 합성 문장의 연결·음성·전사 수신을 확인했다([검증 기록](worklogs/2026-11-02.md#배포-전-로컬-e2e-실행)). 브라우저 음성은 가짜 공급자이며 분리형 실제 공급자·실제 장치·운영 배포/복구와 공개 정책 검증은 남는다. V-01~03, C-03 등 관련 TASK 상태는 유지한다.

마지막 갱신: 2026-11-02 · 비공개 `/voice` 분리형 시험에서 STT·LLM·TTS 선택을 표시하고, TTS에 Google Cloud Standard를 추가했다. STT Soniox·LLM Gemini는 한 후보씩이며 선택을 서버 연결 토큰에 고정한다. Cloud TTS 토큰은 로컬 ADC에서 자동 발급·재사용하며 별도 `export` 없이 실제 합성 PCM 수신을 확인했다. 가짜 공급자 시험 118개·타입 검사와 PC/모바일 브라우저 10개가 통과했다. 사용자는 실제 앱의 Cloud 경로 청취에서 문제 없다고 보고했다. Soniox 항목별 오늘 사용액은 사용자 보고로 기록했으며 Cloud 청구액·발화별 지연·계정 조건은 미확인이다. 최종 공급자 선택과 TASK 상태는 바뀌지 않았다([오늘 기록](worklogs/2026-11-02.md#사용자-보고-사용액과-후보-비교-중단-요청)). 앞서 Soniox·Google Cloud의 같은 가상 문장 WAV 생성도 확인했다.

`/voice`에서 Gemini Live와 분리형을 연결 전에 선택할 수 있다. 분리형은 Soniox 전사·Gemini 텍스트·TTS를 연결하고 공통 학습 기록을 사용한다. 사용자 직접 시험에서 짧은 대화 약 3회의 전사·응답·재생 성공과 Soniox STT 사용액 $0.002298이 보고됐다. Gemini 청구액·끼어들기·저장 학습·장시간 연결은 미확인이다. 서버 생성 문구에만 분리형 TTS를 한 번 허용하고 연결 토큰을 학습 세션에 묶었다. 로컬 무료 Gemini 시험과 분리형 사용액은 구분하며 공개 배포의 시간 이용권·주간 비용 대조·공급자 데이터 조건은 아직 미완료다([작업 기록](worklogs/2026-10-30.md#분리형-음성-main-통합)).

현재 단계: 가짜 AI의 저장 학습 흐름을 유지하며 Gemini Live 비공개 음성을 전체 학습 흐름에 연결하는 중이다. `/voice`의 단기 토큰·마이크·재생·중단·전사문 시험과 합성 입력의 실제 공급자 음성/전사 수신은 확인했다. 사용자는 직접 음성 시험에서 문제가 없다고 보고했다([2026-10-29 worklog](worklogs/2026-10-29.md)). 계정별 저장·재개·구조화 교정/재시도 상태·근거 노트 연결을 추가했고 사용자는 이번 저장 학습 시험을 완료했다고 보고했다. 가짜 연결/합성 DB로 앱 흐름을 확인했으며 실제 Gemini의 새 도구 동작·교정 품질과 전체 AI 노트 선별은 남는다. 합성 음성 자동 감지 누락과 도구만 완료된 단계의 조기 답변 완료 처리를 수정했다. 교정/재시도 프롬프트를 구체화한 뒤 실제 합성 연결의 교정 1건·재시도 성공 1건이 기록돼 고정 스모크 1회가 통과했다. 교육 품질과 전체 시나리오 검증은 남는다([프롬프트 보완과 검증](worklogs/2026-10-29.md#재시도-판정-프롬프트-보완)). 실행은 [README](../README.md#gemini-live-비공개-음성-시험)를 따른다.

`/account`의 합성 이메일 인증·로그아웃·탈퇴 확인과 `/learn`의 계정별 저장/재개·가짜 노트/다운로드는 로컬 시험할 수 있다. 실제 메일·Google 인증·유료 전환·운영 백업/삭제 복구·JSONL 로거는 미완료다. 로그인·재로그인 모두 이메일/Google을 지원하는 요구사항은 문서에 반영했으며 계정 연결 등은 D-02 합의 후 B-01에서 구현한다.

문서·코드 명명 정리는 반영했으며 문서 머리말의 공통 안내·진행 이력·제안서 분류·TASKS의 명세 중복 정리를 마쳤다. 세부 변경은 [CHANGELOG](CHANGELOG.md), 이번 점검은 [2026-10-28 worklog](worklogs/2026-10-28.md)를 따른다.

- 사용자의 요청으로 추가 E2E 검증은 후속으로 보류한다. 기존 검증 결과와 미완료 TASK 상태는 유지한다.
- 사용자 수정 후 [전체 튜터 프롬프트 검토본](proposals/VOICE-TUTOR-PROMPT.md)을 로컬 MVP에 반영했다. B-03은 IN PROGRESS이며 연속적인 난이도 조절·질문 부담·한국어 도움·주제 다양성의 실제 AI 평가는 후속이다.
- 주제·복습 표현 맥락의 조회 범위를 최근 6개월로 승인받았다. 현재 부분 구현의 복습 조회에도 기간 필터를 적용했으며, 시작 난이도는 최신 유효 값 참고가 기준이다. 이전 음성 세션의 유효한 근거 노트에서 복습 표현 최대 2개를 선별·전달하는 부분 구현을 추가했다. 현재 대화 재개와 구분하며 계정 격리·만료 제외를 검증했다. 주제/상황 이력 기반 소재 선택·수행 근거 기반 난이도 시작점과 실제 AI 복습 품질은 남는다. 노트 선별/요약 프롬프트도 별도 후속 범위다.

## 합의와 미정 범위

- 로컬 E2E 우선과 음성 포트 경계는 [ADR-055](adr/055-GEMINI-LIVE-FIRST-E2E-AND-VOICE-PORT.md), 후보 확장 비교의 후순위는 [ADR-066](adr/066-DEFER-EXPANDED-AI-CANDIDATE-COMPARISON.md)을 따른다. 공개 경로의 공급자·모델·연결 방식은 미확정이다.

- 제안과 과거 검토의 구분은 [제안서 색인](proposals/INDEX.md), 남은 결정 논의 순서는 [사전 결정 진행표](proposals/MVP-PREIMPLEMENTATION-DECISIONS.md)를 따른다. 진행표의 과거 ‘미정’ 표시는 현행 PRD·결정·설계와 대조하며 다음 논의는 필요한 항목 다섯 개씩 묶는다.
