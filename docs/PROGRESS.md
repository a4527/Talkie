# Talkie 진행 현황

갱신일: 2026-11-14. 작업 상태·수용 기준의 기준은 [TASKS](TASKS.md)이며 아래는 현재 범위의 요약이다.

현재 단계는 **기존 로컬 자유 대화 앱에서 첫 카페 미션으로 전환하기 전**이다. C 통합·관찰/평가 정책과 합성 사례는 정리했지만 미션 생성·수행·최종 평가·횟수 차감·달성 일수 코드는 미구현이다. 현행 계약은 [PRD](PRD.md), 연결 설계는 [MISSIONS](design/MISSIONS.md)를 따른다. 문서 정리 과정·Claude 검토·검사 환경 조치는 [오늘 기록](worklogs/2026-11-14.md)에 남긴다.

## 다음 재개 지점

1. [평가 사례](proposals/FIRST-MISSION-EVALUATION-CASES.md)의 남은 등급 후보·독립 감점 근거를 검토한다. 대본/판정 후보는 실제 AI 결과나 승인된 정답표가 아니다. C(고급)를 포함한 다섯 수준을 쓰며 짧고 충분한 수행을 평가한다.
2. [첫 연결 순서](design/MISSIONS.md#첫-연결-범위와-구현-순서)에 따라 최소 API/저장·평가/노트 호출 계약을 구체화한다. 운영 무진전 임계값·연결 성립/환급·일수 날짜/소급·공개 이용량 수치를 임의로 확정하지 않는다.
3. 사용자가 보류한 추가 E2E는 후속으로 유지한다. 미션 계약이 정해지기 전에 기존 자유 대화 검증을 전환 완료로 재사용하지 않는다.

## 합의와 미정 범위

- C 통합·관찰 범위·미션 계약은 [PRD 4절](PRD.md#4-주요-사용자-흐름)·DEC-069/070/083/084를 따른다. 세부 등급·중복 감점 보류 추천은 미확정이며 [첫 미션 상세 검토](proposals/FIRST-MISSION-DETAILS.md)와 사례 초안을 계약으로 취급하지 않는다.
- 현행 사용자 차감 단위는 미션 횟수다. 과거 시간제는 [당시 비교 기록](proposals/API-USAGE-BUDGET.md)으로 보존하고 새로 구현하지 않는다. 주간 실제 과금 대조·노트 호출 보호·단일 음성 연결은 유지한다.
- 로컬 비공개 합성/본인 음성 시험과 실제 사용자/유료 호출 조건은 [PRD 공급자 정책](PRD.md#provider-data-policy)으로 구별한다. 공급자·모델·공개 경로의 최종 채택은 미승인이며 외부 조건의 과거 조사를 현재 적합성 검증으로 쓰지 않는다.
- Google 연결 정책/로컬 구현과 실제 클라이언트 미검증, 음성 종료 추출 코드/합성 평가와 실제 음성 E2E·교육 품질 미검증을 구분한다. 제품 미정은 [PRD 11절](PRD.md#11-개발-접근과-미결정-사항), 기술적 미정은 [DESIGN](DESIGN.md#기술적-미정과-결정-시점)에 둔다.
