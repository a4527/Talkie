# Talkie 진행 현황

갱신일: 2026-11-17. 작업 상태·수용 기준의 기준은 [TASKS](TASKS.md)이며 아래는 현재 범위의 요약이다.

현재 단계는 **기존 로컬 자유 대화 앱에서 첫 카페 미션으로 전환하기 전**이다. C 통합·관찰/평가 정책과 합성 사례는 정리했지만 미션 생성·수행·최종 평가·횟수 차감·달성 일수 코드는 미구현이다. 현행 계약은 [PRD](PRD.md), 연결 설계는 [MISSIONS](design/MISSIONS.md)를 따른다. 문서 정리 과정·Claude 검토·검사 환경 조치는 [오늘 기록](worklogs/2026-11-14.md)에 남긴다.

## 다음 재개 지점

1. [평가 사례](proposals/FIRST-MISSION-EVALUATION-CASES.md)의 여덟 사례 12개 기준 판정 후보·점수 요약은 2026-11-14 사용자 검토를 마쳤다. 실제 AI 판정과의 대조는 평가 호출 구현 뒤에 한다. 상호작용 기준의 정의 구분은 평가 프롬프트 작성 때 반영한다.
2. 첫 미션의 [최소 연결 계약](design/MISSIONS.md#최소-연결-계약)을 2026-11-15에 합의했다(DEC-086~089, 승인·미구현). 정의 레지스트리·시작 고정, 진행 상태(`missionProgress`)의 저장·병합·재개, 실시간 미션 도구(검증기·클라이언트 창 경계·서버 전용 미션 지시), 검증 결과에 따른 자동 종료·실전 실패 마무리 대사·서버의 종료 사유/최종 경로 기록, 종료 평가 호출(노트와 동시 요청)과 결과 집계/상세 저장을 구현하고 합성·DB 시험을 통과했다. 미션 선택·결과 화면도 구현해 단위·DB·가짜 공급자 브라우저 시험을 통과했다(2026-11-15). 평가 판정의 합성 사례 대조를 무료 비공개 시험으로 진행해 기준 경계를 평가 지시에 보강했다(2026-11-16, 80% 달성 여부는 모두 후보와 일치, 과적합·80% 경계 사례 미검증). 새 사례 두 묶음(H·N)으로 과적합을 검토했다. 기준 일치율 93~96%·80% 달성 여부는 N 묶음 17/17 일치였지만, 설명 외 발화(수락·요청)의 저장 누락을 직원 발화로 추정하는 문제가 두 묶음에서 반복됐다. 경계 판정은 DEC-090, 처리 요청 인정 범위는 DEC-091로 정해 평가 지시에 반영했고 3차 새 사례에서 기준 일치 98.4%·80% 달성 여부 14/14 일치를 확인했다. 누락 시 일수 인정 정책은 B-12 일수 작업에서 다룬다. 상대역이 요청 전에 처리 선택지를 먼저 꺼내던 문제를 지시로 고치고 분리형 텍스트 응답으로 확인했다(Live 미확인). 누락 표시는 버퍼 상한 잘림만 다루고 빈 전사는 표시되지 않는다는 한계를 확인해 저장 형식은 유지하기로 했다(사용자 선택). 상대역의 수준별 말하기(A1 짧은 문장·선택지와 조건 분리)와 조건 동의 전 확정 금지를 지시에 넣고 분리형 텍스트로 확인했다(A1 가장 긴 문장 평균 13→6단어, Live·여러 턴 미확인). 텍스트 경로의 여러 턴·연습·단일 응답 범위·80% 경계 점검에서 분리형 응답의 미션 보고 형식 때문에 확정까지 간 대화가 자동 종료되지 않는 문제를 찾았다([11월 16일](worklogs/2026-11-16.md#텍스트-경로-남은-점검-서브-에이전트-4개-동시-실행)). 2026-11-17에 분리형 응답 스키마로 출력 형식을 고정하고 상대역 지시를 정리해, 무료 텍스트 시험에서 실전 5개·연습 대화의 자동 종료가 모두 기대와 일치했다. 연습 교정은 구조를 유지하고(호출 수 동일) 큰 문법 오류·어색한 표현만 교정 → 다시 말하기 → 역할극 복귀로 정했다(DEC-092). 교정 응답의 경로 사건은 검증기가 무시한다. 무료 텍스트 시험에서 교정 채택·시도 판정·복귀와 시도 뒤 미션 완료를 확인했다(상황당 1~4회, Live 미확인). 다음은 [11월 17일 다음 순서](worklogs/2026-11-17.md#다음-순서제안)(11월 16일 평가 경계 결정 → 교정 흐름 남은 점 결정·반복 측정 → 실제 공급자 음성 시험)다. 분리형 TTS 무료 한도(하루 10회)를 시험 계획에 반영한다. 실제 공급자에서 토큰 고정 지시의 우선 동작·도구 호출 품질은 확인하지 않았다. 운영 무진전 임계값·연결 성립/환급·일수 날짜/소급·공개 이용량 수치를 임의로 확정하지 않는다.
3. 사용자가 보류한 추가 E2E는 후속으로 유지한다. 미션 계약이 정해지기 전에 기존 자유 대화 검증을 전환 완료로 재사용하지 않는다.

## 합의와 미정 범위

- C 통합·관찰 범위·미션 계약은 [PRD 4절](PRD.md#4-주요-사용자-흐름)·DEC-069/070/083/084/085를 따르고, 최소 연결 계약은 DEC-086~089(결과 집계 장기 보관은 DEC-088)를 따른다. 언어 세부 기준은 각자의 정의로 독립 판정한다(DEC-085). 사례별 세부 등급은 미확정이며 [첫 미션 상세 검토](proposals/FIRST-MISSION-DETAILS.md)와 사례 초안을 계약으로 취급하지 않는다.
- 현행 사용자 차감 단위는 미션 횟수다. 과거 시간제는 [당시 비교 기록](proposals/API-USAGE-BUDGET.md)으로 보존하고 새로 구현하지 않는다. 주간 실제 과금 대조·노트 호출 보호·단일 음성 연결은 유지한다.
- 로컬 비공개 합성/본인 음성 시험과 실제 사용자/유료 호출 조건은 [PRD 공급자 정책](PRD.md#provider-data-policy)으로 구별한다. 공급자·모델·공개 경로의 최종 채택은 미승인이며 외부 조건의 과거 조사를 현재 적합성 검증으로 쓰지 않는다.
- Google 연결 정책/로컬 구현과 실제 클라이언트 미검증, 음성 종료 추출 코드/합성 평가와 실제 음성 E2E·교육 품질 미검증을 구분한다. 제품 미정은 [PRD 11절](PRD.md#11-개발-접근과-미결정-사항), 기술적 미정은 [DESIGN](DESIGN.md#기술적-미정과-결정-시점)에 둔다.
